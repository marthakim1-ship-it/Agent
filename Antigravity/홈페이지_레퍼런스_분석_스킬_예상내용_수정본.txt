================================================================================
[홈페이지 레퍼런스 분석 스킬 - 최종 완성 종합 메모 (수정본)]
================================================================================

1. 스킬 명칭 및 목적
   - 스킬 명칭: website-reference-analyzer
   - 목적: 수집된 홈페이지 레퍼런스 자료를 4~5단계 표준 템플릿과 8단계 정밀 분석 논리에 따라 분석하고, UTF-8 .txt 메모장 파일(100개 단위 분할)로 출력한다.

--------------------------------------------------------------------------------

2. 입력 데이터 및 탐색 보완 규칙 (1~2단계 & 예외 처리 보완)
   - [기본 자료 지정]: 파일명에 [리서치 결과]가 들어간 파일 및 `research/YOVIA_BRAND_REFERENCE_RESEARCH_200.txt` (또는 `research/batches/` 배치 파일)을 자동 탐색하여 기본 자료로 활용한다.
   - [대용량 배치 로딩]: 500KB 이상 대용량 파일 탐색 시 `research/batches/batch-*.txt` 20개 단위 배치 로딩으로 메모리 부하 방지.
   - [추가 자료 입력 명령]: 사용자가 "리서치 자료 추가 입력"이라고 명령하면 이후 제공하는 파일, URL, 텍스트를 추가 자료로 인지하여 `research/additional/` 폴더에 영구 보관한다.
   - [누적 병합]: 추가 자료는 기존 자료를 덮어쓰지 않고 누적 병합한다.
   - [출처 분리 및 URL 정규화]: 기본 자료와 추가 자료의 출처를 명확히 구분하고, URL 정규화(프로토콜/슬래시 제거)를 통해 동일 사이트 중복 발견 시 통합하되 모든 출처를 보존한다.

--------------------------------------------------------------------------------

3. 출력 파일 및 4~5단계 표준 분석 양식
   - [출력 디렉토리]: `output/` 폴더 자동 생성 후 저장 (`output/홈페이지_분석_001-100.txt`)
   - [파일 포맷]: UTF-8 인코딩 방식의 .txt 메모장 파일로 생성한다.
   - [용량 분할 네이밍]: 1개 TXT 파일당 최대 100개 홈페이지 분석 수록 (100개 초과 시 '001-100', '101-200' 네이밍 분할).
   - [무단절 원칙]: 1개 홈페이지의 단위 분석 내용은 절대로 파일 분할 경계에서 쪼개어 나누지 않는다.
   - [3대 영역 독립 분리]: 홈페이지별 분석 / 전체 비교 분석 / 최종 인사이트 영역을 각각 분리 작성한다.

   - [5단계 표준 분석 양식 (홈페이지 1개 단위)]:
     * 기본 정보: 홈페이지 이름 / URL / 업종 / 정보 출처
     * 세부 분석 (4단계 기준): 디자인 특징 / 화면 구성 / 사용자 흐름 / 문구와 콘텐츠 / 주요 기능 / 장점과 단점 / 참고할 부분

--------------------------------------------------------------------------------

4. 6단계 확정: 8단계 정밀 분석 논리 프로세스
   [1] 홈페이지별 개별 분석 (7개 세부항목)
   [2] 비슷한 내용 그룹화 (Grouping)
   [3] 등장 횟수 및 비율 기록 (%)
   [4] 패턴 구분 (공통 30% 이상 / 반복 10%~30% / 특이 10% 미만 우수 아이디어)
   [5] 공통점과 차이점 도출
   [6] 패턴별 장점과 문제점 상세 분석
   [7] 최종 인사이트 수립 (출처 연계)
   [8] 추가 조사 항목 명시 (추측 금지)

--------------------------------------------------------------------------------

5. 7~8단계 및 예외 처리 반영 완료
   - SKILL.md 지침 파일 완성: (.gemini/skills/website-reference-analyzer/SKILL.md)
   - 8단계 정밀 분석 논리 가이드: (.gemini/skills/website-reference-analyzer/references/analysis-logic.md)
   - UTF-8 .txt 보고서 템플릿: (.gemini/skills/website-reference-analyzer/references/report-template.txt)
