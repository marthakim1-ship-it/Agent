## 2. 확정된 데이터 처리 & 시스템 규칙 (Summary of Established Rules)

### 📌 1~2단계: 데이터 수집 및 명령어 규칙
1. **기본 리서치 자료 자동 탐색**:
   - 파일명에 `[리서치 결과]`가 포함된 파일 및 `research/YOVIA_BRAND_REFERENCE_RESEARCH_200.txt` (대용량인 경우 `research/batches/batch-*.txt` 20개 단위 배치 로딩)를 기본 리서치 자료(Base Research)로 사용.
2. **"리서치 자료 추가 입력" 명령어 감지**:
   - 사용자가 `"리서치 자료 추가 입력"`이라고 입력하면 이후 제공되는 파일, URL, 텍스트를 추가 자료(Additional Research)로 인지하여 `research/additional/` 폴더에 영구 보존.
3. **누적 병합 및 출처 명시**:
   - 추가 자료는 기존 자료를 덮어쓰지 않고 병합하며, 보고서에 **[기본 자료 출처]**와 **[추가 자료 출처]**를 구분하여 명시.
4. **URL 정규화 & 중복 통합**:
   - URL 프로토콜(`http://`, `https://`) 및 끝 슬래시(`/`) 정제를 통해 중복 홈페이지는 1개로 통합하되, 발견된 수집 출처 경로 정보는 모두 보존.

### 📌 3단계: 결과물 저장 및 파일 생성 규칙
1. **UTF-8 .txt 포맷**: 분석 결과물은 모두 UTF-8 인코딩 방식의 `.txt` 메모장 파일로 생성.
2. **저장 위치**: 프로젝트 루트 내 `output/` 디렉토리를 자동 생성 후 저장.
3. **100개 단위 분할**: 1개 TXT 파일당 최대 100개 홈페이지 분석 결과 수록 (`output/홈페이지_분석_001-100.txt`, `101-200.txt` 등).
4. **무단절 원칙 (No Split)**: 1개 홈페이지 분석 단위(100번째 항목)는 파일 경계에서 잘리지 않고 단일 파일에 완결 처리.
5. **3대 영역 독립 분리**:
   - **영역 1: 홈페이지별 분석** (기본 정보 + 세부 분석)
   - **영역 2: 전체 비교 분석** (공통점, 차이점, 패턴 수치화, 우수사례, 장단점)
   - **영역 3: 최종 인사이트** (필수 참고, 선택 참고, 차별화 참고, 추가 조사 필요 항목)

### 📌 4~5단계: 사용자 정의 슬롯 (4단계 확정 완료)
- **4단계 (사용자 입력 포맷 및 AI 처리 프로세스 확정)**:
  - **사용자 전달 양식**: `[원하는 전체 느낌]`, `[공통적으로 마음에 든 점]`, `[레퍼런스별 차이점]`, `[반드시 적용하고 싶은 요소]`, `[피하고 싶은 요소]`, `[우선 참고할 홈페이지]`, `[아직 결정하지 못한 부분]`
  - **자료 수신 시 AI 처리 절차**:
    1. 비슷한 표현과 선호를 그룹화
    2. 원하는 느낌을 명확한 UI/UX 디자인 언어로 정리
    3. 필수/선택/제외 요소로 구분
    4. 정량 분석 가능한 세부 기준 항목으로 변환
    5. 최종 4단계 분류 기준안 작성 후 사용자 확인 요청 후 분석 실행
- **5단계 (홈페이지 1개 단위 포맷)**: 4단계 기준에 맞춰 유연하게 조정 연동.

### 📌 6단계: 8단계 정밀 분석 논리 프로세스
AI가 수집된 자료를 분석할 때 반드시 따라야 하는 8단계 논리:
1. **홈페이지별 개별 분석**: 7개 핵심 항목 추출 (디자인, 화면구성, 유저흐름, 문구/콘텐츠, 주요기능, 장단점, 참고할부분)
2. **비슷한 내용 그룹화 (Grouping)**: 메인 카피, 제품 이미지, CTA 버튼, 후기 등 요소 묶기
3. **등장 횟수 & 비율 계산 (%)**: 전체 대상 수 대비 각 요소의 발견 수량 및 비율 정량 기록
4. **패턴 구분 (수치 + 아이디어 가치)**:
   - 공통 패턴: 30% 이상
   - 반복 패턴: 10% 이상 ~ 30% 미만
   - 특이 사례: 10% 미만 중 우수 아이디어
5. **공통점과 차이점 도출**: 대부분 사용 방식 / 업종별 차이 방식 / 반대 방식 / 독자적 방식 대조
6. **패턴별 장단점 분석**: 패턴명, 사용 홈페이지, 장점, 단점, 적합한 상황, 주의점 기록
7. **최종 인사이트 수립 (출처 연계)**: 필수 참고 / 선택 참고 / 차별화 참고 (수집 출처 표기 필수)
8. **추가 조사 항목 명시**: 추측 금지 ➔ `[추가 조사 필요 / 확인할 내용 / 현재 부족한 근거]` 형태 항목 명시

- **분기 A (4단계/5단계 세부 입력 시)**: 사용자가 분류 기준(4단계) 및 1개 레퍼런스 포맷(5단계)을 제공하면, `.gemini/skills/website-reference-analyzer/SKILL.md` 및 `report-template.txt`에 유연하게 주입 적용한다.
- **분기 B ("리서치 자료 추가 입력" 명령 시)**: 이후 입력되는 파일, URL, 텍스트를 `research/additional/` 폴더에 저장하고 추가 리서치 자료로 보관 태깅한다.
- **분기 C (리서치 분석 실행 명령 시)**: 아래 [2단계]~[5단계] 순서로 자동 분석 실행에 진입한다.

### [3단계] 8단계 정밀 분석 논리 적용
