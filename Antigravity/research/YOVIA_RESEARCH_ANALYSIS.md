# YOVIA 웹사이트 레퍼런스 분석

## 1. 분석 기준

200개 레코드를 다음 세 관점으로 구분했다.

1. **직접 레퍼런스**: 요거트, 스키르, 파우치, 마시는 식사, 휴대형 아침
2. **인접 레퍼런스**: 단백질 음료·바, DTC 식품, 제품 구조와 사용법이 명확한 소비재
3. **주변 레퍼런스**: 제품 카테고리는 멀지만 패키지 컬러·상품 탐색·기능 설명 패턴을 참고할 수 있는 사이트

동일 공식 도메인은 첫 번째 유효 레코드만 대표값으로 사용했다. `failed`는 분석에서 제외했고, `partial`은 확인된 필드만 반영했다.

## 3. 반복적으로 확인된 UX 패턴

### 3.1 히어로 영역

가장 빈번한 구조는 다음 조합이다.

- 한 문장 가치 제안
- 제품 패키지 대형 이미지
- 영양 또는 편의 배지 2–4개
- `제품 보기`와 `구매처 찾기`의 이중 CTA

YOVIA에서는 제품명보다 먼저 다음 경험을 전달하는 편이 적합하다.

> 파우치를 열고, 내장 스푼으로, 토핑까지 한 번에.

히어로에는 파우치 전면만 두기보다 개봉부·스푼·요거트 질감·토핑을 한 화면에서 읽을 수 있는 제품 구조 컷이 필요하다.

### 3.2 핵심 수치

기능성 식품은 긴 설명보다 숫자를 먼저 보여준다.

- 단백질
- 당
- 칼로리
- 프로바이오틱 또는 원료 수
- 준비 시간

YOVIA의 상단 배지는 실제 확정된 수치만 사용하고 `락토프리`, `무가당`, `빌트인 스푼`, `토핑 포함`을 동일한 시각 체계로 표현한다.

### 3.3 제품 사용법

파우치와 간편식 레퍼런스에서 효과적인 방식은 3–4단계 사용 흐름이다.

1. 파우치 상단을 연다.
2. 빌트인 스푼을 꺼낸다.
3. 토핑을 섞거나 올린다.
4. 이동 중 또는 책상에서 바로 먹는다.

각 단계는 설명문보다 손·패키지·내용물의 근접 이미지가 중심이 되어야 한다.

### 3.4 제품군 탐색

제품이 여러 맛으로 확장될 경우 다음 구조가 반복된다.

- 맛별 고유 컬러
- 패키지 전면 썸네일
- 핵심 영양 수치
- `자세히 보기` 또는 `구매하기`
- 알레르기·원료 태그

맛 컬러는 페이지 전체 테마를 바꾸기보다 제품 카드, 배지, 탭과 배경 포인트에 제한하는 편이 정보 일관성을 유지한다.

### 3.5 모바일

확인된 모바일 중심 패턴과 YOVIA에 필요한 구성은 다음과 같다.

- 한 손 사용을 고려한 큰 CTA
- 세로형 제품 패키지와 짧은 카피
- 스크롤 중 유지되는 구매 또는 판매처 CTA
- 제품 상세의 영양·원료·FAQ 아코디언
- 가로 비교표 대신 세로 카드
- 사용법 이미지를 한 단계씩 넘기는 구조

## 4. 권장 정보 구조

```text
1. 헤더
2. 히어로: 한 문장 가치 제안 + 제품 구조 컷
3. 핵심 배지: 락토프리 / 무가당 / 빌트인 스푼 / 토핑 포함
4. 사용 상황: 출근 전 / 등교 전 / 이동 중 / 책상
5. 4단계 사용법
6. 제품 구조: 파우치, 절취선, 스푼, 요거트, 토핑
7. 맛·제품 카드
8. 영양·원료 정보
9. 브랜드 원칙과 제품 개발 배경
10. FAQ
11. 구매 또는 출시 알림 CTA
12. 푸터
```

## 5. 시각 방향

YOVIA의 지정 컬러는 역할을 분리해 사용하는 것이 좋다.

| 컬러 | 권장 역할 |
|---|---|
| `#E6F0F7` | 기본 배경 |
| `#91C7E8` | 제품 정보·신뢰 영역 |
| `#EDD72A` | 핵심 CTA와 강조 배지 |
| `#FD8030` | 토핑·맛·에너지 포인트 |
| `#B4BD02` | 원료·웰니스 보조색 |

주요 이미지는 세 가지 유형으로 구성한다.

- 패키지 정면과 개봉 구조
- 숟가락으로 뜬 요거트 질감과 토핑
- 출근·등교·책상·이동 중 실제 섭취

## 6. 피해야 할 방향

- 영양 수치가 확정되지 않은 상태에서 숫자를 장식처럼 사용하는 것
- 모든 맛의 컬러를 한 화면에 같은 강도로 사용하는 것
- 제품 구조 설명 없이 일반적인 “건강한 아침” 카피만 반복하는 것
- 데스크톱의 넓은 표를 모바일에 그대로 축소하는 것
- 지나친 모션으로 요거트 질감과 패키지 정보가 가려지는 것
- `Shop`과 `Where to Buy`의 목적이 구분되지 않는 CTA

## 7. 결론

YOVIA의 가장 강한 웹사이트 차별점은 “건강한 요거트” 자체보다 **파우치·내장 스푼·토핑을 하나의 사용 경험으로 설명할 수 있다는 점**이다.

따라서 메인 페이지는 브랜드 감성보다 먼저 다음 세 질문에 답해야 한다.

1. 무엇이 들어 있는가?
2. 어떻게 열고 먹는가?
3. 언제 가장 편리한가?

레퍼런스에서 반복된 패키지 중심 히어로, 큰 기능 배지, 단계별 사용법, 맛별 컬러, 모바일 고정 CTA를 이 세 질문에 맞춰 결합하는 것이 핵심 방향이다.
