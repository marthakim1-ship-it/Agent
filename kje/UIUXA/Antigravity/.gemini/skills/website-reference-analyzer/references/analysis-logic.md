# 8단계 정밀 분석 논리 가이드 (Analysis Logic Reference)

본 문서는 `website-reference-analyzer` 스킬 실행 시 AI가 준수해야 하는 정밀 분석 및 정량 계산 지침입니다.

---

## 1. 개별 사이트 7대 분석 항목
- 디자인 특징 (컬러, 톤앤매너, 비주얼 스타일)
- 화면 구성 (레이아웃, 그리드, 영역 배치)
- 사용자 흐름 (GNB, 정보 구조, CTA 흐름)
- 문구와 콘텐츠 (슬로건, 대표 카피, 톤오브보이스)
- 주요 기능 (인터랙션, 도구, 대표 기능)
- 장점과 단점 (우수한 UX 요소 및 페인포인트)
- 참고할 부분 (벤치마킹 핵심 요소)

---

## 2. 정량적 패턴 구분 수치 기준
- **공통 패턴 (Common Pattern)**: 전체 대상 홈페이지 중 `30% 이상` 발견된 요소
- **반복 패턴 (Recurring Pattern)**: `10% 이상 ~ 30% 미만` 발견된 요소
- **특이 사례 (Unique Case)**: `10% 미만` 발견되었으나 아이디어 가치가 높은 우수 사례

---

## 3. 추측 금지 및 근거 표기 원칙
- 원문에 근거가 없는 정보는 임의로 추정하거나 왜곡하여 작성하지 않는다.
- 데이터가 부족한 경우 반드시 아래 서식으로 작성한다:
  ```text
  ■ 추가 조사 필요
  - 확인할 내용: [확인이 필요한 구체적 내용]
  - 현재 부족한 근거: [자료에 미포함된 세부 정보]
  ```
