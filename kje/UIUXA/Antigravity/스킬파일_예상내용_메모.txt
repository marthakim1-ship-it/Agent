================================================================================
[스킬 파일 작성 예정 내용 초안 메모]
================================================================================

1. 스킬 개요
   - 스킬 이름: homepage-reference-analyzer (홈페이지 레퍼런스 분석 스킬)
   - 목적: 홈페이지 레퍼런스 자료를 바탕으로 정해진 4대 목차와 세부 기준에 따라 분석을 수행하고 텍스트 파일(.txt 메모장) 형태의 보고서를 생성한다.

--------------------------------------------------------------------------------

2. 데이터 입력 및 처리 규칙 (1~2단계 확정)
   - [기본 자료 지정]: 파일명에 [리서치 결과]가 들어간 파일을 항상 기본 리서치 자료(Base Research)로 사용한다.
   - [추가 자료 명령]: 사용자가 "리서치 자료 추가 입력"이라고 명령하면 이후 제공하는 파일, URL, 텍스트를 추가 자료(Additional Research)로 인식한다.
   - [덮어쓰기 금지]: 추가 자료는 기존 자료를 덮어쓰지 않고 누적 병합한다.
   - [출처 분리 표기]: 기본 자료와 추가 자료의 출처를 명확히 구분해서 기록한다.
   - [중복 레퍼런스 통합]: 동일한 홈페이지가 중복되면 하나로 묶되, 수집된 출처 정보는 모두 기록한다.
   - [통합 분석]: 분석 시 기본 자료와 추가 자료를 함께 종합적으로 활용한다.

--------------------------------------------------------------------------------

3. 출력 결과물 및 작성 규칙 (3~5단계 확정)
   - [출력 파일 형식]: 텍스트 파일(.txt 메모장 파일)
   - [파일 분할 규칙]: 메모장 1개 파일당 최대 100개 홈페이지 분석 내용 포함 (100개 초과 시 별도 순차 파일로 분할 생성)
   - [결과물 세부 목차 및 구조]:

     1) 기본 정보
        - 홈페이지 이름
        - URL
        - 업종

     2) 홈페이지별 분석
        - 디자인
        - 화면 구성
        - 사용자 흐름
        - 문구와 콘텐츠
        - 주요 기능
        - 장점과 단점
        - 참고할 부분

     3) 전체 비교 분석
        - 공통점
        - 차이점
        - 반복되는 패턴
        - 눈에 띄는 사례

     4) 최종 인사이트
        - 새 홈페이지에 적용할 아이디어
        - 우선 참고할 홈페이지
        - 적용 시 주의할 점
        - 추가 조사가 필요한 내용

--------------------------------------------------------------------------------

4. 향후 진행 예정 단계
   - 6단계: 분석 순서 및 방법 확정
   - 7~8단계: 최종 SKILL.md 및 reference 파일 정식 작성
   - 9~10단계: 테스트 및 실전 사용
================================================================================
