- 다음 예정 작업: 새 설계 결과를 입력으로 최종 스토리보드 3장 제작

## 1. 현재 상태 요약

가상 클라이언트 분석 결과 21개를 각각 독립 입력으로 사용하여 사이트맵 단계부터 설계 결과를 전부 재생성했다.

새 공통 설계 계약:

```text
MAIN-001      메인페이지(홈)
CATEGORY-001  카테고리 페이지
BRAND-001     브랜드 소개 페이지
```

모든 Client의 메인페이지에는 다음 상품 슬롯이 존재한다.

```text
PRODUCT-001 ~ PRODUCT-015
```

실제 상품명·가격·용량·영양·효능·재고 등은 입력에서 확정되지 않았으므로 상품 슬롯을 실제 상품으로 단정하지 않고 `NOT_VERIFIED`로 표시했다.

각 Client는 공통 핵심 화면 3개 외에 분석 주제에 맞는 특화 화면 2개를 가진다.

```text
TASK-001  Client별 핵심 과업 화면
TASK-002  Client별 검증·결과 화면
```

총 설계 화면 수는 Client별 5개이며, 특화 화면명은 21개 Client에서 모두 다르다.

## 3. 수정한 실행 규칙

### 설계 프롬프트

파일:

```text
설계 프롬프트\설계프롬프트.txt
```

추가한 주요 계약:

- 핵심 화면 3개 필수
- 세 화면 간 왕복 이동
- 메인페이지 상품 슬롯 최소 15개
- PRODUCT ID 고유성
- JSON `products` 배열
- HTML 실제 DOM 상품 요소 최소 15개
- 상품별 대체 텍스트·행동·이동 대상·검증 상태
- JSON과 HTML의 PRODUCT ID 및 수량 일치
- 미확정 정보의 `NOT_VERIFIED` 처리
- 근거 없는 상품·브랜드 정보 생성 금지

### 최종 스토리보드 제작 프롬프트

파일:

```text
스토리보드 결과\최종_스토리보드_제작_프롬프트.txt
```

기존 메인페이지 1장 계약을 다음으로 변경했다.

```text
MAIN-001      메인페이지 1장
CATEGORY-001  카테고리 페이지 1장
BRAND-001     브랜드 소개 페이지 1장
총 3장
```

메인페이지에는 `PRODUCT-001~PRODUCT-015` 이상의 개별 상품 항목을 명세하도록 수정했다.

## 7. 재생성 스크립트

현재 전체 재생성 스크립트:

```text
tools\regenerate-all-designs-v2.ps1
```

스크립트 역할:

1. 정상 분석 파일 `VC_XXX_{이름}.md` 탐색
2. Requirement·이동 경로·Site ID 추출
3. 공통 핵심 화면 3개 생성
4. Client별 특화 화면 2개 생성
5. 상품 슬롯 15개 생성 및 `NOT_VERIFIED` 처리
6. MD·MMD·HTML·JSON 원본 생성

주의:

- 스크립트 실행만으로 SVG는 생성되지 않는다.
- 생성 후 Mermaid CLI로 MMD 42개를 SVG로 렌더링해야 한다.
- 렌더링과 전체 검증을 통과한 파일만 `설계 출력물`에 분류해야 한다.
- Windows PowerShell에서 UTF-8 BOM 없는 스크립트를 직접 실행하면 한글 파싱 문제가 발생할 수 있다. 현재 작업에서는 `Get-Content -Raw -Encoding UTF8`로 읽고 `Invoke-Expression`하여 실행했다.

## 10. 다음 작업 시 주의사항

- 21개 Client 결과를 단순 연결하거나 특정 Client 하나의 구조로 통일하지 않는다.
- 공통 요구는 통합하되 Client별 충돌·HOLD·NOT_VERIFIED를 삭제하지 않는다.
- 실제 상품 15종이 확정된 것으로 해석하지 않는다. 현재 15개는 설계 슬롯이다.
- 상품명·가격·용량·영양·효능·재고·판매 채널·인증을 임의 생성하지 않는다.
- 브랜드 소개에 근거 없는 연혁·수상·인증·환경 효과를 추가하지 않는다.
- Figma와 별도 메인페이지 HTML/CSS 구현은 사용자가 명시적으로 요청하기 전까지 실행하지 않는다.
- 스토리보드 생성 전에 최신 `설계 출력물`의 21개 Client·189개 파일을 다시 확인한다.
- 기존 `최종_스토리보드.md`가 있다면 덮어쓰기 전에 프롬프트에 정의된 archive 경로로 보존한다.
