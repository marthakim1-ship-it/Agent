# VC-001 서하린 — 화면 설계서

## 프로젝트 및 설계 범위

VC-001 분석 결과를 4개의 정보 탐색 화면으로 통합한 모바일 우선 저충실도 설계다. 제품 비교, 판매처, 구매, 로그인, 결제는 설계 범위에서 제외한다.

## 화면 ID 규칙과 전체 화면 목록

| ID | 화면 | 목적 | 주요 진입 | 주요 종료 |
|---|---|---|---|---|
| P-001 | 홈 | 제품의 정체와 핵심 가치를 빠르게 이해 | 기본 URL, 홈 복귀 | P-002, P-003, P-004 |
| P-002 | 제품 상세 | 제품 구조와 특징을 종합적으로 확인 | P-001, P-003, P-004, 직접 진입 | P-001, P-003, P-004 |
| P-003 | 사용 안내 | 사용 상황과 단계별 방법을 확인 | P-001, P-002, P-004, 직접 진입 | P-001, P-002, P-004 |
| P-004 | 성분·영양 | 원료·영양·알레르기 및 근거 상태를 확인 | P-001, P-002, P-003, 직접 진입 | P-001, P-002, P-003 |

## 공통 영역

| 영역 | UI 요소 | 동작 |
|---|---|---|
| 헤더 | YOVIA 로고, 4개 화면 내비게이션 | 선택 화면으로 이동, 현재 화면 표시 |
| 본문 시작 | 화면 ID, 제목, 한 문장 목적 | 직접 진입 시에도 맥락 제공 |
| 관련 정보 | 다음 화면 카드 | 도착 화면을 명시한 링크 제공 |
| 푸터 | 정보 상태 안내, 홈 링크 | 홈 복귀 |

## 화면별 설계

### P-001 홈

- 목적: 제품 정의와 일상 속 사용 가치를 짧게 이해시킨다.
- 구성: 히어로, 제품 이미지 플레이스홀더, 핵심 가치 3개, 정보 탐색 카드.
- 행동: 제품 상세·사용 안내·성분 및 영양 이동.
- 상태: 텍스트 우선 로딩, 이미지 오류 시 대체 설명.

### P-002 제품 상세

- 목적: 제품 구조, 구성 요소와 확인된 특징을 한곳에서 설명한다.
- 구성: 제품 전체 이미지, 구조 라벨, 구성 요소 카드, 검증 상태, 관련 정보.
- 행동: 구조 항목 선택, 사용 안내·성분 및 영양 이동.
- 상태: 이미지 로딩·오류, 제품 자산 미확정.
- 제약: 확인되지 않은 재질·용량·성능을 생성하지 않는다.

### P-003 사용 안내

- 목적: 사용 상황과 개봉·준비·섭취·정리 순서를 연결해 설명한다.
- 구성: 상황 카드, 4단계 안내, 단계별 이미지 플레이스홀더, 주의사항.
- 행동: 상황 선택, 이전·다음 단계, 제품 상세·성분 및 영양 이동.
- 상태: 기본, 선택 단계, 단계 자산 미확정.
- 제약: 운전 중 취식 장면은 사용 예시에서 제외한다.

### P-004 성분·영양

- 목적: 원료·영양·알레르기 정보의 내용과 신뢰 수준을 함께 제공한다.
- 구성: 정보 상태 요약, 원료, 영양, 알레르기, 출처·기준일, 관련 제품.
- 행동: 세부 정보 펼치기, 제품 상세·사용 안내 이동.
- 상태: 기본, 로딩, 자료 미확정, 자료 오류.
- 제약: 확인되지 않은 수치와 건강 효능은 표시하지 않는다.

## 유효성 검사와 상태 메시지

입력 폼은 없다. 상태 메시지는 원인과 다음 행동을 함께 제공한다.

| 상태 | 메시지 | 복구 행동 |
|---|---|---|
| 이미지 오류 | 제품 이미지를 불러오지 못했습니다. 텍스트 설명을 확인해 주세요. | 다시 시도 또는 계속 탐색 |
| 제품 자료 미확정 | 실제 제품 자산 확인이 필요합니다. | 확인된 설명 보기 |
| 영양 자료 미확정 | 확정된 수치와 출처가 아직 없습니다. | 제품 상세 또는 사용 안내 이동 |
| 자료 오류 | 정보를 불러오지 못했습니다. | 다시 시도 또는 홈 이동 |

## 반응형 기준

- 모바일(최대 767px): 1열, 하단 고정 없이 자연스러운 문서 흐름.
- 태블릿(768~1199px): 카드 2열, 단계 정보 2열.
- 데스크톱(1200px 이상): 최대 폭 1200px, 히어로·상세 정보 2열.
- 모든 화면에서 의미와 탐색 순서는 동일하게 유지한다.

## 접근성 요구사항

- 제목 계층과 랜드마크를 논리적으로 구성한다.
- 모든 이미지 플레이스홀더에 목적 중심 대체 텍스트를 제공한다.
- 키보드만으로 탐색하고 현재 포커스를 확인할 수 있어야 한다.
- 색상 외에 텍스트로 검증·오류 상태를 구분한다.
- 링크 이름만으로 이동할 화면을 예측할 수 있어야 한다.

## 가정 및 보류

- 실제 이미지와 제품 사양은 원본 자산 확인 전까지 플레이스홀더와 `확인 필요` 상태로 둔다.
- 제품 비교와 판매처는 향후 근거가 확보되면 별도 재설계한다.
- 현재 HTML은 정보 구조와 이동 관계를 검토하는 저충실도 시안이다.
