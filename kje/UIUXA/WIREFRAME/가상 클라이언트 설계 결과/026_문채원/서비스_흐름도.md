# VC-026 문채원 서비스 흐름도
## 개요와 시작·종료
체험·샘플링 프로그램 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 체험 구성 확인 → TASK-002 체험 신청 상태 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 체험 구성 확인 | 체험 신청 상태 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 체험 신청 상태 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC026-REQ-001**: 체험 목적·구성·대상·주의 조건을 신청 전에 제공
- **VC026-REQ-002**: 확정 구성과 예시·콘셉트 구성을 명확히 구분
- **VC026-REQ-003**: 체험 신청 없이 제품·사용법·주의 정보 접근
- **VC026-REQ-004**: 현장 QR 직접 진입의 맥락과 복구 경로 유지
- **VC026-REQ-005**: 피드백은 선택 사항으로 목적·보관 기간 표시
- **VC026-REQ-006**: 미확정 맛·수량·무료·한정·재고 공개 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
