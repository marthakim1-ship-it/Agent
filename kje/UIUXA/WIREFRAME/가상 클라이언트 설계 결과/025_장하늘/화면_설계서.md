### MAIN-001 — 메인페이지(홈)

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | 메인페이지(홈) (MAIN-001) |
| 화면 목적 | 반복 구매·정기배송 경험 관점의 브랜드·상품 탐색 시작 |
| 주요 콘텐츠 | 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태 |
| 인터페이스 요소 | 본문 바로가기, 헤더, 전역 내비게이션, 상품 카드 15개, 상태 라벨, 푸터. 화면 고유 콘텐츠는 ‘브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태’이며 주요 조작은 ‘카테고리 보기, 브랜드 소개 보기’이다. |
| 레이아웃 | 본문 바로가기 → 헤더·전역 내비게이션 → 브랜드·제품 가치 → 카테고리 진입 → 상품 15개 → 브랜드 소개 → 검증 상태 → 푸터 순서로 배치한다. 모바일부터 데스크톱까지 상품 DOM 순서를 유지한다. |
| 작동 방식 | ‘카테고리 보기, 브랜드 소개 보기’를 수행한다. 지원 상태는 기본, 로딩, 빈 상태, 오류, 완료이며, 오류 발생 시 재시도·수정·이전 단계 중 적절한 복구 수단을 제공한다. |
| 연결 화면 | CATEGORY-001, BRAND-001 |
| 사용자 경로 | 직접 진입, 핵심 화면에서 복귀 → 카테고리 보기, 브랜드 소개 보기 → CATEGORY-001, BRAND-001 |
| 비고·주석 | 제목·상태 텍스트·키보드 포커스·오류 복구. 확인되지 않은 상품·가격·재고·정책·효능·인증 정보는 NOT_VERIFIED 또는 HOLD로 표시하고 활성 CTA로 확정하지 않는다. |
