# VC-025 장하늘 서비스 흐름도
## 개요와 시작·종료
반복 구매·정기배송 경험 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 반복 구매 조건 → TASK-002 변경·해지 관리 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 반복 구매 조건 | 변경·해지 관리 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 변경·해지 관리 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC025-REQ-001**: 단건 재구매와 정기 구매 조건을 동등하게 비교
- **VC025-REQ-002**: 현재 상태·다음 일정·비용·구성을 명확히 표시
- **VC025-REQ-003**: 변경·건너뛰기·해지를 가입과 동등하게 접근
- **VC025-REQ-004**: 알림과 자동 갱신에 별도 동의·복구 제공
- **VC025-REQ-005**: 모바일에서 적용 전·후 상태를 비교
- **VC025-REQ-006**: 정책 확정 전 구독·할인·배송 혜택 활성화 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
