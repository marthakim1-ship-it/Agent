# VC-029 신가람 사이트맵
## 프로젝트 개요
재고 대기·출시 알림 분석을 기준으로 공통 핵심 3화면과 전용 과업 2화면을 구성한다.
## 설계 근거와 핵심 사용자 목표
- **VC029-REQ-001** (Must): 판매 중·품절·출시 예정·미확정 상태를 명확히 구분
- **VC029-REQ-002** (Must): 알림 목적·범위·채널·철회 방법을 신청 전에 제공
- **VC029-REQ-003** (Should): 알림 없이도 제품·사용법·대체 정보 접근
- **VC029-REQ-004** (Should): 상태 변경·신청·철회 결과를 명확히 확인
- **VC029-REQ-005** (Should): 모바일에서 상태와 기준일을 첫 화면에 유지
- **VC029-REQ-006** (Hold): 가짜 품절·긴급성·미확정 출시일·재고 공개 금지
대표 Site 근거: SITE-002, SITE-012, SITE-041, SITE-081, SITE-181
## 전역 내비게이션 구조
메인페이지 · 카테고리 · 브랜드 소개 · 판매 상태 확인 · 알림 설정 관리
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 판매 상태 확인
  - TASK-002 알림 설정 관리

## 공통·회원·예외
로그인을 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD와 재시도·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001의 PRODUCT-001~015는 실제 라인업이 아닌 NOT_VERIFIED 설계 슬롯이다.
## 연결성·가정
5개 화면은 시작점에서 도달·복귀 가능하다. 실제 상품·가격·재고·정책·효능·인증은 확정하지 않는다.
