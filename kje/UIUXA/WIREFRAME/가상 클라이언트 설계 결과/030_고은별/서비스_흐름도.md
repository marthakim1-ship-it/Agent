# VC-030 고은별 서비스 흐름도
## 개요와 시작·종료
출시 전 경험 QA·릴리스 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 출시 검증 → TASK-002 결함·재검증 상태 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 출시 검증 | 결함·재검증 상태 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 결함·재검증 상태 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC030-REQ-001**: 핵심 여정·직접 진입·복귀 경로의 출시 체크리스트 운영
- **VC030-REQ-002**: 기본·로딩·빈 상태·오류·완료·미확정 상태 검증
- **VC030-REQ-003**: 콘텐츠·정책·CTA의 승인 버전 일치 확인
- **VC030-REQ-004**: 320px·200% 확대·키보드·느린 연결 후보 검증
- **VC030-REQ-005**: 결함 심각도·소유자·재현·재검증 이력 기록
- **VC030-REQ-006**: 미실행 테스트·중대 결함·미확정 정책의 출시 승인 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
