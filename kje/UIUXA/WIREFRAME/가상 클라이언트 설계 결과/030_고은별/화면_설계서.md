## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 출시 전 경험 QA·릴리스 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입, 핵심 화면에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: CATEGORY-001, BRAND-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 출시 전 경험 QA·릴리스 기준 상품 후보 탐색
- 진입: MAIN-001
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 빈 상태·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 출시 전 경험 QA·릴리스 근거 구분
- 진입: MAIN-001
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 이동: CATEGORY-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-001 출시 검증
- 목적: 출시 전 경험 QA·릴리스 핵심 과업
- 진입: CATEGORY-001
- 구성: 여정 체크리스트, 결함 상태표
- 행동: 결함·재검증 상태 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-002, CATEGORY-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-002 결함·재검증 상태
- 목적: 출시 전 경험 QA·릴리스 검증 상태와 결과 확인
- 진입: TASK-001
- 구성: 근거·기준일, 상태·조건, 다음 행동·복구

- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

## 유효성·오류·접근성
오류마다 재시도·수정·이전 단계를 제공한다. 44px 조작 영역, 보이는 포커스, 이미지 대체 텍스트, 색상 외 상태 문구를 적용한다.

- **VC030-REQ-001**: 핵심 여정·직접 진입·복귀 경로의 출시 체크리스트 운영
- **VC030-REQ-002**: 기본·로딩·빈 상태·오류·완료·미확정 상태 검증
- **VC030-REQ-003**: 콘텐츠·정책·CTA의 승인 버전 일치 확인
- **VC030-REQ-004**: 320px·200% 확대·키보드·느린 연결 후보 검증
- **VC030-REQ-005**: 결함 심각도·소유자·재현·재검증 이력 기록
- **VC030-REQ-006**: 미실행 테스트·중대 결함·미확정 정책의 출시 승인 금지
