# 가상클라이언트 기반 분석 결과 — VC-015 (문지호)

## 1. 가상 클라이언트
- **프로젝트 주제**: 모바일 성능과 안정성 관점에서 YOVIA 리서치 사이트를 분석한다.
- **제작 목적**: 느린 모바일 환경에서도 핵심 제품 정의·기본 탐색·CTA가 먼저 작동하고 미디어 실패 시 대체 경로를 제공한다.
- **제공 자료**: `SRC-BRAND-001`, `SRC-REF-001~003`, `EVD-0028`; dead 3개를 제외한 유효 리서치 197개.
- **적용 매체**: 모바일 우선 반응형 웹.

## 4. 내비게이션
- **시작 화면**: 핵심 제품 정의와 기본 탐색을 미디어보다 먼저 사용할 수 있게 한다. (VC015-REQ-001~002; SITE-006, SITE-015)
- **이동 경로**: 핵심 텍스트 확인 → 제품 이미지·사용법 → CTA → 외부 연결, 실패 시 재시도·대체 경로. (VC015-REQ-001~005; SITE-006, SITE-015, SITE-077)
- **연결 페이지**: 각 상태와 행동을 해당 제품·검증 정보에 연결하며 종료·오류 시 이전 유효 화면 또는 상시 정보로 복귀한다. (VC015-REQ-003~005; SITE-015, SITE-077)
- **검색 및 위치 안내**: 현재 위치와 상태는 텍스트로 병기한다. 전체 검색은 실제 문서량과 운영 체계가 확정된 뒤 검토한다. (VC015-REQ-003~005; SITE-006, SITE-077)

## 5. 화면 구성
- **헤더**: 현재 제품과 주요 탐색 맥락을 유지하면서 `제품`, `사용법`, `구매 안내`, `오류·복구` 접근 후보를 제공한다. (VC015-REQ-001~002; SITE-006, SITE-015)
- **내비게이션**: 현재 제품·조건·상태를 잃지 않고 이전 단계와 관련 정보로 이동하도록 한다. (VC015-REQ-004~005; SITE-015, SITE-077)
- **핵심 콘텐츠**: 핵심 제품 정의, 우선 로드 자산, 기본 탐색과 명확한 CTA. (VC015-REQ-001~003; SITE-006, SITE-015, SITE-077)
- **보조 콘텐츠**: 출처·기준일·적용 범위·미확정 상태와 오류·복귀 안내. (VC015-REQ-003~005; SITE-015, SITE-077)
- **푸터**: 정책·문의·운영 책임이 실제로 확정된 항목만 연결한다. (VC015-REQ-006; SITE-006)

## 6. 검토 결과
- **누락 항목**: 실측 성능, 대상 기기·네트워크, 이미지 규격, 미디어·외부 연결 실패 기준.
- **중복 항목**: 목적이 같은 정보는 묶되 여섯 Requirement의 조건·상태·행동은 독립적으로 유지했다. 다른 Client 결과를 근거로 사용하지 않았다.
- **사용자 관점의 개선점**: 느린 연결이나 이미지 실패 상황에서도 제품 이해와 기본 탐색이 중단되지 않아야 한다.
- **수정 사항**: 지정 양식에 따라 일반화된 분류명과 반복 문장을 클라이언트별 MENU·CONTENT·FUNCTION, 내비게이션, 화면 구성, 검토 항목으로 다시 작성했다.
- **보류·충돌·근거 부족**: 실측 전 성능 등급·속도 개선 수치와 복합 모션 효과는 `NOT_VERIFIED/HOLD`다.
- **검증 결론**: 조건부 완료. 모든 Requirement를 정보 구조와 화면 후보에 연결했으며 미확정 운영 정보는 확정하지 않았다.
