# VC-021 김서준 — 검색 유입·콘텐츠 발견성 분석 결과

## 1. 분석 개요

- 가상 클라이언트: 김서준 / 검색 유입·콘텐츠 발견성 책임자
- 분석 목표: 외부 검색이나 공유 링크로 개별 페이지에 바로 진입한 사용자가 질문의 답을 즉시 확인하고, 검증된 관련 정보로 이동하도록 정보 구조를 정의한다.
- 근거: `VC021-REQ-001~006`, `EVD-0034`, `SRC-BRAND-001`, `SRC-REF-001`, `SRC-REF-003`
- 리서치 범위: 수집 200건 중 completed 101건과 partial 96건, 총 197건을 후보로 사용하고 dead 3건은 제외했다. 누적 분석 70건의 통계를 전체로 확대 해석하지 않는다.
- 핵심 관찰 대상: SITE-001, SITE-002, SITE-006, SITE-012, SITE-015, SITE-017, SITE-077

## 2. 브랜드·사용자·목표 해석

YOVIA는 그릭요거트를 기반으로 바쁜 일상에서도 간편하게 건강한 식습관을 이어가도록 돕는 간편 건강식 브랜드다. 핵심 사용자는 브랜드명, 그릭요거트, 무가당, 락토프리, 간편 아침 등의 질문으로 검색한 뒤 홈이 아닌 상세 URL에 직접 들어오는 첫 방문자다.

사용자의 우선 목표는 `검색 질문 확인 → 한 문장 답변 → 제품·사용법·원료·검증 근거 확인 → 관련 정보 이동`이다. 구매 경로, 가격, 재고, 리뷰, 효능은 확정 자료가 없으므로 설계에서 활성화하거나 검색 노출 정보로 만들지 않는다.

## 3. 레퍼런스 분석

| 관찰 축 | 참고 Site | 적용 판단 |
|---|---|---|
| 페이지 첫 제목과 질문의 일치 | SITE-001, SITE-002, SITE-017 | 페이지마다 하나의 질문과 한 문장 답을 상단에 둔다. |
| 제품·사용법·성분의 분리 | SITE-001, SITE-012, SITE-017 | 서로 다른 탐색 목적을 가진 독립 페이지로 두고 맥락 링크로 연결한다. |
| 모바일 직접 진입 맥락 | SITE-006, SITE-015, SITE-077 | 브랜드명, 현재 위치, 페이지 목적이 첫 화면에서 유지되어야 한다. |
| 신뢰 정보의 상태 표현 | SITE-012, SITE-017 | 확인됨·준비 중을 텍스트 라벨로 표시한다. |

레퍼런스의 구체 카피나 기능을 그대로 복제하지 않는다. 검색 수요, URL 정책, 구조화 데이터 유형은 아직 검증되지 않았으므로 후보 설계로만 다룬다.

## 6. 최종 설계 방향

- 핵심 흐름: 외부 검색 → 검색 유입 랜딩 또는 상세 직접 진입 → 한 문장 답 → 상세 근거 → 관련 정보 → 다음 행동 확인.
- 필수 화면군: 홈, 검색 유입 랜딩, 제품 정보 허브·상세, 사용법, 원료·성분, 검증 정보, 관련 콘텐츠, 페이지 안내, 다음 행동, 결과 확인, 예외 상태.
- 로그인은 현재 요구사항에 없으므로 흐름도 필수 분기를 충족하기 위한 `가정`으로만 표시하며, 정보 열람을 막지 않는다.
- 입력 기능 역시 확정되지 않았으므로 입력 오류 화면은 `가정`인 알림 신청 흐름에만 연결한다.
- 성공 기준: 사용자가 어느 URL로 들어오더라도 현재 페이지의 질문과 답, YOVIA 맥락, 다음 관련 페이지를 찾을 수 있다.
- 공개 금지: 확정되지 않은 가격·재고·리뷰·효능 및 이를 포함한 검색 노출 데이터.
