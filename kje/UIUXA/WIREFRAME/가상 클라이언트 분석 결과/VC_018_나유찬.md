## 4. 내비게이션
- **시작 화면**: 캠페인과 상시 제품 경험 연결에 필요한 핵심 상태와 행동을 제품 맥락 안에서 제시하는 후보.
- **이동 경로**: 유입 약속→제품 근거→조건·상태→다음 행동.
- **연결 페이지**: 제품·검증 정보와 관련 행동 사이를 왕복하며 종료·오류 시 상시 정보로 복귀한다.
- **검색 및 위치 안내**: 전체 검색은 문서량과 운영 체계가 확정된 뒤 검토하며 현재 위치와 상태는 텍스트로 병기한다.

## 5. 화면 구성
- **헤더**: 제품 탐색을 유지하면서 캠페인, 제품, 이용 조건 접근 후보를 제공한다.
- **내비게이션**: 현재 제품·지역·상태 맥락을 잃지 않는 이동 후보.
- **핵심 콘텐츠**: 캠페인과 상시 제품 경험 연결에 필요한 사실, 조건, 상태, 다음 행동.
- **보조 콘텐츠**: 근거·기준일·관련 자료·복구 경로.
- **푸터**: 정책·문의·운영 책임이 확정된 항목만 연결한다.

## 6. 검토 결과
- **누락 항목**: 실제 제품 데이터, 운영 정책, 책임자, 시스템 사양과 사용자 테스트.
- **중복 항목**: 기존 VC-001~010과 공유되는 명확성·모바일·접근성 원칙은 유지하되 캠페인과 상시 제품 경험 연결의 운영 판단은 독립적으로 보존했다.
- **사용자 관점의 개선점**: 기능을 먼저 확정하지 않고 사용자 질문과 상태를 기준으로 정보와 행동을 연결해야 한다.
- **수정 사항**: 200개 조사 중 dead 3개를 제외한 197개를 유효 후보로 계산했으며 completed 101과 partial 96의 관찰 범위를 구분한다.
- **보류·충돌·근거 부족**: 각 Hold 요구는 관련 정책·데이터·시스템 승인 전 `NOT_VERIFIED`로 유지한다.
- **검증 결론**: 조건부 완료. MENU / CONTENT / FUNCTION 후보가 Requirement ID와 대표 Site ID에 연결됨.
