## 4. 내비게이션

- **시작 화면**: 메인페이지 또는 표시 정보 관련 직접 진입 후보
- **이동 경로**: 메인페이지 → 카테고리 → 상품 후보 → 표시 정보 확인 → 문구 승인 상태 → 결과 확인·이전 단계
- **연결 페이지**: 브랜드 소개, 카테고리, 표시 정보 확인, 문구 승인 상태
- **검색 및 위치 안내**: 현재 위치와 상태를 텍스트로 표시하며 최종 GNB·URL은 확정하지 않음

## 5. 화면 구성

- **핵심 콘텐츠**: YOVIA 정의, 식품 표시·광고 준법 핵심 조건, 근거·기준일·상태
- **보조 콘텐츠**: 관련 제품 탐색, 주의·미확정·HOLD 설명
- **기능 후보**: 필수 표시 표·승인 상태 패널, 재시도, 이전 단계, 홈 복귀
- **반응형 후보**: 모바일에서 핵심 조건→상태→행동 순서 유지
- **접근성 후보**: 색상 외 상태 텍스트, 키보드 포커스, 44px 조작 영역, 라이브 오류 안내

- **MENU**: 메인, 카테고리, 브랜드 소개, 표시 정보 후보

- **FUNCTION**: 필수 표시 표·승인 상태 패널, 상태 확인, 오류 복구, 조건부 다음 행동
