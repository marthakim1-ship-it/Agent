MENU 후보는 `표시 정보`, `주장 승인`, `주의사항`, `승인 이력`, `모바일 표시`, `검증 상태`의 6개다. CONTENT 후보는 제품 요약과 법정 표시 원문, 표현별 승인 상태와 적용 범위, 주요 흐름에 노출할 필수 주의사항, 출처·기준일·버전·승인자, 항목명·값·단위의 모바일 관계, 승인 없는 수치·인증·효능·비교 우위이다. FUNCTION 후보는 요약·원문 연결, 승인 상태 패널, 상시 주의 요약, 버전·승인 이력, 반응형 표시표, 미승인 문구 차단이다. 이는 최종 사이트맵·화면 배치·구현 사양이 아니라 Client 요구에서 도출한 후보다.

## 4. 내비게이션

- **시작 화면**: 메인페이지 또는 표시 정보 관련 직접 진입 후보 (VC022-REQ-001~002; SITE-001, SITE-003)
- **이동 경로**: 메인페이지 → 카테고리 → 상품 후보 → 표시 정보 확인 → 문구 승인 상태 → 결과 확인·이전 단계 (VC022-REQ-001~005; SITE-001, SITE-003, SITE-008)
- **연결 페이지**: 브랜드 소개, 카테고리, 표시 정보 확인, 문구 승인 상태 (VC022-REQ-003~005; SITE-003, SITE-008)
- **검색 및 위치 안내**: 현재 위치와 상태를 텍스트로 표시하며 최종 GNB·URL은 확정하지 않음 (VC022-REQ-003~005; SITE-001, SITE-008)

## 5. 화면 구성

- **헤더**: 브랜드와 제품 정보에서 표시 정보로 진입하는 후보를 제공하되 승인되지 않은 건강·영양 표현을 강조하지 않는다. (VC022-REQ-001~002; SITE-001, SITE-003)
- **내비게이션**: 표시 항목명·값·단위·승인 상태의 관계를 모바일에서도 유지하고 현재 위치를 텍스트로 안내한다. (VC022-REQ-004~005; SITE-003, SITE-008)
- **핵심 콘텐츠**: YOVIA 정의, 식품 표시·광고 준법 핵심 조건, 근거·기준일·상태 (VC022-REQ-001~003; SITE-001, SITE-003, SITE-008)
- **보조 콘텐츠**: 법정 표시 원문, 문구 승인 이력, 필수 주의와 미승인 표현 상태. (VC022-REQ-003~005; SITE-003, SITE-008)
- **푸터**: 법정 고지와 정책 문서는 승인된 원문과 버전이 확보된 경우에만 연결한다. (VC022-REQ-006; SITE-001)

## 6. 검토 결과

- **누락 항목**: 실제 법정 표시 원문, 문구별 출처·기준일·버전·승인자와 모바일 표시 기준이 필요하다.
- **중복 항목**: 표시 원문과 요약의 역할을 구분하고 여섯 Requirement를 표시 정보와 승인 상태로 묶었다.
- **사용자 관점의 개선점**: 핵심 요약에서 법정 원문과 주의사항으로 바로 이동하고 문구의 적용 범위를 오해하지 않아야 한다.
- **수정 사항**: MENU는 메인·카테고리·브랜드 소개·표시 정보, CONTENT는 준법 조건·근거·상태, FUNCTION은 필수 표시 표·승인 상태 패널 후보로 정리했다. 유효 리서치 197개를 기준으로 failed/dead 자료를 정상 근거에서 제외했다.
- **보류·충돌·근거 부족**: 실제 상품·수치·인증·효능·비교 우위는 `NOT_VERIFIED/HOLD`다.
- **검증 결론**: 조건부 완료. 승인 자료가 없는 표시·광고 문구는 공개 후보로 확정하지 않는다.
