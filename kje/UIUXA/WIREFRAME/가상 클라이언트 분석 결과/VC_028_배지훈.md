## 4. 내비게이션

- **시작 화면**: 메인페이지 또는 주문 지원 관련 직접 진입 후보
- **이동 경로**: 메인페이지 → 카테고리 → 상품 후보 → 문제 유형 확인 → 처리 상태 확인 → 결과 확인·이전 단계
- **연결 페이지**: 브랜드 소개, 카테고리, 문제 유형 확인, 처리 상태 확인
- **검색 및 위치 안내**: 현재 위치와 상태를 텍스트로 표시하며 최종 GNB·URL은 확정하지 않음

- **핵심 콘텐츠**: YOVIA 정의, 주문 후 문제 해결 핵심 조건, 근거·기준일·상태

- **반응형 후보**: 모바일에서 핵심 조건→상태→행동 순서 유지
