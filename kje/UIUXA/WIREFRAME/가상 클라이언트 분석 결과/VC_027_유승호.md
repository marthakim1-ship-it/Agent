- **시작 화면**: 메인페이지 또는 후기 관련 직접 진입 후보
- **이동 경로**: 메인페이지 → 카테고리 → 상품 후보 → 후기 맥락 확인 → 신고·정정 상태 → 결과 확인·이전 단계

- **검색 및 위치 안내**: 현재 위치와 상태를 텍스트로 표시하며 최종 GNB·URL은 확정하지 않음
