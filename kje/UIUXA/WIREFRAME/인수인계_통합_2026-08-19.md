# YOVIA UI/UX 작업 통합 인수인계

- 작성일: 2026-08-19
- 작업 루트: `kje/UIUXA/WIREFRAME/`
- 현재 핵심 범위: 메인페이지, 브랜드 소개 페이지, 제품 카테고리 페이지, 로고 시안
- 기준 가상 클라이언트: VC-001 서하린

## 1. 현재 결론

외부 공유용으로 우선 사용할 조합은 아래 2차 세트다.

```text
스토리보드 결과/
├─ 메인페이지_스토리보드_2차.html
├─ 브랜드소개페이지_스토리보드_2차.html
└─ 카테고리페이지_스토리보드_2차.html
```

세 HTML은 같은 폴더에 있을 때 어느 파일을 먼저 열어도 서로 이동할 수 있다. CSS와 JavaScript가 각 HTML 내부에 포함되어 있으므로 외부 공유 시 위 HTML 3개만 같은 폴더에 넣어 ZIP으로 전달하면 된다. 파일명을 변경하거나 서로 다른 폴더로 나누면 상대경로 이동이 끊긴다.

권장 시작 파일:

```text
메인페이지_스토리보드_2차.html
```

## 2. 2차 세트 연결 상태

세 페이지 모두 아래 매핑을 사용한다.

```text
P-001 → 메인페이지_스토리보드_2차.html
P-005 → 브랜드소개페이지_스토리보드_2차.html
P-006 → 카테고리페이지_스토리보드_2차.html
```

연결 위치:

- 공통 헤더 내비게이션
- 히어로 및 본문 CTA
- 상품 카드의 카테고리 이동 버튼
- 페이지 하단 CTA
- 푸터 탐색 메뉴

기존의 화면 이동 안내 `alert`는 제거하고 실제 `location.href` 이동으로 교체했다.

유지된 인터랙션:

- 메인 2차: 상품 슬라이드와 반응형 노출 수
- 카테고리 2차: 그룹 필터, 결과 수 안내, 최대 3개 상품 비교 모달
- 브랜드 2차: 페이지 간 실제 이동

## 3. 전체 스토리보드 시안 현황

### 메인페이지

```text
메인페이지_스토리보드.html
메인페이지_스토리보드_2차.html
메인페이지_스토리보드_3차.html
메인페이지_스토리보드_4차.html
```

- 2차: 외부 공유용 2차 세트에 연결됨.
- 3차: 그릭요거트 베이스 중심 디자인.
- 4차: Daily Schedule System 콘셉트, 상품 슬라이드 포함.
- 각 HTML에 대응하는 설계 설명 MD가 같은 폴더에 있다.

### 브랜드 소개 페이지

```text
브랜드소개페이지_스토리보드.html
브랜드소개페이지_스토리보드_2차.html
```

- 2차가 현재 선택본이다.
- 현재 브랜드 2차의 링크는 메인 2차·카테고리 2차로 연결된다.

### 카테고리페이지

```text
카테고리페이지_스토리보드.html
카테고리페이지_스토리보드_2차.html
카테고리페이지_스토리보드_3차.html
```

- 2차: Product Library 콘셉트. 필터와 최대 3개 비교 기능 포함. 외부 공유용 2차 세트에 연결됨.
- 3차: Greek Yogurt Shelf 콘셉트. BASE → PUREE → TOPPING → SIGNATURE 선반 구조.
- 3차에는 520px 이상 스크롤할 때 우측 하단에 나타나는 `맨 위로 ↑` 버튼이 있다.
- 카테고리 3차의 상품 구성은 BASE 3, PUREE 5, TOPPING 3, SIGNATURE 4로 총 15개다.
- 각 HTML에 대응하는 설계 설명 MD가 같은 폴더에 있다.

## 4. 시안 연결 관련 주의

이전에 메인 4차·브랜드 2차·카테고리 3차를 연결했으나, 이후 사용자의 요청으로 브랜드 2차가 2차 세트에 연결되도록 변경됐다.

따라서 현재 상태는 다음과 같다.

```text
정상 완결 세트: 메인 2차 ↔ 브랜드 2차 ↔ 카테고리 2차

메인 4차 → 브랜드 2차 또는 카테고리 3차
카테고리 3차 → 브랜드 2차 또는 메인 4차
브랜드 2차 → 메인 2차 또는 카테고리 2차
```

즉, 메인 4차·브랜드 2차·카테고리 3차 조합은 현재 완전한 순환 세트가 아니다. 이 조합도 별도로 완결해야 한다면 브랜드 2차를 복제해 전용 파일을 만들거나, 쿼리 파라미터/공통 라우터를 도입해야 한다. 현재 선택본인 브랜드 2차를 임의로 다시 4차·3차에 연결하면 2차 세트가 깨진다.

## 5. 디자인 및 리서치 적용 원칙

- 모든 최근 시안은 흑백 스토리보드로 제작했다.
- 200개 레퍼런스 분석에서 반복 관찰된 제품 중심 히어로, 상품·맛 그룹화, 카드·필터, 사용 단계, 수치·배지, 모바일 흐름 등을 페이지별로 선별 적용했다.
- 카테고리 3차는 일반 커머스보다 그릭요거트 직접 레퍼런스를 우선했다.
- 직접 참고한 브랜드군: Chobani, Fage, Siggi’s, Noosa, Ellenos, Oikos, Icelandic Provisions, Painterland Sisters, Culina Yogurt.
- 레퍼런스를 그대로 복제하지 않고 YOVIA의 확인된 제품 구조와 정보 상태에 맞춰 재구성했다.
- 미확정 가격, 판매, 원료, 영양, 알레르기, 인증, 건강 효능은 확정 정보처럼 표시하지 않는다.

## 6. 상품 정보 기준

카테고리 상품 슬롯은 `PRODUCT-001`~`PRODUCT-015` 총 15개다. 이는 디자인·기획 슬롯이며 실제 출시 상품 15종 확정을 뜻하지 않는다.

```text
기본 팩: PRODUCT-001~003
퓨레: PRODUCT-004~008
토핑: PRODUCT-009~011
시그니처·스타터: PRODUCT-012~015
```

정보 상태:

- `CONFIRMED`: 기획 자료에서 확인된 명칭·용량 등
- `PROPOSAL`: 시그니처 조합 등 제안 상태
- `HOLD`: 공식 자료 확보 전인 맛, 원료, 영양, 가격, 판매 정보 등

## 7. 로고 작업 현황

로고 작업 기준 문서:

```text
로고/logo.md
```

입력 초안:

```text
로고/input/로고 초안11.jpeg
로고/input/로고 초안12.jpeg
로고/input/로고 초안13.jpeg
```

주요 생성 결과:

```text
로고/output/로고_초안11_시안01.png
로고/output/로고_초안11_시안02.png
로고/output/로고_초안11_시안03.png
로고/output/로고_초안12_13_결합시안01.png
로고/output/로고_초안12_13_결합시안02.png
로고/output/로고_초안12_13_결합시안03.png
```

- 투명 배경이 아니라 흰 배경으로 생성했다.
- `로고_초안12_13_결합시안02` 선택 내용은 `로고/output/flow.md`에 기록했다.
- Pinterest 유사 로고 조사 이미지와 분석 자료도 `로고/output/`, `로고/md파일/`에 있다.
- 로고 관련 파일은 현재 작업 트리에 커밋되지 않은 파일이 다수 있으므로 삭제·일괄정리하지 않는다.

## 8. 검증된 사항

### 2차 연결 세트

- 세 파일 모두 P-001, P-005, P-006 매핑 존재
- 세 파일 모두 실제 `location.href` 이동 사용
- 이전 이동 안내 alert 없음
- 메인 슬라이드 유지
- 카테고리 필터·비교 유지
- `git diff --check` 통과

### 카테고리 3차

- 상품 15개, 고유 ID 15개
- ID 범위 PRODUCT-001~015
- 선반 수 3·5·3·4
- 흑백 표현 유지
- 모바일·태블릿 반응형 정의
- 섹션 바로가기와 상단 이동 버튼 동작 정의
- `git diff --check` 통과

## 9. 외부 공유 방법

1. 새 폴더에 2차 HTML 3개를 복사한다.
2. 세 파일명을 변경하지 않는다.
3. 폴더를 ZIP으로 압축한다.
4. 상대방에게 압축 해제 후 `메인페이지_스토리보드_2차.html`을 열도록 안내한다.
5. 브랜드나 카테고리 파일부터 열어도 나머지 페이지로 이동할 수 있다.

외부 서버는 필요 없다. 일반 브라우저에서 로컬 HTML로 열 수 있다.

## 10. 작업 트리 및 보존 규칙

- 기존 시안은 덮어쓰거나 삭제하지 않는다.
- 현재 여러 HTML·MD·로고 이미지가 미추적 또는 수정 상태다.
- 사용자 작업과 이번 작업이 혼재하므로 일괄 초기화, `git reset --hard`, 재귀 삭제를 하지 않는다.
- 커밋 또는 푸시는 사용자가 명시적으로 요청할 때만 한다.
- 새 시안은 `_3차`, `_4차`처럼 별도 파일로 보존한다.

## 11. 다음 작업 권장

우선순위는 사용자 선택에 따라 아래 중 하나다.

1. 외부 공유용 2차 세트를 브라우저에서 직접 클릭 점검하고 ZIP 패키지 제작
2. 메인 4차·브랜드 2차·카테고리 3차용 브랜드 페이지 복제본을 만들어 별도 완결 세트 구성
3. 카테고리 2차에도 3차와 동일한 `맨 위로` 버튼 적용
4. 실제 로고·제품 이미지 확정 후 흑백 플레이스홀더 교체
5. 미확정 상품명, 원료, 영양, 가격, 판매 정책 확보 후 HOLD 영역 업데이트

## 12. 재개 위치

외부 공유본을 다듬는다면 아래 파일부터 연다.

```text
스토리보드 결과/메인페이지_스토리보드_2차.html
```

최신 실험 시안을 이어가려면 아래 파일들을 함께 검토한다.

```text
스토리보드 결과/메인페이지_스토리보드_4차.html
스토리보드 결과/브랜드소개페이지_스토리보드_2차.html
스토리보드 결과/카테고리페이지_스토리보드_3차.html
```

단, 이 최신 실험 조합은 4절에 적은 것처럼 현재 브랜드 2차의 링크 목적지가 2차 세트이므로 별도 연결 설계가 필요하다.
