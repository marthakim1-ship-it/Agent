# YOVIA 브랜드 소개 스토리보드 2차 — Brand Manifesto

- 화면 ID: `P-005-C02`
- 상태: 기존 브랜드 소개와 비교하는 2차 후보
- 표현 조건: 흑백·회색
- 입력: YOVIA 브랜드 정본, 200개 레퍼런스 분석, `VC_001 서하린`
- 핵심 목표: 왜 필요한 브랜드인지 이해 → 브랜드 가치와 제품 경험 연결 → 제품 카테고리 이동
- 제외: 가상 창업자·연혁·성과·수상·고객 사례, 미검증 효능·수치·인증

## 1. 콘셉트

`건강한 선택이 번거롭지 않도록`이라는 문제 해결형 브랜드 선언문으로 구성한다.

기존 페이지가 정의·배경·미션·가치의 일반적인 순서였다면 2차는 다음 이야기 흐름을 사용한다.

`브랜드 선언 → 고객의 간극 → Before/After → 가치 기준 → 제품 경험 → 핵심 고객 → 근거 상태 → 제품 CTA`

YOVIA의 O 형태는 공식 이름의 어원이 아니라 그릭요거트 볼과 통합 경험을 보여주는 시각 프레임으로만 사용한다.

## 3. 브랜드 정본 적용

### 확정 정보

- YOVIA는 그릭요거트 기반 간편 건강식 브랜드다.
- 바쁜 일상에서 건강한 식습관을 이어가도록 돕는다.
- 핵심 타깃은 시간 부족을 경험하는 20~30대 직장인·대학생이다.
- 파우치·빌트인 스푼·토핑을 포함한 올인원 취식 경험을 지향한다.
- Convenience, All-in-One, Healthy Routine, Clarity를 핵심 가치로 사용한다.

### 표현 제한

- O를 공식 브랜드명 의미나 어원으로 설명하지 않는다.
- 공식 미션 문구가 확정된 것처럼 표현하지 않는다.
- 락토프리·무가당은 방향과 실제 표시 근거를 구분한다.
- 세부 패키지 기술·친환경 소재·효능은 시험·인증 전 HOLD다.
- 실제 출시·성과·고객·파트너 정보는 생성하지 않는다.

## 6. 반응형

- 데스크톱: 히어로 2열, Before/Direction 3열 구조, 가치 4열, 고객 3열, 푸터 3열
- 태블릿: 가치 2열, 푸터 브랜드 영역 전체 폭
- 모바일: 전 영역 1열, 문제 행과 근거 상태를 2행으로 전환
- 모든 버튼 최소 높이 46px

## 7. 기존 시안과 차이

| 항목 | 기존 브랜드 소개 | 2차 |
|---|---|---|
| 서사 | 정의·배경·미션·가치 나열 | 문제 → 전환 → 가치 → 제품 경험의 선언문 |
| 히어로 | 설명과 이미지 플레이스홀더 | 초대형 선언과 O형 제품 경험 프레임 |
| 가치 | 일반 카드 | 번호와 명암이 다른 4개 기준 카드 |
| 차별점 | 설명 문단 | 패키지 구조 이미지와 세 경험 단계 |
| 신뢰 | 단일 보류 패널 | 항목별 CONFIRMED·VERIFY·HOLD |
| 푸터 | 상태 안내와 홈 버튼 | 브랜드 정의·재탐색·프로젝트 상태 3열 |

## 8. 검증 기준

- 기존 브랜드 소개 HTML·MD를 덮어쓰지 않는다.
- CSS 색상은 무채색만 사용한다.
- 이동 대상은 `P-001`, `P-005`, `P-006`만 사용한다.
- YOVIA 브랜드 정의는 정본 문구와 의미가 일치해야 한다.
- 공식 어원·연혁·성과·수치·인증을 생성하지 않는다.
- O형 그래픽은 장식적 프레임임을 문서와 화면에 표시한다.
