YOVIA 2차 스토리보드 실질 보완 메모

작성일: 2026-08-21
기준: 기존 외부 공유용 2차 세트
원본 보존: 기존 "스토리보드 결과" 폴더의 2차 HTML은 수정하지 않음

[1. 공통 보완]

1) 페이지 내 빠른 탐색 추가
- 기존: 페이지가 길지만 원하는 영역으로 바로 이동하는 장치가 없었음.
- 보완: 헤더 아래에 화면별 영역 바로가기를 추가함.
- 차이: 메인은 제품 구성/대표 상품/사용 상황/정보 상태, 브랜드는 문제 정의/핵심 가치/제품 경험/근거 상태, 카테고리는 제품 목록/선택 비교/상태 안내/근거 정보로 즉시 이동할 수 있음.

2) 보완본과 정보 상태 표시 강화
- 기존: 하단 주석을 읽어야 시안의 제약을 파악할 수 있었음.
- 보완: 각 화면 상단에 보완본 성격과 미확정 정보를 알리는 배너을 배치함.
- 차이: 가격, 구매, 효능, 인증 등을 완성 정보로 오인할 가능성이 줄어듦.

3) 키보드 접근성 강화
- 기존: 버튼의 포커스 상태가 분명하지 않은 구간이 있었음.
- 보완: focus-visible 표시를 세 화면에 통일 적용함.
- 차이: Tab 키로 탐색할 때 현재 위치를 쉽게 알 수 있음.

4) 모션 감소 설정 대응
- 기존: 운영체제의 모션 감소 설정을 일관되게 반영하지 않았음.
- 보완: prefers-reduced-motion에서 스크롤·전환 효과를 즉시 처리하도록 조정함.
- 차이: 움직임에 민감한 사용자의 부담을 줄임.

5) 긴 페이지 복귀 기능 통일
- 기존: 메인 페이지에만 맨 위로 이동 기능이 있었음.
- 보완: 메인, 브랜드, 카테고리 전체에 스크롤 후 나타나는 맨 위로 버튼을 적용함.
- 차이: 긴 스토리보드 검토 후 상단 내비게이션으로 빠르게 복귀할 수 있음.

[2. 메인페이지 보완]

- 제품 구성, 상품 슬라이드, 사용 상황, 정보 상태 영역에 고유 이동 지점을 부여함.
- 상단에 CONFIRMED / PROPOSAL / HOLD 구분을 알려 상품·정책 정보의 완성도를 먼저 인지하게 함.
- 상품 슬라이드와 반응형 노출 수는 기존 동작을 유지함.

[3. 브랜드 소개 보완]

- 문제 정의, 핵심 가치, 제품 경험, 근거 상태를 바로 비교할 수 있게 함.
- 브랜드 서사와 검증 상태를 구분하여, 제안 문구를 공식 성과·효능으로 오인하지 않도록 상단 안내를 추가함.
- 메인·카테고리와 동일한 키보드 포커스, 모션 감소, 맨 위로 패턴을 적용함.

[4. 제품 카테고리 보완]

1) 비교 선택 피드백 강화
- 기존: 2개를 선택해야 비교가 가능하다는 조건이 버튼 비활성화로만 표시됨.
- 보완: 현재 선택 개수와 비교 가능 여부를 실시간 문장으로 표시함.

2) 선택 초기화 추가
- 기존: 상품을 하나씩 다시 해제해야 했음.
- 보완: "선택 초기화" 버튼을 추가하여 비교 상태를 한 번에 비울 수 있게 함.

3) 최대 선택 안내 방식 개선
- 기존: 4번째 상품을 선택하면 브라우저 alert가 흐름을 차단함.
- 보완: 페이지 내 aria-live 피드백으로 "최대 3개"를 알림.
- 차이: 사용 흐름이 끊기지 않고 보조기기에도 상태 변경이 전달됨.

4) 제품 탐색 구조 명확화
- 제품 목록, 선택 비교, 상태 안내, 근거 정보에 바로가기를 추가함.
- 필터·비교 모달·Esc 닫기·배경 클릭 닫기는 유지함.

[5. 변경하지 않은 핵심]

- 흑백 스토리보드 스타일
- 메인·브랜드·카테고리 상대경로 연결
- 메인 상품 슬라이드
- 카테고리 제품군 필터와 최대 3개 비교 모달
- 미확정 가격·판매·영양·인증·효능을 HOLD로 다루는 원칙
- 실제 상품 이미지와 최종 컬러 UI는 적용하지 않음

[6. 검토 방법]

1. 메인페이지_스토리보드_2차.html을 연다.
2. 헤더와 하단 CTA로 세 페이지를 순환한다.
3. 각 페이지의 영역 바로가기를 누른다.
4. Tab 키로 버튼·링크 포커스를 확인한다.
5. 카테고리에서 필터, 2~3개 선택, 비교, 선택 초기화를 확인한다.
6. 긴 페이지를 내린 후 맨 위로 버튼을 확인한다.

이 보완본은 기존 스토리보드를 다시 디자인한 최종 UI가 아니라, 현재 흑백 와이어프레임의 탐색·상태 피드백·접근성·검토 효율을 실질적으로 높인 버전이다.

[7. 2026-08-21 레퍼런스 기반 시각 디자인 추가 보완]

적용 레퍼런스 원칙
- SITE-001 Chobani: 제품군을 빠르게 탐색하는 카드·그룹 구조
- SITE-002 Fage, SITE-003 Siggi's: 절제된 타이포그래피와 짧은 상품 정보 위계
- SITE-004 Noosa, SITE-005 Ellenos: 제품 질감·패키지를 크게 보여주는 히어로와 비주얼 영역
- SITE-180 Culina Yogurt: 베이스·퓨레·토핑의 조합 맥락
- 200개 전체 분석: 제품 중심 히어로, 상품·맛 그룹화, 카드·필터, 사용 단계, 수치·배지, 모바일 우선 흐름

공통 시각 변경
- 기존의 평면적인 흰 배경과 사각 구획을 웜 오프화이트 배경, 검정 대비, 라운드 컨테이너 체계로 재구성함.
- 헤더를 검정 브랜드 바로 바꾸고 현재 페이지를 필 형태 라임 포인트로 구분함.
- 초기 시각 시안에 라임 포인트를 사용했으나, 흑백 조건에 맞지 않아 2026-08-21 즉시 제거함. 현재 결과물은 검정, 흰색, 중성 회색만 사용함.
- 영역 바로가기와 버튼을 필 형태로 통일하고, 섹션은 24~28px 라운드 컨테이너로 분리함.
- 신호·상태·핵심 제품 영역은 색상이 아닌 명도, 테두리, 타이포그래피, 패턴으로 구분함.

메인페이지 시각 변경
- 히어로를 검정 무대 안의 두 개 라운드 패널로 재구성함.
- 타이틀 크기와 줄 간격을 크게 조정해 제품 중심 히어로의 주목도를 높임.
- 패키지 플레이스홀더를 키우고 살짝 회전시켜 평면 스케치보다 제품 오브젝트에 가깝게 연출함.
- 상품 카드를 라운드 선반형 카드로 바꾸고, 제품군에 따라 비주얼 명암을 달리함.
- 제품 구성도에 강한 색면과 오프셋 그림자를 적용해 베이스·퓨레·토핑 관계를 강조함.

브랜드 소개 시각 변경
- 히어로를 타이포그래피 패널과 거대 원형 비주얼 패널로 분리함.
- 스토리 진행을 statement → problem → values → experience → evidence 순서의 에디토리얼 리듬으로 강조함.
- 핵심 가치 카드의 반복되는 사각 격자를 라운드 카드 세트로 바꾸고, 교차 색면으로 리듬을 부여함.
- 제품 경험, 근거, 다음 CTA를 독립 패널로 만들어 서사 단계가 쉽게 구분되도록 함.

카테고리페이지 시각 변경
- 히어로를 제품 인덱스 보드 형태로 재구성하고 첫 제품군에 포인트 색을 적용함.
- 필터를 화면 내 독립된 둥근 툴바로 바꾸어 상품 탐색 제어부를 분명하게 함.
- 상품 카드를 선반형 라운드 카드로 바꾸고, 팩·퓨레·토핑에 따라 비주얼 배경을 구분함.
- 카드 호버 시 살짝 올라오는 피드백과 검정 오프셋 그림자를 추가함.
- 비교, 상태 안내, 근거, 다음 CTA를 각각 독립 라운드 패널로 분리해 긴 카탈로그의 리듬을 개선함.

변경 전·후 핵심 차이
- 변경 전: 거의 모든 영역이 직선, 1px 테두리, 흰색·회색으로 구성되어 섹션 위계가 비슷했음.
- 변경 후: 검정 브랜드 바, 웜 배경, 라운드 패널, 크게 확대된 타이포그래피, 제품군별 색면, 제한된 포인트 색으로 영역 위계가 분명해짐.
- 변경 전: 카드와 영역이 스토리보드 박스에 가까웠음.
- 변경 후: 패키지·질감·선반 탐색을 연상시키는 편집 디자인으로 바뀌어 레퍼런스 반영이 눈에 보이도록 함.
