# YOVIA 2차 스토리보드 보완본

이 폴더는 기존 2차 스토리보드를 유지하면서 검토와 개발 전달에 필요한 부분을 보완한 별도 세트다. 원본 파일은 수정하지 않았다.

## 시작 파일

` 메인페이지_스토리보드_2차.html `을 먼저 연다. 세 HTML은 같은 폴더에 두어야 서로 이동한다.

## 화면 구성

| 화면 ID | 파일 | 주요 확인 항목 |
|---|---|---|
| P-001 | `메인페이지_스토리보드_2차.html` | 히어로, 제품 조합, 상품 슬라이드, 정보 상태 |
| P-005 | `브랜드소개페이지_스토리보드_2차.html` | 브랜드 문제 정의, 미션, 가치, 근거 상태 |
| P-006 | `카테고리페이지_스토리보드_2차.html` | 제품군 필터, 15개 설계 슬롯, 최대 3개 비교 모달 |

## 보완 내용

- 원본과 분리된 보완본 폴더 구성
- 세 페이지의 상대경로 이동 유지
- 키보드 포커스 표시 강화
- 사용자의 모션 감소 설정 반영
- 메인 페이지에 보완본·정보 상태 안내 추가
- 메인 페이지에 맨 위로 이동 버튼 추가
- 기존 슬라이드·필터·비교 모달 동작 유지

## 정보 상태 기준

- `CONFIRMED`: 현재 자료에서 확인된 정보
- `PROPOSAL`: 설계·기획 제안
- `VERIFY`: 추가 자료로 확인 필요
- `HOLD`: 효능, 인증, 영양, 가격, 판매 정책 등 미확정 정보

## 공유 전 확인

- 데스크톱·태블릿·모바일에서 헤더와 카드가 잘리지 않는지 확인
- 세 페이지의 헤더·CTA·푸터 이동 확인
- 키보드 `Tab`으로 주요 버튼을 순서대로 탐색할 수 있는지 확인
- 카테고리 필터, 2~3개 상품 비교, `Esc` 모달 닫기 확인
- 가격·구매·영양·인증 정보가 확정값처럼 보이지 않는지 확인

이 결과물은 클릭 가능한 와이어프레임 겸 스토리보드이며, 최종 컬러 UI와 운영 콘텐츠는 아니다.
