# YOVIA 카테고리 페이지 스토리보드 3차 — Greek Yogurt Shelf

- 화면 ID: `P-006-C03`
- 상태: 기존·2차 카테고리와 비교하는 3차 후보
- 표현 조건: 흑백·회색
- 중심 근거: 200개 전체 분석 중 그릭요거트·스키르 직접 레퍼런스군
- 상품 슬롯: PRODUCT-001~015, 총 15개
- 제외: 가격, 재고, 구매, 구독, 미검증 맛·원료·영양·건강 효능

## 1. 콘셉트

`그릭요거트 베이스 → 퓨레 → 토핑 → 시그니처 조합`을 실제 매장의 제품 선반처럼 탐색한다.

- 그릭요거트 볼과 질감 이미지로 카테고리 진입
- 기본 팩 3개를 가장 먼저 크게 표시
- 퓨레 5개와 토핑 3개는 조합 부품 선반으로 분리
- BASE → PUREE → TOPPING 관계 설명
- 시그니처 4개는 시간·상황 제안 선반으로 구성
- 영양 배지 대신 CONFIRMED·PROPOSAL·HOLD 상태 사용

## 7. 카테고리 시안 비교

| 시안 | 중심 구조 | 탐색 방식 |
|---|---|---|
| 기존 | 제품군별 일반 카드 | 그룹 필터와 카드 묶음 |
| 2차 | 제품 라이브러리 | 즉시 필터와 최대 3개 비교 |
| 3차 | 그릭요거트 제품 선반 | 베이스→퓨레→토핑→시그니처 순차 탐색 |

## 8. 검증 기준

- 기존·2차 카테고리 파일을 수정하지 않는다.
- PRODUCT-001~015가 각각 한 번 존재한다.
- BASE 3·PUREE 5·TOPPING 3·SIGNATURE 4가 정확하다.
- CSS는 무채색만 사용한다.
- 이동 대상은 `P-001`, `P-005`, `P-006`만 사용한다.
- 그릭요거트 질감·맛·영양은 공식 이미지와 제품 자료 전 확정하지 않는다.
