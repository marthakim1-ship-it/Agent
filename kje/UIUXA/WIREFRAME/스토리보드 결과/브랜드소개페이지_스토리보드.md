# YOVIA VC-001 서하린 — 브랜드소개페이지 스토리보드

- 입력 설계 폴더: `설계 출력물/`
- 브랜드소개 화면 ID: `P-005`
- 화면명: `브랜드 소개`
- 판정 근거: 사이트맵의 독립 2차 화면, 화면 설계서·JSON의 브랜드 이해 목적, 서비스 흐름의 직접 진입·종료 조건, 와이어프레임의 P-005 콘텐츠 영역이 모두 일치함
- 작성 기준: 사이트맵 / 서비스 흐름도 / 화면 설계서 / 화면 목록 / 와이어프레임
- 문서 상태: 후보
- 핵심 사용자: YOVIA를 처음 접한 바쁜 20~30대 직장인·대학생·취준생
- 핵심 목표: 브랜드의 정체성·출발점·미션·핵심 가치와 현재 검증 범위를 이해하고 제품 상세 또는 사용 안내로 이동
- 제외 범위: 로그인, 회원가입, 검색, 구매, 결제, 구독, 미확정 효능·인증·성과·연혁·창업자
