# YOVIA 카테고리 페이지 스토리보드 2차 — Product Library

- 화면 ID: `P-006-C02`
- 상태: 기존 카테고리 페이지와 비교하는 2차 후보
- 표현 조건: 흑백·회색
- 입력: 200개 레퍼런스 분석, `VC_001 서하린`, 기존 PRODUCT-001~015 슬롯
- 목표: 제품군 필터 → 상품 확인 → 최대 3개 상태 비교 → 브랜드 소개 이동
- 제외: 가격, 재고, 구매, 장바구니, 구독, 미검증 건강·친환경 효능

## 1. 콘셉트

15개 상품을 단순 카드 목록이 아니라 `제품 라이브러리`로 정리한다.

- PRODUCT ID와 번호를 주요 탐색 단서로 사용
- 팩·퓨레·토핑을 명암과 텍스트 라벨로 구분
- 전체·팩·퓨레·토핑 필터 제공
- 최대 3개 상품의 이름·제품군·기획 상태만 비교
- 확정·제안·HOLD 상태를 모든 카드에서 확인
- 가격·재고·구매는 비교표에서도 HOLD

## 6. 인터랙션

### 필터

- 선택된 필터는 `aria-pressed=true`
- 해당 제품군만 표시하고 결과 수를 라이브 영역으로 안내
- 필터 변경은 비교 선택을 제거하지 않음

### 비교

- 카드 체크박스로 최대 3개 선택
- 4번째 선택은 취소하고 최대 수량 안내
- 2개 이상 선택해야 비교 버튼 활성화
- 비교 항목은 제품명·제품군·기획 상태·가격/구매 HOLD
- Escape와 배경 클릭으로 모달 닫기

## 7. 반응형

- 데스크톱: 상품 3열, 비교 슬롯 3열, 상태 요약 4열
- 태블릿: 상품 2열, 비교 버튼 다음 행, 상태 요약 2열
- 모바일: 상품·비교 슬롯·상태 요약 모두 1열
- 모바일에서는 고정 필터를 해제해 화면을 가리지 않도록 함

## 8. 기존 시안과 차이

| 항목 | 기존 카테고리 | 2차 |
|---|---|---|
| 제품 탐색 | 그룹별 카드 묶음 | 전 상품 라이브러리와 즉시 필터 |
| 식별 | 상품명 중심 | PRODUCT ID·번호·상품명 |
| 비교 | 없음 | 최대 3개 제한 비교 |
| 상태 | 별도 상태 안내 | 모든 카드·비교표·안내에서 반복 |
| 모바일 | 그룹별 1열 | 필터 → 1열 → 비교 흐름 |
| 푸터 | 보류 상태 문구 | 카테고리 정의·탐색·정책 상태 3열 |

## 9. 검증 기준

- 기존 카테고리 HTML·MD를 덮어쓰지 않는다.
- CSS 색상은 무채색만 사용한다.
- PRODUCT-001~015가 각각 한 번씩 존재한다.
- 필터 결과는 전체 15·팩 7·퓨레 5·토핑 3과 일치한다.
- 비교는 최대 3개이며 확인된 필드만 사용한다.
- 이동 대상은 `P-001`, `P-005`, `P-006`만 사용한다.
- 가격·재고·구매·건강 효능을 생성하지 않는다.
