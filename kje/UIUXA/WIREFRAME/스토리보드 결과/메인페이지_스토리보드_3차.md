# YOVIA 메인페이지 스토리보드 3차 — Greek Yogurt Base

- 화면 ID: `P-001-C03`
- 상태: 1·2차 비교용 후보
- 표현 조건: 흑백·회색만 사용
- 핵심 콘셉트: 그릭요거트의 농도·질감·스푼 자국을 중심으로 전개
- 분석 기준: 200개 레퍼런스 중 유효 197개 + `VC_001 서하린`
- 기존 시안: 1·2차 모두 보존

## 1. 디자인 방향

3차는 패키지와 카드가 중심인 2차와 달리 `그릭요거트 베이스` 자체를 브랜드의 시작점으로 사용한다.

- 원형 볼, 소용돌이, 스푼 자국을 주요 형태 언어로 사용
- 크림색을 쓰지 않고 흰색·회색·검정의 농도 차이로 질감 표현
- 둥근 상단 상품 카드로 요거트 용기 연상
- 시간대 카드를 통해 그릭요거트와 일상 연결
- “꾸덕함”은 콘셉트 카피로만 사용하며 실제 품질 사실은 공식 자료 전 `not_verified`

### 핵심 참고 사이트

- `SITE-002 Fage`: 절제된 질감·신뢰 표현
- `SITE-003 Siggi's`: 제품과 정보의 간결한 위계
- `SITE-004 Noosa`: 맛과 요거트 질감 표현
- `SITE-005 Ellenos`: 디저트형 질감 연출
- `SITE-178 Painterland Sisters`: 원료·생산 배경의 신뢰
- `SITE-180 Culina Yogurt`: 맛별 원료와 사용 맥락

질감 패턴은 19/197로 전체 빈도는 낮다. 따라서 전체 구조를 질감 효과로 채우지 않고 히어로와 베이스 소개에만 사용한다.

## 5. 상품 표시 규칙

메인 표시 상품은 PRODUCT-001~003, PRODUCT-012~015의 7개다. 기본 팩은 용량과 기획서 명시 상태를 표시하고 시그니처·스타터는 제안 또는 기획 상태를 명확하게 쓴다. 전체 15개는 `P-006`으로 연결한다.

## 8. 검증 기준

- 1·2차 파일을 수정하거나 덮어쓰지 않는다.
- 모든 CSS 색상은 R·G·B가 동일한 무채색이다.
- 상품 카드는 정확히 7개다.
- 이동 대상은 `P-001`, `P-005`, `P-006`만 사용한다.
- 질감 시각은 플레이스홀더이며 실제 제품 사진으로 오인시키지 않는다.
- 원료·영양·알레르기·락토프리·무가당·가격·판매는 공식 자료 전 HOLD다.
- 푸터에 확인되지 않은 사업자·법무·고객지원·SNS를 생성하지 않는다.
