## 8. 접근성 요구사항

| 항목 | 요구사항 | 적용 영역 |
|---|---|---|
| 구조 | `header/nav/main/section/footer` 랜드마크와 H1→H2 제목 계층 | 전체 |
| 바로가기 | 첫 포커스 요소로 “본문으로 바로가기” 제공 | 헤더 |
| 대체 콘텐츠 | 정보 이미지·차트에 대체 텍스트/텍스트 요약; 장식 이미지는 빈 `alt` | 히어로, 통계, 제품, AI, 인포그래픽, 지도, 후기 |
| 키보드 | GNB, 메뉴, 카드, 슬라이더, 탭, 아코디언, CTA를 키보드만으로 사용 | 전체 인터랙션 |
| 포커스 | 배경과 구분되는 포커스 표시; Sticky UI가 포커스를 가리지 않음 | 전체 |
| 명도 대비 | 일반 텍스트 4.5:1, 큰 텍스트·UI 경계 3:1 이상 목표 | 전체 |
| 비색상 정보 | 자세 점수·상태를 숫자, 아이콘, 문구와 함께 전달 | AI, 오류·완료 상태 |
| 모션 | 자동 재생 최소화; 정지 제어; `prefers-reduced-motion` 대응 | 히어로, 수치, 게이지, 인포그래픽 |
| 터치 | 모바일 조작 영역 최소 44×44px, 요소 간 충분한 간격 | 헤더, 카드, CTA, 아코디언 |
| 오류 | 오류 문구와 입력을 프로그램적으로 연결; 오류 요약 후 첫 오류로 이동 | 검색, 신청·예약 연결 화면 |
| 확대·재배치 | 200% 확대 및 320px CSS 폭에서도 정보·기능 손실 없음 | 전체 |
| 동적 상태 | 중요한 변경은 적절한 라이브 영역으로 알리고 불필요한 반복 알림 금지 | AI, 센터 검색, 신청 상태 |
