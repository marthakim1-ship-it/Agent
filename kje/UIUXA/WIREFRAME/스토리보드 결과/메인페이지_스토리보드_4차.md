# YOVIA 메인페이지 스토리보드 4차 — Daily Schedule System

- 화면 ID: `P-001-C04`
- 상태: 1·2·3차 비교용 후보
- 표현 조건: 흑백·회색만 사용
- 중심 콘셉트: 하루 시간표와 모듈형 제품 인덱스
- 분석 기준: 200개 레퍼런스 중 유효 197개 + `VC_001 서하린`

## 1. 콘셉트

4차는 감성적인 식품 이미지보다 바쁜 사용자의 `하루 일정`을 중심 구조로 사용한다. 시간, 제품, 상황, 정보 상태를 카탈로그·시간표·티켓·장부 형식으로 정리한다.

- `07:30` 대형 시간 타이포로 고객 상황을 첫 장면에 제시
- 제품 대표 이미지는 티켓과 바코드 형태의 흑백 패키지 프레임에 배치
- 하루 일정표에서 시간·상황·관련 제품을 연결
- 상품을 번호·코드 기반 인덱스 카드로 탐색
- 제품 구조는 흑백 기술 도면처럼 설명
- 신뢰 정보는 데이터 장부 형식으로 구분

## 7. 검증 기준

- 1·2·3차 파일을 수정하지 않는다.
- CSS는 무채색만 사용한다.
- 상품 카드 수는 7개다.
- 이동 대상은 `P-001`, `P-005`, `P-006`만 허용한다.
- 시간은 사용 상황을 구분하는 시각 장치이며 취식 시간 효능으로 표현하지 않는다.
- 원료·영양·효능·가격·판매·사업 정보는 공식 자료 전 생성하지 않는다.
