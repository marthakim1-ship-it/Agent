# YOVIA VC-001 — 제품상세페이지 스토리보드

- 화면 ID: `P-002`
- 화면명: 제품 상세
- 문서 상태: 후보 설계
- 표시 방식: `PRODUCT-001`~`PRODUCT-015`를 한 화면에서 전환하는 단일 동적 상세
- 기본 상품: `PRODUCT-001`
- 목적: 카테고리에서 선택한 상품의 유형·기획 상태·확인된 구성을 살펴보고 HOLD 정보를 구분
- 제외: 가격, 할인, 재고, 구매, 장바구니, 구독, 미확정 이미지·원료·영양·알레르기·패키지 성능

## 상품 유형별 표시 규칙

| 범위 | 표시 정보 | 상태 |
|---|---|---|
| PRODUCT-001~003 | 기본 팩 명칭·중량 구분 | 기획서 명시, 세부 사양 HOLD |
| PRODUCT-004~008 | 퓨레 슬롯 번호·페어링 역할 | 실제 맛·원료 HOLD |
