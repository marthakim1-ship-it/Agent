# VC-022 이정민 — 식품 표시·광고 준법 스토리보드

## 1. 제작 기준

- 독립 입력: VC-022 분석 결과, 사이트맵, 서비스 흐름도, 화면 설계서
- 화면: MAIN-001, CATEGORY-001, BRAND-001, TASK-001, TASK-002
- 다른 Client 및 통합 스토리보드는 입력으로 사용하지 않음
- JavaScript 없이 HTML/CSS로 구현

## 2. 핵심 흐름

`MAIN-001 → CATEGORY-001 → 상품 후보 → TASK-001 표시 정보 확인 → TASK-002 문구 승인 상태 → 결과 확인 또는 복귀`

## 3. 화면별 설계

| 화면 ID | 화면명 | 핵심 목적 | VC-022 고유 영역 | 이동 |
|---|---|---|---|---|
| MAIN-001 | 메인페이지(홈) | 제품 탐색 전 표시 상태 인지 | 승인 상태 요약, 상품 15개 슬라이드 | CATEGORY-001, BRAND-001, TASK-001 |
| CATEGORY-001 | 카테고리 페이지 | 표시 상태 기준 상품 후보 탐색 | 승인·주의·자료 상태 필터 후보 | MAIN-001, TASK-001 |
| BRAND-001 | 브랜드 소개 페이지 | 브랜드 사실과 광고 표현 구분 | CONFIRMED/CANDIDATE/HOLD 경계 | MAIN-001, CATEGORY-001 |
| TASK-001 | 표시 정보 확인 | 요약과 표시 원문 연결 | 필수 표시 표, 주의사항, 출처 | CATEGORY-001, TASK-002 |
| TASK-002 | 문구 승인 상태 | 문구의 공개 가능 여부 확인 | 적용 범위·기준일·버전·승인자 | TASK-001, MAIN-001 |

## 4. 상품 슬라이드 계약

- PRODUCT-001~015를 하나의 가로 트랙에 모두 유지한다.
- 모바일 약 1개, 태블릿 약 2개, 데스크톱 약 3개와 다음 카드 일부를 노출한다.
- CSS `overflow-x:auto`와 `scroll-snap-type`을 사용한다.
- 터치·트랙패드·스크롤·키보드로 조작하며 JavaScript는 사용하지 않는다.
- 상품명·이미지·가격·영양·효능·재고는 `NOT_VERIFIED`다.

## 5. Requirement 반영

| Requirement | 반영 |
|---|---|
| VC022-REQ-001 | 요약과 표시 원문 연결 |
| VC022-REQ-002 | 건강·영양·무첨가 표현의 승인 상태·적용 범위 |
| VC022-REQ-003 | 필수 주의사항 상시 노출 |
| VC022-REQ-004 | 출처·기준일·버전·승인자 표 |
| VC022-REQ-005 | 모바일에서도 항목명·값·단위 관계 유지 |
| VC022-REQ-006 | 승인 없는 수치·인증·효능·비교 우위 HOLD |

## 6. 판정

**조건부 완료** — 화면과 검증 흐름은 설계했으나 실제 표시 원문·수치·인증·승인자는 미확정이다.
