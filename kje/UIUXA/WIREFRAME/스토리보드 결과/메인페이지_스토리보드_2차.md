- 화면명: 홈 2차 시안
- 시안 상태: 비교 검토용

## 1. 콘셉트 정의

`제품 구조와 섭취 순간을 연결하는 흑백 제품 에디토리얼`

컬러 대신 다음 요소로 시각 위계를 만든다.

- 제목과 숫자의 극단적인 크기 차이
- 검정 면과 흰 면의 대비
- 제품 인지 구간의 넓은 여백
- 상품 탐색 구간의 촘촘한 카드 리듬
- 비대칭 사용 상황 그리드
- 굵은 선, 점선, 원형·사각형의 구조도
- 대형 워드마크로 끝나는 브랜드 푸터

## 7. 1차와 2차의 차이

| 항목 | 1차 | 2차 |
|---|---|---|
| 색상 | 크림·라임·베리 후보 팔레트 | 순수 흑백·회색 |
| 히어로 | 둥근 컬러 분할 카드 | 화면 높이에 가까운 비대칭 에디토리얼 |
| 제품 구조 | 설명 문단 중심 | 베이스·퓨레·토핑 관계도와 3단계 |
| 상품 카드 | 둥근 컬러 카드 | 직선 테두리·큰 상품 번호 |
| 상황 영역 | 같은 크기의 3카드 | 크기와 명암이 다른 4개 비대칭 카드 |
| 신뢰 영역 | 단일 안내 패널 | 정보별 CONFIRMED·PROPOSAL·HOLD 표 |
| 푸터 | 컬러 도형과 슬로건 | 초대형 흑백 워드마크와 구조적 3열 |

## 8. 검증 기준

- HTML과 Markdown은 별도 2차 파일로 저장하며 1차를 덮어쓰지 않는다.
- CSS 색상은 무채색만 사용한다.
- 대표 상품은 정확히 7개다.
- 모든 화면 이동 요소는 `P-001`, `P-005`, `P-006`만 사용한다.
- 모바일에서 정의 → 구조 → 상품 → 상황 → 신뢰 → 행동 순서를 유지한다.
- 제품·영양·효능·가격·판매·사업 정보를 새로 만들지 않는다.
- 푸터 장식은 `aria-hidden`, 탐색은 명시적 `nav` 레이블을 사용한다.
