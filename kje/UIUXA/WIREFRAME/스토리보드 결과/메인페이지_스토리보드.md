# YOVIA VC-001 서하린 — 메인페이지 스토리보드

- **입력 설계 폴더**: `설계 출력물/`
- **메인 화면 ID**: `P-001`
- **메인 화면명**: 홈
- **메인페이지 판정 근거**: 사이트맵의 유일한 1차 화면, 기본 URL 진입 화면, 서비스 흐름 시작 화면
- **작성 기준**: 사이트맵 / 서비스 흐름도 / 화면 설계서 / 화면 목록 JSON / 와이어프레임 HTML
- **문서 상태**: 후보
- **핵심 사용자**: YOVIA를 처음 접하는 바쁜 20~30대 직장인·대학생
- **핵심 목표**: 제품 정체와 일상 편익 이해 → 대표 상품 슬라이드 탐색 → 필요한 정보 선택
- **제외 범위**: 제작 검토용 상태 도구, 로그인·회원가입·입력 폼·검색·구매·결제·구독, 제품 비교·판매처
