# YOVIA VC-001 서하린 — 메인페이지 스토리보드

- 화면 ID: `P-001`
- 화면명: 홈
- 문서 상태: 후보 설계
- 작업 범위: 메인페이지, 브랜드 소개, 제품 카테고리의 3개 화면
- 핵심 사용자: 바쁜 20~30대 직장인·대학생
- 핵심 목표: 제품 정체와 일상 편익 이해 → 대표 상품 탐색 → 브랜드 또는 제품 카테고리 이동
- 제외: 가격, 재고, 구매, 구독, 미검증 건강·영양·친환경 효능
- 주요 근거: `VC001-REQ-001`, `VC001-REQ-002`, `VC001-REQ-003`, `VC001-REQ-005`, `VC001-REQ-007`, `VC001-REQ-008`, `VC001-REQ-009`

## 상태·자료 보완

- 실제 제품·패키지 이미지가 없어 현재는 텍스트 플레이스홀더를 사용한다.
- 원료·영양·알레르기, 락토프리·무가당 표시 근거와 패키지 성능은 공식 자료 확보 후 반영한다.
- 가격·재고·구매·구독·판매처는 정책 확정 전 생성하지 않는다.
- 시그니처 3종과 스타터 팩은 출시 확정이 아니라 제안·기획 상태로 표시한다.
- 운전 중 취식을 권장하는 장면과 미검증 건강 효능은 사용하지 않는다.

## 검증 기준

- 공개 탐색 범위는 P-001·P-005·P-006 세 화면이다.
- 메인 상품 슬라이드는 7개 팩만 표시하고 전체 15개 상품은 P-006으로 연결한다.
- 모든 이동 요소는 버튼 또는 링크로 표현한다.
- 모바일에서 제품 정의, 대표 상품, 사용 상황, 정보 상태, CTA 순서를 유지한다.
