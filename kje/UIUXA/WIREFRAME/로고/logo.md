# YOVIA 로고 레퍼런스 검색 기준

## 1. 작업 목적

`input/로고 초안.png`와 형태적으로 유사한 로고 레퍼런스를 Pinterest에서 안정적으로 찾는다.

- 레퍼런스는 방향 탐색용이며 그대로 복제하지 않는다.
- 검색 결과의 제목보다 실제 이미지의 형태를 우선 평가한다.
- 한 번에 요청된 개수만 저장한다.

## 2. 브랜드 기준

- **배경색**: 흰색
- **로고색**: 검정색 또는 흑백·회색조
- **브랜드 콘셉트**: 바쁜 일상 속에서도 간편하고 건강하게 즐기는 무가당·락토프리 올인원 그릭요거트 브랜드
- **전달 인상**: 간결함, 균형, 연결, 부드러운 흐름, 현대적이고 신뢰감 있는 분위기

## 3. 로고 초안의 형태 분석 기준

검색 전에 `input/로고 초안.png`를 직접 확인하고 아래 특징을 기준으로 삼는다.

1. 크기가 다른 원 또는 타원이 연속적으로 겹친다.
2. 얇은 원형 윤곽선과 채워진 면이 함께 사용된다.
3. 중심이 한곳에 고정되지 않고 좌우로 흐르는 비대칭 구도다.
4. 겹침을 통해 연결·순환·융합의 인상을 만든다.
5. 복잡한 일러스트보다 단순한 기하학 심벌에 가깝다.
6. 워드마크보다 심벌 형태의 유사성을 우선한다.

## 4. Pinterest 검색어 작성 규칙

Pinterest 내부 검색과 웹 검색을 함께 사용한다. 검색어는 `형태 + 구성 + 스타일 + 용도 + 색상` 순서로 조합한다.

### 우선 검색어

```text
abstract overlapping circles logo black and white
minimal overlapping circle logo monochrome
geometric circle overlap symbol logo
abstract connected rings logo grayscale
organic circular line logo black
asymmetric overlapping ellipse logo minimal
```

### Pinterest 결과가 불안정할 때 사용하는 웹 검색어

```text
site:pinterest.com "overlapping circles logo" monochrome
site:pinterest.com "abstract circle logo" black white
site:pinterest.com "connected rings logo" minimal
site:pinterest.com "overlapping ellipse logo" geometric
```

### 검색 확장 순서

검색 결과가 부족할 때만 아래 순서로 한 단어씩 확장한다.

```text
circle → ellipse → ring → loop → orbit → organic geometry
overlapping → connected → interlocking → layered → flowing
logo → symbol → mark → icon → identity
```

한 검색어에서 적합한 후보가 없으면 같은 결과를 오래 탐색하지 말고 다음 검색어로 전환한다.

## 5. 후보 선정 기준

아래 필수 조건을 모두 만족하는 이미지만 후보로 선정한다.

- 원·타원·링의 겹침이 핵심 조형이다.
- 단독 심벌 또는 로고 마크로 사용할 수 있다.
- 흰색 또는 단색 배경에서 형태를 명확히 확인할 수 있다.
- 검정·흰색·회색조로 변환해도 구조가 유지된다.
- 초안처럼 연결·순환·융합의 인상이 있다.
- 워터마크·UI·장식이 로고 형태를 심하게 가리지 않는다.

후보가 여러 개라면 다음 우선순위로 선택한다.

1. 초안과 겹침 구조가 가장 유사한 것
2. 흑백 적용이 쉬운 것
3. 작은 크기에서도 식별 가능한 것
4. 목업이 아닌 평면 심벌 이미지
5. 출처 핀과 원본 이미지를 확인할 수 있는 것

## 6. 제외 기준

다음 이미지는 저장하지 않는다.

1. 컬러 사용이 형태 판단에 필수적인 로고
2. 명함·간판·패키지 등에 합성된 목업
3. 로고보다 포스터·배경·3D 아트에 가까운 이미지
4. 원형 요소가 장식일 뿐 핵심 심벌이 아닌 이미지
5. 텍스트 워드마크가 중심이고 심벌이 없는 이미지
6. Pinterest 로그인·가입 팝업이 겹친 화면 캡처
7. 검색 결과 그리드 전체 또는 Pinterest UI가 포함된 화면 캡처
8. 해상도가 지나치게 낮거나 워터마크가 형태를 가린 이미지
9. 이미 저장한 후보와 사실상 동일한 중복 이미지

## 7. 안정적인 Pinterest 탐색 절차

1. `input/로고 초안.png`를 확인하고 형태 키워드 3~5개를 기록한다.
2. 우선 검색어로 Pinterest 핀 후보를 찾는다.
3. 핀 제목만 믿지 말고 상세 이미지에서 겹침 구조와 흑백 적용 가능성을 확인한다.
4. 핀의 고유 URL을 기록한다.
5. 상세 화면에 로그인 팝업이 나타나면 화면 전체를 결과물로 저장하지 않는다.
6. 공개 핀 데이터의 대표 이미지 주소(`i.pinimg.com`)를 확인해 이미지 자체를 확보한다.
7. 대표 이미지 주소를 확인할 수 없으면 다른 핀 후보로 전환한다.
8. 저장 후 파일을 다시 열어 팝업·잘림·깨짐·색상 조건을 검사한다.

Pinterest 페이지는 지역 도메인이나 로그인 상태에 따라 달라질 수 있다. 핀 ID가 같은 경우 국가별 도메인이 달라도 동일 핀으로 간주한다.

## 8. 실행 명령 규칙

사용자가 아래 문장을 입력하면 레퍼런스 수집 작업을 즉시 시작한다.

```text
레퍼런스 수집 시작해
```

위 명령은 다음 작업 요청으로 해석한다.

```text
로고/input/의 이미지 분석
→ 로고/레퍼런스/의 이미지 스타일 분석
→ 두 기준을 함께 만족하는 Pinterest 레퍼런스 검색
→ 적합 후보 검증
→ 이미지 영역만 캡처 또는 공개 대표 이미지 확보
→ 로고/output/에 다음 번호의 JPG로 저장
→ 저장 결과 재검증
```

### 입력별 역할

- `input/`: 찾으려는 대상의 형태·구조·비율·방향성을 결정하는 **주 기준**
- `레퍼런스/`: 결과 이미지의 표현 방식·색상·평면성·완성도·분위기를 결정하는 **스타일 기준**
- `output/`: 검증을 통과한 Pinterest 수집 결과만 저장하는 폴더

실행할 때 `input/`과 `레퍼런스/` 안의 판독 가능한 이미지 전체를 먼저 확인한다. 한쪽만 보고 검색하지 않는다.

### 현재 레퍼런스 스타일 기준

`레퍼런스/` 이미지에서 공통적으로 확인되는 다음 특성을 우선한다.

- 흰색 배경과 검정 단색 심벌
- 목업·사진 효과가 없는 평면 그래픽
- 원·호·반복·회전·중첩을 이용한 기하학 구성
- 작은 크기에서도 읽히는 굵고 명확한 실루엣
- 양화와 음화 공간이 균형을 이루는 구조
- 장식보다 심벌 자체가 중심인 이미지

레퍼런스 이미지 안의 특정 로고를 그대로 복제하거나 동일 이미지를 다시 수집하지 않는다. 스타일과 완성도만 검색 기준으로 사용한다.

### 기본 실행값

- 사용자가 개수를 지정하지 않으면 **1장만** 수집한다.
- 사용자가 개수를 지정하면 요청한 수량만 수집한다.
- 기존 `output/` 파일은 유지하고 가장 큰 번호 다음부터 생성한다.
- 적합한 후보가 없으면 기준을 낮춰 저장하지 말고 검색어를 변경한다.
- 여러 후보 중에서는 `input/` 형태 유사성, `레퍼런스/` 스타일 유사성 순으로 판정한다.

### 캡처 정의

이 문서에서 `캡처`는 Pinterest 페이지 전체 스크린샷이 아니라 다음 중 하나를 의미한다.

1. 핀 상세 화면에서 로고 이미지 영역만 잘리지 않게 캡처
2. Pinterest 공개 대표 이미지(`i.pinimg.com`)를 확보해 JPG로 저장

로그인 팝업, Pinterest 헤더, 저장 버튼, 검색 결과 UI, 주변 추천 이미지는 결과 JPG에 포함하지 않는다.

## 9. Flow 이미지 생성 프롬프트 작성 규칙

Pinterest 레퍼런스 수집이 완료되면 `output/`의 수집 이미지를 분석하여 Flow 이미지 생성 기능에 사용할 프롬프트를 작성한다.

### 작성 목적

- 수집 이미지를 그대로 복제하는 프롬프트가 아니라 YOVIA 로고 방향을 새롭게 탐색할 수 있는 생성 프롬프트를 작성한다.
- `input/`의 형태 방향, `레퍼런스/`의 스타일 기준, 개별 `output/` 이미지의 조형 특징을 함께 반영한다.
- 최종 생성물은 흰색 배경의 검정 단색 평면 심벌을 기본으로 한다.

### 이미지별 분석 항목

각 `output/*.jpg`에서 다음 항목을 독립적으로 분석한다.

1. 기본 도형: 원, 타원, 링, 호, 반복 모듈
2. 조합 방식: 중첩, 교차, 연결, 회전, 방사, 연속 흐름
3. 실루엣: 대칭·비대칭, 열린 형태·닫힌 형태, 중심 집중도
4. 양화·음화 공간의 관계
5. 선과 면의 비율 및 굵기
6. 작은 크기에서의 식별성
7. YOVIA 콘셉트와 연결할 수 있는 인상: 간편함, 건강함, 올인원, 균형, 부드러운 흐름
8. 제거할 요소: 컬러, 3D, 목업, 사진 질감, 워터마크, 문자, 불필요한 장식

### 프롬프트 작성 언어와 형식

- 프롬프트 본문은 반드시 **영문**으로 작성한다.
- 이미지 파일명과 Markdown 제목은 원래 파일명을 그대로 사용한다.
- 한 이미지당 하나의 독립 프롬프트를 작성한다.
- 프롬프트는 Flow에 바로 입력할 수 있는 완결된 명령문이어야 한다.
- 다른 이미지의 특징을 자동 혼합하지 않는다.
- 특정 브랜드·작가·기존 로고를 그대로 복제하도록 지시하지 않는다.

영문 프롬프트에는 가능한 범위에서 다음 내용을 포함한다.

```text
Create an original minimalist logo symbol for YOVIA...
geometric construction and composition
overlapping circular or organic forms
black symbol on a clean white background
flat vector-like appearance
balanced positive and negative space
clear silhouette at small sizes
no text, no letters, no mockup, no 3D, no gradients, no shadows, no watermark
```

위 예문을 그대로 반복하지 말고 각 이미지에서 관찰한 구조에 맞게 구체화한다.

### 저장 파일

작성한 프롬프트는 다음 파일 하나에 누적한다.

```text
output/flow.md
```

각 항목은 이미지 파일명을 대제목으로 작성하고 바로 아래에 영문 프롬프트를 기록한다.

```md
# pinterest_similar_logo_01.jpg

Create an original minimalist logo symbol for YOVIA ...

# pinterest_similar_logo_02.jpg

Create an original minimalist logo symbol for YOVIA ...
```

- `flow.md`에는 `output/`의 실제 레퍼런스 JPG만 항목으로 등록한다.
- `flow.md` 자체와 이미지가 아닌 파일은 분석 대상에서 제외한다.
- 같은 파일명의 대제목을 중복 생성하지 않는다.

### 재작성 금지와 `재실행` 명령

한 번 작성된 이미지별 프롬프트는 사용자가 아래 명령을 입력하기 전까지 다시 작성하거나 수정하지 않는다.

```text
재실행
```

일반 실행 시 처리 규칙:

1. `output/flow.md`가 없으면 새로 생성한다.
2. `flow.md`에 없는 새 JPG만 분석해 항목을 추가한다.
3. 이미 같은 파일명의 대제목이 있으면 해당 프롬프트를 유지하고 건너뛴다.
4. 파일의 수정 시각이 바뀌어도 `재실행` 명령이 없으면 기존 프롬프트를 유지한다.
5. 기존 프롬프트의 문장 교정·확장·요약도 재작성으로 간주해 실행하지 않는다.

`재실행` 명령 입력 시 처리 규칙:

1. `output/`의 현재 JPG 목록을 다시 확인한다.
2. 각 이미지를 다시 분석한다.
3. `flow.md`의 해당 파일명 항목을 최신 분석 결과의 영문 프롬프트로 교체한다.
4. 현재 존재하지 않는 이미지의 기존 항목은 사용자 요청 없이 삭제하지 않는다.
5. 재실행 후에도 파일명 대제목과 이미지별 1개 프롬프트 구조를 유지한다.

### Flow 프롬프트 검증

- [ ] 모든 프롬프트 본문이 영문이다.
- [ ] 각 대제목이 실제 JPG 파일명과 정확히 일치한다.
- [ ] 이미지당 프롬프트가 정확히 1개다.
- [ ] 흰색 배경·검정 단색·평면 심벌 조건이 포함된다.
- [ ] 문자·목업·3D·그라디언트·그림자·워터마크 제외 조건이 포함된다.
- [ ] 레퍼런스를 그대로 복제하거나 특정 로고를 모사하도록 지시하지 않는다.
- [ ] `재실행` 명령 없이 기존 항목을 수정하지 않았다.

## 10. 저장 규칙

- **입력 폴더**: `input/`
- **결과 폴더**: `output/`
- **최종 레퍼런스 폴더**: `레퍼런스/`
- **파일 형식**: JPG
- **파일명**:

```text
pinterest_similar_logo_01.jpg
pinterest_similar_logo_02.jpg
```

- 번호는 기존 파일 다음 번호를 사용한다.
- 한 번에 1개 요청이면 검증을 통과한 1개만 생성한다.
- JPG가 아닌 원본은 변환 후 육안으로 품질을 재확인한다.
- 기존 결과를 사용자 요청 없이 덮어쓰지 않는다.

## 11. 저장 후 검증 체크리스트

- [ ] 요청한 개수와 저장 파일 수가 일치한다.
- [ ] JPG 파일이 정상적으로 열린다.
- [ ] Pinterest 로그인·가입 팝업과 사이트 UI가 없다.
- [ ] 로고가 잘리지 않고 전체 형태가 보인다.
- [ ] 흰색 또는 단색 배경이다.
- [ ] 컬러 없이도 형태를 이해할 수 있다.
- [ ] 목업이 아니다.
- [ ] 원·타원·링의 겹침이 핵심 조형이다.
- [ ] 기존 후보와 중복되지 않는다.
- [ ] 원본 Pinterest 핀 URL을 완료 보고에 기록한다.
