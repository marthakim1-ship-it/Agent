# YOVIA 4단계 병합 작업 인수인계

## 1. 현재 상태

YOVIA의 메인페이지·제품 카테고리·브랜드 소개를 하나의 상품 기준으로 통일하고, 보완 클라이언트의 상품 체계·화면 위계 요구를 반영한 상태다.

- 통합 관리 항목: YV-001~022, 총 22개
- 기본 팩: 3개
- 생과일 퓨레 구성 옵션: 10개
- 견과류 토핑 추가 구성 옵션: 5개
- 시그니처·스타터 팩 추천 조합: 4개
- 대표 상품: YV-001, YV-019, YV-022
- 대표 3종은 전체 22개 안의 재노출 항목이며 별도로 합산하지 않는다.

기본 병합본과 디자인 보완 시안2를 모두 보존하고 있다. 이후 디자인 검토는 시안2를 기준으로 진행한다.

## 4. 상품 체계 정본

| 번호 | 범위 | 상품군 | 기준 | 상태 |
|---|---:|---|---|---|
| YV-001~003 | 3개 | 기본 팩 | 120g·400g·800g 용량 변형 후보 | 확인 필요 |
| YV-004~013 | 10개 | 생과일 퓨레 | 과일 풍미 구성 옵션 | 제안 |
| YV-014~018 | 5개 | 견과류 토핑 | 식감 추가 구성 옵션 | 제안 |
| YV-019~022 | 4개 | 시그니처·스타터 팩 | 사용 상황과 첫 경험을 위한 추천 조합 | 제안 |

120g·400g·800g은 독립 판매 상품인지 하나의 기본 팩 안의 용량 선택인지 공식 확인 전이다. 퓨레·토핑의 용량과 단독 판매 여부, 추천 조합의 출시·판매 여부도 확인 전이다.

## 5. 페이지별 역할

### 메인페이지 시안2

- 첫 화면 문장과 제품 패키지 중심 구성 유지
- 팩·퓨레·토핑의 세 가지 역할 설명
- 출근·등교 전, 업무 사이, 캠퍼스, 활동 후의 네 장면 유지
- 구성 탐색 예시 유지
- 대표 상품 3종과 전체 22개 카드 유지
- 상품군 순서: 기본 팩 → 생과일 퓨레 → 견과류 토핑 → 시그니처·스타터 팩
- 상품군 제목에서만 원형 그래픽과 명암 변화를 사용
- 일반 퓨레·토핑 카드는 메인에서 번호·이름·핵심 차이·상태 중심으로 축약
- 상세 비교는 카테고리 시안2로 연결

대표 상품 3종은 최근 검토에서 다음처럼 정리했다.

- 세 카드 모두 동일한 3열 너비
- 이미지 영역과 패키지 크기 동일
- 동일한 중립 원형 배경 사용
- 역할별로 과도하게 다른 원형·동심원 그래픽을 사용하지 않음
- 기본 구조·시그니처 조합·첫 구성 경험의 차이는 본문 역할 라벨과 선정 이유로 설명

대표 카드에 다시 5:4:3 폭, 서로 다른 이미지 높이, 분산 원형 또는 강한 동심원 그래픽을 적용하지 않는다. 해당 방식은 카드가 찌그러지고 테스트 그래픽처럼 보이는 문제가 있어 제외했다.

### 카테고리 시안2

- 22개 전체 비교 담당
- 정보 순서: 번호 → 이름 → 상품군 → 용량·구성 → 핵심 특징 → 상태
- 상품군 순서: 기본 팩 → 퓨레 → 토핑 → 시그니처·스타터 팩
- 필터: 전체·기본 팩·퓨레·토핑·추천 조합
- 추천 조합 4개는 별도 필터 데이터 그룹으로 분리
- 최대 3개 상품 비교와 비교 모달 유지
- 상태 표시는 보조 위계로 표현

### 브랜드 소개 시안2

- 상품 판매 목록보다 브랜드 이유와 사용 경험을 먼저 설명
- 기존의 긴 상품명 목록 두 구간은 화면에서 숨기고 데이터는 유지
- `한 팩의 선택을 네 가지 역할로` 구간에서 03·10·05·04 체계를 큰 네 장면으로 설명
- 상세 상품은 `22개 상품 비교하기`를 통해 카테고리 시안2로 연결
- 정기배송은 준비 중인 방향으로만 표시

## 6. 유지해야 할 콘텐츠와 디자인

- `바쁜 하루, 한 팩에 담은 세 가지 구성` 문장
- 제품 패키지 중심 첫 화면
- 원형·곡선 그래픽
- 팩·퓨레·토핑 관계
- 네 가지 일상 장면
- 구성 탐색 예시
- 대표 상품 3종
- 전체 22개 상품 체계
- 확정·제안·보류 기준
- 회색 와이어프레임, 둥근 카드와 넓은 여백

원형은 모든 카드에 반복하지 않는다. 첫 화면, 구성 관계, 상품군 제목과 마지막 제안처럼 브랜드 인상을 회수해야 하는 지점에서만 사용한다.

## 7. 제외해야 할 내용

- 현재 기준과 충돌하는 새 상품·기능·효능·가격
- 확인되지 않은 듀얼 챔버와 시간 단축 수치
- 확정되지 않은 판매·구매·정기배송 정책
- 확인되지 않은 영양·알레르기·원료·패키지 정보
- 기존 네 장면을 대체하는 새로운 사용자 설정
- 외부 레퍼런스의 색상·문장·패키지·상품 분류 복제
- 메인 전체를 카테고리와 같은 상세 비교 화면으로 만드는 변경
- 대표 상품 3종을 서로 다른 폭과 높이로 만들어 카드 정렬을 깨는 변경

## 11. 주의 사항

- 현재 시안2는 디자인 검토본이며 기본 병합본을 삭제하지 않는다.
- 숨김 마크업은 상품 데이터를 유지하기 위한 병합 과정의 잔여 구조다. 최종 승인 전에는 제거하지 않는다.
- 숨김 구조를 정리할 때는 카테고리 필터, 비교 기능과 22개 데이터 생성 스크립트의 선택자를 먼저 확인한다.
- 파일명을 변경하면 세 시안2의 헤더·CTA·푸터 링크를 함께 수정한다.
- 상품을 추가하거나 삭제하면 세 페이지, 기준표, 분석 문서의 총수를 모두 갱신한다.
