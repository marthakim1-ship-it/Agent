# VC-031 류지민 보완 결과

- 기존 메인페이지의 첫 화면, 팩·퓨레·토핑 관계, 네 가지 일상 장면, 구성 탐색 예시, 대표 상품 3종과 전체 상품 영역을 유지했다.
- YV-001~022를 통합 관리 번호로 사용하고 화면 번호와 분리했다.
- 기본 팩은 용량 변형 후보, 퓨레·토핑은 구성 옵션 제안, 시그니처·스타터는 추천 조합 제안으로 정리했다.
- 대표 영역은 선정 이유, 전체 영역은 상품군·구성·차이·상태 비교를 담당한다.
- 구성 선택 CTA는 구성 확인 수준으로 유지하고 정기배송은 준비 중인 미래 방향으로만 표시한다.
- 확정하지 않은 항목: 기본 팩 판매 단위, 퓨레·토핑의 용량과 단독 판매 여부, 추천 조합의 출시 여부, 가격·영양·알레르기·구매·정기배송 정책.
