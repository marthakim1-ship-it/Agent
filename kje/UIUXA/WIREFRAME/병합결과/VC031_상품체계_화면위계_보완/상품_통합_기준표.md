# YOVIA 상품 통합 기준표 — VC-031 보완본

이 문서는 메인페이지, 제품 카테고리, 브랜드 소개가 함께 사용하는 상품 정보의 Single Source of Truth다. 화면 번호와 상품 관리 번호를 분리하며, 확인되지 않은 판매 단위는 확정하지 않는다.

## 계산 기준

> YOVIA는 판매 단위 확인이 필요한 기본 팩 용량 변형 후보 3개, 추천 조합 제안 4개, 구성 옵션 제안 15개를 하나의 체계로 관리한다.

- 통합 관리 항목: 22개
- 판매 상품: 현재 자료만으로 확정 가능한 항목 0개
- 용량 변형 후보: 3개(YV-001~003). 독립 상품인지 하나의 기본 팩 안의 용량 옵션인지 확인 필요
- 구성 옵션 제안: 15개(YV-004~018). 퓨레 10개와 토핑 5개의 단독 판매 여부·용량 확인 전
- 추천 조합 제안: 4개(YV-019~022). 실제 판매 단위와 출시 여부 확인 전
- 대표 영역의 YV-001, YV-019, YV-022는 중복 계산하지 않는다.
- 화면 번호(P-001, P-005, P-006)와 통합 관리 번호(YV-001~YV-022)는 서로 다른 체계다.

## 세 페이지 공통 표시 순서

`상품 또는 구성 이름 → 상품군 → 용량·구성 → 핵심 특징 → 상태`

- 대표 영역: 왜 YOVIA를 대표하는지 설명한다.
- 전체 상품 영역: 22개 체계 안의 상품군·구성·차이·상태를 비교한다.
- 대표 재노출은 허용하지만 통합 관리 항목 수에 중복 합산하지 않는다.

## 확인 필요

- YV-001~003이 독립 판매 상품인지 하나의 기본 팩 상품의 용량 옵션인지
- 퓨레 10종과 토핑 5종의 개별 용량, 단독 판매 여부 및 추가 선택 정책
- 시그니처 팩과 스타터 팩의 출시 여부, 실제 판매 단위 및 최종 구성
- 가격, 원료, 영양, 알레르기, 패키지 사양, 구매 및 정기배송 정책
