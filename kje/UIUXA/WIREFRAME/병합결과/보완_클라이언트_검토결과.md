# YOVIA 보완 클라이언트 검토 결과

## 1. 역할과 검토 범위

- 역할: YOVIA의 상품 체계와 브랜드 경험을 하나의 기준으로 정리하는 브랜드·커머스 편집 책임자
- 기준 화면: 기존 `메인페이지_병합시안3.html`
- 최종 반영 화면: `메인페이지_병합시안.html`, `카테고리페이지_병합시안.html`, `브랜드소개_병합시안.html`
- 원칙: 새 상품·기능·효능·가격을 추가하지 않고 기존 시안3의 강점을 유지하면서 기준과 화면 위계만 보완한다.

## 2. 보완 클라이언트의 새 결과 제안

### 상품 체계

- 통합 관리 항목은 YV-001~022, 총 22개로 정의한다.
- YV-001~003은 기본 팩의 용량 변형 후보이며 독립 판매 단위 여부는 확인 전으로 둔다.
- YV-004~013은 생과일 퓨레 구성 옵션 제안으로 정의한다.
- YV-014~018은 견과류 토핑 추가 구성 옵션 제안으로 정의한다.
- YV-019~022는 `시그니처·스타터 팩` 추천 조합 제안으로 통합한다.
- 대표 3종 YV-001·YV-019·YV-022는 전체 22개에 포함하며 별도로 합산하지 않는다.

### 페이지 역할

- 메인: 브랜드 메시지, 사용 장면, 구성 방식, 대표 상품의 가치와 전체 카드 체계를 보여준다.
- 카테고리: 22개 항목을 동일한 정보 순서로 비교하고 필터·선택 비교를 제공한다.
- 브랜드 소개: 상품 체계를 반복 판매하지 않고 YOVIA가 준비 부담을 줄이려는 이유와 상품 구조의 관계를 설명한다.

### 정보 순서

모든 항목은 `번호 → 이름 → 상품군 → 용량·구성 → 핵심 특징 → 상태` 순서로 관리한다. 확인되지 않은 용량·판매 단위·가격·영양·알레르기·정기배송 정책은 임의로 확정하지 않는다.

### 화면 위계

- 첫 화면의 문장, 패키지, 원형·곡선 그래픽을 유지한다.
- 대표 상품은 선정 이유와 역할을 설명하고 일반 상품은 같은 기준의 비교 카드로 사용한다.
- 기본 팩·퓨레·토핑·시그니처·스타터의 전환은 구간 제목과 여백으로 구분한다.
- 상태 표시는 유지하되 상품명과 브랜드 문장보다 약하게 표현한다.
- 구성 예시의 우선 행동은 구성 확인으로 제한하고 정기배송은 준비 중으로만 안내한다.

## 4. 유지·적용·제외 판단

### 기존 시안3에서 유지

- `바쁜 하루, 한 팩에 담은 세 가지 구성` 문장
- 제품 패키지 중심 첫 화면과 원형·곡선 그래픽
- 팩·퓨레·토핑 관계 설명
- 출근·등교 전, 업무 사이, 캠퍼스, 활동 후의 네 장면
- 구성 탐색 예시
- 역할이 다른 대표 3종
- 회색 와이어프레임, 둥근 카드, 넓은 여백
- 확정·제안·보류와 미확정 정보 안내

### 보완 결과에서 적용

- YV-001~022 통합 상품 기준
- 세 페이지의 번호·이름·상품군·용량·구성·특징·상태 동기화
- `시그니처·스타터 팩` 추천 조합 4개 통합
- 대표 영역과 전체 상품 영역의 다른 반복 목적
- 상품군별 공통 정보 순서
- 구성 예시와 다음 행동의 확정 단계 통일
- 메인·카테고리·브랜드 소개의 상호 연결

### 제외

- 새 상품·기능·효능·가격
- 확인되지 않은 듀얼 챔버, 시간 단축 수치, 판매·정기배송 정책
- 기존 네 장면을 대체하는 새로운 사용자 설정
- 외부 브랜드의 색상·문장·패키지·상품 분류 복제
- 메인 전체를 카테고리처럼 바꾸거나 모든 구간을 동일 카드로 교체하는 안

## 5. 레퍼런스 원리 적용 판단

- 사용성: Chobani에서 상품 정보가 일정한 순서로 읽히는 원리만 가져와 YOVIA의 공통 정보 순서에 적용했다.
- 심미성: 기존 웹디자인 시안1의 큰 패키지·원형·곡선·둥근 카드 원리를 회색 와이어프레임 안에서 유지했다.
- 무드: Daily Harvest에서 생활 목표와 쉬운 선택을 연결하는 문장 원리만 참고하고 YOVIA의 네 가지 일상 장면으로 다시 표현했다.
- 외부 레퍼런스의 색상, 상품명, 패키지, 영양·판매 정보는 가져오지 않았다.

## 6. 최종 반영 및 검수 결과

- 세 페이지 모두 YV-001~022의 22개 항목을 사용한다.
- 번호별 이름·상품군·용량·구성·핵심 특징·상태 불일치는 0건이다.
- 대표 3종은 YV-001·YV-019·YV-022이며 전체 22개 안에 포함된다.
- 추천 조합은 `시그니처·스타터 팩` 4개로 통일했다.
- 메인에는 시안3의 상품 카드 구조를 복원했고, 카테고리는 상세 비교 역할을 유지한다.
- 브랜드 소개는 기본 팩 3·구성 옵션 15·추천 조합 4의 관계를 브랜드 이유와 연결한다.
- 구성 탐색의 우선 행동은 구성 확인이며 정기배송은 준비 중으로 표시한다.
- 중복 HTML ID와 존재하지 않는 로컬 HTML 링크는 0건이다.
- Edge 렌더링에서 카테고리 4개 상품군과 22개 카드 생성을 확인했다.

## 7. 완료 판단

보완 클라이언트가 요구한 상품 기준 통일, 세 페이지 동기화, 대표·전체 역할 구분, 추천 조합 통합, 행동 단계 조정과 병합 근거 기록을 완료했다. 실제 제품 자료가 확정되기 전에는 가격·영양·알레르기·판매·정기배송 정보를 추가하지 않는다.
