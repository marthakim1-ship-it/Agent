# YOVIA 4단계 선택 병합 분석

기존 시안3을 전체 교체하지 않고 상품 기준, 페이지 정합성, 화면 위계에 필요한 보완만 선택해 반영한다.

보완 클라이언트의 별도 제안, 시안3 비교, 유지·적용·제외 판단과 최종 근거는 `보완_클라이언트_검토결과.md`에 기록한다.

## 현재 해결된 내용

- 제품 패키지와 원형·곡선 중심의 첫 화면
- 팩·퓨레·토핑 관계 설명
- 출근·등교 전, 업무 사이, 캠퍼스, 활동 후의 네 장면
- 구성 탐색 예시
- 서로 다른 역할의 대표 3종
- 퓨레 10종과 토핑 5종의 고유 이름과 풍미·식감
- 가격·영양·알레르기·판매 정책의 미확정 상태 통제

## 4단계에서 보완할 내용

- 카테고리의 22개 항목을 세 페이지 공통 기준으로 사용
- 기본 팩을 확정 판매 상품이 아닌 용량 변형 후보로 정리
- 퓨레·토핑을 구성 옵션, 시그니처·스타터를 추천 조합으로 정리
- 모든 항목에 공통 정보 순서 적용
- 대표 영역은 가치 설명, 전체 영역은 비교·탐색으로 역할 분리
- 구성 예시 CTA를 구성 확인 수준으로 제한
- 원형·곡선을 대표 구간과 상품군 전환, 마지막 제안에서 선택적으로 반복
- 메인의 전체 22개 카드 구조는 시안3의 카드 위계를 복원하고, 상세 비교 기능은 카테고리로 이관
- 시그니처 3개와 스타터 1개는 `시그니처·스타터 팩`이라는 하나의 추천 조합 구간으로 통합

## 유지·적용·제외

| 구분 | 내용 |
|---|---|
| 유지 | 첫 문장, 패키지 히어로, 구성 관계, 네 장면, 대표 3종, 회색 와이어프레임 |
| 적용 | 22개 통합 기준, 공통 정보 순서, 상품군 구간 전환, 대표·전체 역할 분리 |
| 제외 | 새 상품, 확정되지 않은 효능·가격·영양·판매·정기배송 정책 |

## 레퍼런스 원리의 선택 적용

- Chobani: 상품 종류가 달라도 이름·종류·크기·주요 정보가 일정한 순서로 읽히는 원리만 적용한다.
- 기존 웹디자인 시안1: 큰 패키지와 원형·곡선, 둥근 카드, 넓은 여백의 규칙만 회색 와이어프레임으로 변환한다.
- Daily Harvest: 건강 효능을 확대하지 않고 사용자의 하루와 쉬운 선택을 먼저 연결하는 문장 원리만 적용한다.
- 외부 브랜드의 색상, 문장, 상품 분류, 패키지, 영양·판매 정보는 복제하지 않는다.

## 완료 판단

- 통합 관리 항목은 YV-001~022의 22개다.
- 대표 3종은 YV-001, YV-019, YV-022이며 전체 22개에 포함된다.
- 화면별 노출 목적은 달라도 번호·이름·상품군·상태는 같아야 한다.
- 메인은 대표 3종의 가치와 전체 22개 카드 체계를 보여주고, 카테고리는 동일 데이터를 이용한 상세 비교를 담당한다.
- 브랜드 소개는 상품 체계가 브랜드의 간편한 선택 경험과 어떻게 연결되는지 설명한다.
- 세 페이지의 22개 항목을 번호별로 대조한 결과 이름·상품군·용량·구성·핵심 특징·상태 불일치는 0건이다.
- 세 페이지에서 중복 HTML ID와 존재하지 않는 로컬 HTML 링크는 확인되지 않았다.
- Edge 렌더링에서 카테고리의 4개 상품군과 22개 카드가 생성되며, 필터·최대 3개 비교·비교 모달·모바일 메뉴의 이벤트 연결을 확인했다.

## 시안2 디자인 보완

- 상품군은 기본 팩 → 생과일 퓨레 → 견과류 토핑 → 시그니처·스타터 팩 순서로 읽히게 정리했다.
- 상품군 제목에만 원형 그래픽과 명암 변화를 적용해 긴 카드 구간에서도 YOVIA의 시각 언어가 이어지게 했다.
- 대표 3종은 동일한 3열·동일 높이와 깨끗한 패키지 중심 이미지 자리를 유지하고, 본문의 역할 라벨과 선정 이유로 기본 구조·시그니처 조합·첫 구성 경험을 구분했다.
- 퓨레·토핑 일반 카드는 메인에서 번호·이름·핵심 차이·상태 중심으로 축약하고 상세 비교는 카테고리로 연결했다.
- 네 가지 일상 장면 중 출근·등교 전을 대표 장면으로 확대하고 나머지는 확장 장면으로 낮췄다.
- 상태·후보·자료 안내의 크기와 대비를 낮춰 브랜드 문장과 상품명이 먼저 보이게 했다.
