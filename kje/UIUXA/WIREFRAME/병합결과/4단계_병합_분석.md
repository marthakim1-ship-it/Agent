# YOVIA 4단계 선택 병합 분석

기존 시안3을 전체 교체하지 않고 상품 기준, 페이지 정합성, 화면 위계에 필요한 보완만 선택해 반영한다.

## 현재 해결된 내용

- 제품 패키지와 원형·곡선 중심의 첫 화면
- 팩·퓨레·토핑 관계 설명
- 출근·등교 전, 업무 사이, 캠퍼스, 활동 후의 네 장면
- 구성 탐색 예시
- 서로 다른 역할의 대표 3종
- 퓨레 10종과 토핑 5종의 고유 이름과 풍미·식감
- 가격·영양·알레르기·판매 정책의 미확정 상태 통제

## 4단계에서 보완할 내용

- 카테고리의 22개 항목을 세 페이지 공통 기준으로 사용
- 기본 팩을 확정 판매 상품이 아닌 용량 변형 후보로 정리
- 퓨레·토핑을 구성 옵션, 시그니처·스타터를 추천 조합으로 정리
- 모든 항목에 공통 정보 순서 적용
- 대표 영역은 가치 설명, 전체 영역은 비교·탐색으로 역할 분리
- 구성 예시 CTA를 구성 확인 수준으로 제한
- 원형·곡선을 대표 구간과 상품군 전환, 마지막 제안에서 선택적으로 반복

## 유지·적용·제외

| 구분 | 내용 |
|---|---|
| 유지 | 첫 문장, 패키지 히어로, 구성 관계, 네 장면, 대표 3종, 회색 와이어프레임 |
| 적용 | 22개 통합 기준, 공통 정보 순서, 상품군 구간 전환, 대표·전체 역할 분리 |
| 제외 | 새 상품, 확정되지 않은 효능·가격·영양·판매·정기배송 정책 |

## 레퍼런스 원리의 선택 적용

- Chobani: 상품 종류가 달라도 이름·종류·크기·주요 정보가 일정한 순서로 읽히는 원리만 적용한다.
- 기존 웹디자인 시안1: 큰 패키지와 원형·곡선, 둥근 카드, 넓은 여백의 규칙만 회색 와이어프레임으로 변환한다.
- Daily Harvest: 건강 효능을 확대하지 않고 사용자의 하루와 쉬운 선택을 먼저 연결하는 문장 원리만 적용한다.
- 외부 브랜드의 색상, 문장, 상품 분류, 패키지, 영양·판매 정보는 복제하지 않는다.

## 완료 판단

- 통합 관리 항목은 YV-001~022의 22개다.
- 대표 3종은 YV-001, YV-019, YV-022이며 전체 22개에 포함된다.
- 화면별 노출 목적은 달라도 번호·이름·상품군·상태는 같아야 한다.
- 메인은 가치와 차이를 짧게 설명하고 카테고리는 전체 비교를 담당한다.
- 브랜드 소개는 상품 체계가 브랜드의 간편한 선택 경험과 어떻게 연결되는지 설명한다.
