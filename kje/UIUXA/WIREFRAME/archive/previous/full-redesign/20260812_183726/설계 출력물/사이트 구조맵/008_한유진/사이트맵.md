# YOVIA VC-008 한유진 사이트맵

## 프로젝트 개요
가족 공유 맥락에서 원료·알레르기·교차접촉·주의를 먼저 확인하는 신뢰 정보을 모바일 우선으로 제공하는 사이트 구조다. 설계 근거는 VC008-REQ-001~006이며 입력에 없는 정책과 수치는 확정하지 않는다.

## 설계 근거와 핵심 사용자 목표
- MENU: 원료·주의, 알레르기, 제품 정보, 검증 상태, 사용 상황, 보류 정보
- CONTENT: 원료, 첨가물, 포함·교차접촉, 적용 대상, 보관 주의, 기준일, 상태 의미, 금지 주장
- FUNCTION: 항목 그룹, 상태 라벨, 고정 주의, 상세 펼치기, 범례, CTA 차단
- 핵심 목표: 탐색 기준을 이해하고, 근거와 적용 범위를 확인한 뒤 확정 가능한 행동으로 이동한다.
- 공개 통제: 어린이 적합·유기농·무첨가 효능은 NOT_VERIFIED/HOLD로 표시하고 CTA에서 제외한다.

## 전역 내비게이션 구조
- 공통: 홈, 원료·주의, 알레르기, 제품 상세
- 상태·근거: 보류 정보
- 회원 상태별: 로그인은 **가정: 핵심 행동에 인증이 필요한 경우**만 노출한다.
- 예외: 결과 없음, 입력 오류 안내, 오류 안내에서 이전 유효 화면 또는 홈으로 복구한다.

## 계층형 사이트맵
- 1차 — 홈
  - 2차 — 원료·주의
  - 2차 — 알레르기
  - 2차 — 제품 정보
  - 2차 — 사용 상황
  - 2차 — 제품 상세
  - 2차 — 검증 상태
    - 3차 — 보류 정보
    - 3차 — 다음 행동
    - 3차 — 로그인
    - 3차 — 결과 없음
    - 3차 — 입력 오류 안내
    - 3차 — 오류 안내

## 주요 사용자 여정과 검토
홈 → 탐색 → 선택 → 상세 확인 → 핵심 행동 → 결과 확인 순서를 유지한다. 로그인 여부, 입력 오류, 결과 없음, 이전 단계 이동을 조건부로 포함했다. 공유 화면은 단일 노드로 유지했고 모든 예외 화면은 복구 경로가 있다.

## 가정
- 실제 제품 데이터, 기준일, CTA와 인증 정책은 미확정이다.
- 검색·필터·계산은 입력 데이터가 확정된 뒤 활성화한다.
- 어린이 적합·유기농·무첨가 효능은 근거가 확보될 때까지 공개하지 않는다.
