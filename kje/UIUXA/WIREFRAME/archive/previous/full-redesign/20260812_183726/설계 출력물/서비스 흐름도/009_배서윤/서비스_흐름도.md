# YOVIA VC-009 배서윤 서비스 흐름도

## 서비스 흐름 개요
사용 후 정리·잔여물·폐기 과정과 환경 주장 근거를 연결하는 정보을 기준으로 탐색 → 선택 → 상세 확인 → 핵심 행동 → 결과 확인을 수행한다. 미확정 정보는 행동과 분리한다.

## 사용자 유형과 시작 조건
- 탐색 사용자: 홈에서 사용 방법 또는 소재·환경 선택
- 근거 확인 사용자: 상세 화면에서 검증·적용 범위 확인
- 비회원: 공개 정보 탐색
- 회원: **가정**상 인증이 필요한 핵심 행동 수행
- 재진입 사용자: 직접 링크·오류 복구·이전 단계로 진입

## 핵심 정상 흐름
1. 홈에서 목적을 선택한다.
2. 조건을 입력하고 결과에서 대상을 선택한다.
3. 상세·근거·상태를 확인한다.
4. 확정 정보에만 핵심 행동을 제공한다.
5. 필요 시 로그인 후 결과를 확인한다.

## 분기·오류·이탈·재진입
- 로그인 여부: 인증 필요 여부는 **가정**이며 아니면 결과로 바로 이동한다.
- 입력값 오류: 오류 원인과 수정 방법을 제시하고 이전 단계로 복귀한다.
- 결과 없음: 조건 초기화 후 탐색으로 복귀한다.
- 이전 단계: 유효한 선택 상태를 유지한다는 **가정**이다.
- 로드 실패: 재시도 또는 홈 이동을 제공한다.
- 친환경·생분해·폐기 감소 수치: HOLD 처리하고 CTA를 차단한다.

| 4 | 폐기 안내 확인·선택 | 데이터·상태 처리 | 폐기 안내 | 다음 화면 또는 분기 |

| 7 | 제품 상세 확인·선택 | 데이터·상태 처리 | 제품 상세 | 다음 화면 또는 분기 |

## 연결성 검토
사이트맵의 화면 이름을 그대로 사용했다. 모든 화면은 홈에서 도달 가능하고 결과 없음·입력 오류·로드 오류는 정상 흐름으로 복구한다.
