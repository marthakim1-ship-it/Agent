# VC-019 권세아 화면 설계서

## 프로젝트 및 설계 범위
최소 측정과 안전한 실험을 위한 7개 저충실도 화면을 정의한다. 실제 거래·회원·외부 시스템 구현은 범위 밖이다.

## 화면 ID 규칙과 전체 목록
SCR-001부터 연속 부여하며 사이트맵·서비스 흐름도·JSON·HTML에서 동일하게 사용한다.

| ID | 화면명 | 목적 |
|---|---|---|
| SCR-001 | 홈 | 사용자 목표별 명확한 시작점 제공 |
| SCR-002 | 제품 상세 | 제품 이해 행동과 결과 분리 |
| SCR-003 | 사용법 | 사용법 목표를 독립적으로 완료 |
| SCR-004 | 판매처 안내 | 외부 이동 조건과 복귀 경로 안내 |
| SCR-005 | 외부 이동 결과 | 성공·취소·오류를 구분 |
| SCR-006 | 측정 동의 | 비필수 측정 선택과 제한 설명 |
| SCR-007 | 설정 완료 | 동의 반영 결과 확인 |

## 공통 구조
- 헤더: 홈과 제품, 사용법, 판매처 탐색.
- 본문: 제목, 목적, 핵심 콘텐츠, 상태, 주요·복구 행동.
- 푸터: 검증된 정책·문의 링크만 배치.

## 클라이언트 전용 화면 설계 원칙
- 화면 패턴: 목표·이벤트 분리형 측정
- 전용 컴포넌트: 목표 선택 카드, 행동 체크포인트, 동의 범위 패널, 외부 이동 결과, 측정 이벤트 설명
- 상태 설계: 성공·취소·오류와 측정 허용 여부를 별도 기록
- 다른 Client의 화면 배열과 컴포넌트를 자동 병합하지 않는다.

## 화면별 설계
### SCR-001 홈
- 목적: 사용자 목표별 명확한 시작점 제공
- 진입 조건: 직접 진입 또는 전역 내비게이션
- 종료 조건: 제품 이해 수행 또는 이전 단계 이동
- 구성/UI: 제품 이해, 사용법, 판매처 목표, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 이해, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-002 제품 상세
- 목적: 제품 이해 행동과 결과 분리
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 사용법 확인 수행 또는 이전 단계 이동
- 구성/UI: 제품 사실, 관련 행동, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 사용법 확인, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-003 사용법
- 목적: 사용법 목표를 독립적으로 완료
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 판매처 이동 수행 또는 이전 단계 이동
- 구성/UI: 단계 안내, 완료 상태, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 판매처 이동, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-004 판매처 안내
- 목적: 외부 이동 조건과 복귀 경로 안내
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 외부 이동 수행 또는 이전 단계 이동
- 구성/UI: 판매처 후보, 외부 이동 안내, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 외부 이동, 이전 단계 이동 → SCR-005
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-005 외부 이동 결과
- 목적: 성공·취소·오류를 구분
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 제품으로 돌아가기 수행 또는 이전 단계 이동
- 구성/UI: 이동 상태, 복귀 행동, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품으로 돌아가기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-006 측정 동의
- 목적: 비필수 측정 선택과 제한 설명
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 선택 저장 수행 또는 이전 단계 이동
- 구성/UI: 측정 목적, 선택 상태, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 선택 저장, 이전 단계 이동 → SCR-007
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-007 설정 완료
- 목적: 동의 반영 결과 확인
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 홈으로 이동 수행 또는 이전 단계 이동
- 구성/UI: 반영 상태, 변경 경로, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 홈으로 이동, 이전 단계 이동 → SCR-001
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공


## 반응형 기준
- 모바일(0~767px): 단일 열, 44px 이상 조작 영역, 핵심 행동 우선.
- 태블릿(768~1023px): 내비게이션과 본문 균형, 카드 2열 허용.
- PC(1024px 이상): 고정 목차와 본문 2열, 읽기 폭 제한.

## 접근성 요구사항
본문 바로가기, 명확한 포커스, 의미 있는 제목 구조, 이미지 대체 텍스트, 상태 텍스트, 키보드 이동, 오류 복구 안내를 제공한다.

## Requirement 추적
- **VC019-REQ-001** (높음): 제품 이해·사용법 확인·판매처 이동을 별도 목표로 정의
- **VC019-REQ-002** (높음): 측정 이벤트를 사용자 목표와 Requirement에 연결
- **VC019-REQ-003** (보통 이상): 동의 상태에 따라 비필수 측정을 제한
- **VC019-REQ-004** (보통 이상): 실험 변형에서도 접근성·사실·브랜드 기준 유지
- **VC019-REQ-005** (보통 이상): 모바일·외부 이동·오류로 인한 흐름 단절을 구분
- **VC019-REQ-006** (보류): 측정 설계 전 전환율·개선 효과를 주장하지 않음

## 가정·HOLD·제외
- 가정: 프로토타입의 버튼은 같은 문서 내 화면으로 이동한다.
- HOLD: VC019-REQ-006 및 승인되지 않은 운영 문구.
- 제외: 미확정 가격·영양 수치·재고·배송·효능·인증·로그인 정책.
