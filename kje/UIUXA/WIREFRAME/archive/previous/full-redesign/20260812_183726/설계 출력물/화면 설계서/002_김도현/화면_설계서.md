## 화면 상태

- 기본: 확인된 데이터와 상태 라벨 표시
- 로딩: 레이아웃 유지 스켈레톤, `aria-busy=true`
- 빈 상태: 필요한 자료·조건과 상위 화면 복귀 제공
- 오류: 입력 오류와 시스템 오류 구분, 재시도·대체 경로 제공
- 완료: 마지막 사용 단계, 인증 성공, 외부 행동 결과와 다음 선택 표시
- 미확정: 값을 추측하지 않고 `NOT_VERIFIED`·`HOLD`, 필요한 검증 자료 표시

## 유효성 검사와 오류 메시지

- 로그인 이메일 빈 값: `이메일을 입력해 주세요.` / 형식 오류: `이메일 형식을 확인해 주세요.`
- 비밀번호 빈 값: `비밀번호를 입력해 주세요.`; 상세 정책은 `가정`하지 않음
- 검색 0건: `조건에 맞는 구조·단계·품질 정보가 없습니다. 핵심 제품 구조를 확인해 주세요.`
- 시험 자료 없음: `검증된 시험 자료가 없어 성능을 표시하지 않습니다.`
- 외부 행동 실패: `다음 행동으로 이동하지 못했습니다. 제품 상세로 돌아가 주세요.`
- 이미지 누락: 오인 가능한 대체 이미지를 사용하지 않고 `실제 제품 이미지 준비 중` 표시

## 반응형 기준

- 모바일 `<768px`: 단계·라벨 1열, 이전·다음 순서 유지, 중요 주의사항을 접힌 영역에만 두지 않음.
- 태블릿 `768~1199px`: 2열 카드, 구조 이미지와 라벨 목록 병렬 가능, 전후 비교는 가로 스크롤 대체 제공.
- 데스크톱 `≥1200px`: 최대 1200px, 이미지·설명 2열, 정보 순서는 모바일과 동일.
- 터치 대상 44×44px 이상, 텍스트 200% 확대 시 기능 손실 없음.

## 접근성 요구사항

- 이미지·핫스폿에 의미 있는 대체 텍스트와 동일 정보의 텍스트 목록 제공.
- 단계 변화·검증 상태 변화는 라이브 영역으로 알림.
- 상태를 색상만으로 구분하지 않고 텍스트·아이콘 병기.
- 키보드로 갤러리·단계·아코디언·비교를 모두 조작 가능.
- WCAG AA 대비 목표, 모션 감소 설정 지원.
- 오류 메시지를 관련 입력과 프로그램적으로 연결.

## 가정 및 미확정 정책

- 가정: P60 로그인, P61 저장 항목, P70 검색, P43 지역 조건 확인.
- 조건부: P32 사용 전후, P41 시험 근거, P43 소재·폐기, P50 다음 행동.
- 미확정: 실제 빌트인 스푼 구조, 사용 동선, 주의사항, 시험 결과, 소재·폐기, 대체 패키지, 판매 채널·CTA.
- 자료가 없으면 타사 구조·이미지·정책으로 대체하지 않는다.
