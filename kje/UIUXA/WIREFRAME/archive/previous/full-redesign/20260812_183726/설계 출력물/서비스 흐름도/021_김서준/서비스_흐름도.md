# VC-021 김서준 서비스 흐름도

## 서비스 흐름 개요

`탐색 → 선택 → 상세 확인 → 관련 정보 확인 → 다음 행동 → 결과 확인` 순서로 검색 직접 유입을 처리한다. 정보 열람은 로그인 없이 가능하며 로그인·입력 흐름은 설계 프롬프트의 필수 분기를 표현하기 위한 `가정`이다.

## 사용자 유형과 시작 조건

- 사용자: 제품명·그릭요거트·원료·사용법 질문을 검색한 첫 방문자
- 시작: 외부 검색 결과, 공유 링크, 상세 URL 직접 진입
- 종료: 검증된 답과 관련 정보 확인 또는 가정된 알림 신청 완료

## 핵심 정상 흐름

1. 검색 유입 랜딩에서 질문과 한 문장 답을 확인한다.
2. 제품 상세에서 근거와 현재 정보 상태를 확인한다.
3. 사용법·원료·성분·검증 정보 중 다음 질문을 선택한다.
4. 관련 콘텐츠와 페이지 안내로 위치를 재확인한다.
5. 계속 탐색하거나 알림 신청(`가정`) 후 결과를 확인한다.

## 분기·오류·이탈·재진입

- 유효하지 않은 URL은 오류 안내에서 랜딩 또는 홈으로 복구한다.
- 답을 찾지 못하면 제품 정보 허브에서 범위를 다시 선택한다.
- 검증 문서가 없으면 자료 준비 중에서 관련 콘텐츠로 이동한다.
- 관련 결과가 없으면 콘텐츠 없음에서 이전 단계 또는 제품 정보로 복귀한다.
- 로그인·입력 오류는 정보 열람을 막지 않으며 이전 단계로 돌아갈 수 있다.

## 단계별 정의

| 단계 | 사용자 행동 | 시스템 처리 | 화면 | 다음 조건 |
|---:|---|---|---|---|
| 1 | 검색 결과 선택 | 경로 유효성 확인 | SCR-002 검색 유입 랜딩 | 유효/오류 |
| 2 | 질문 답 확인 | 페이지 고유 답·상태 표시 | SCR-004 제품 상세 | 해결/미해결 |
| 3 | 정보 범위 재선택 | 카드 목록 제공 | SCR-003 제품 정보 | 상세 선택 |
| 4 | 다음 질문 선택 | 관련 화면과 상태 연결 | SCR-005/006/007 | 확인/준비 중 |
| 5 | 관련 콘텐츠 선택 | 맥락 링크 또는 빈 상태 제공 | SCR-008/014/015 | 안내 이동/복귀 |
| 6 | 위치 확인 | 경로·목적 표시 | SCR-009 페이지 안내 | 다음 행동 |
| 7 | 행동 선택 | 회원 분기(가정) | SCR-010/011 | 종료/입력 |
| 8 | 입력 제출 | 유효성 검사(가정) | SCR-012/013 | 수정/완료 |
| 예외 | 재시도·홈 선택 | 복구 경로 제공 | SCR-016 오류 안내 | 랜딩/홈 |

## Mermaid 전체 흐름

전체 Mermaid 원문은 `서비스_흐름도.mmd`와 동일하며, 시작·종료는 둥근 도형, 판단은 마름모, 화면은 사각형으로 구분했다.
