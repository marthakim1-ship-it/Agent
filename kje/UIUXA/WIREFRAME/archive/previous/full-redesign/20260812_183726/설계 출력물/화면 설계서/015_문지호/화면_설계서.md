# VC-015 문지호 화면 설계서

## 프로젝트 및 설계 범위
모바일 성능과 안정성을 위한 7개 저충실도 화면을 정의한다. 실제 거래·회원·외부 시스템 구현은 범위 밖이다.

## 화면 ID 규칙과 전체 목록
SCR-001부터 연속 부여하며 사이트맵·서비스 흐름도·JSON·HTML에서 동일하게 사용한다.

| ID | 화면명 | 목적 |
|---|---|---|
| SCR-001 | 홈 | 느린 환경에서도 핵심 정의와 탐색 제공 |
| SCR-002 | 제품 목록 | 가벼운 목록에서 제품 선택 |
| SCR-003 | 제품 상세 | 핵심 사실과 CTA 우선 표시 |
| SCR-004 | 사용법 | 텍스트 중심 사용 안내 |
| SCR-005 | 구매 안내 | 확정된 외부 연결 후보 제공 |
| SCR-006 | 외부 연결 결과 | 성공·실패와 복귀 경로 표시 |
| SCR-007 | 오류 안내 | 미디어·네트워크 실패 복구 |

## 공통 구조
- 헤더: 홈과 제품, 사용법, 구매 탐색.
- 본문: 제목, 목적, 핵심 콘텐츠, 상태, 주요·복구 행동.
- 푸터: 검증된 정책·문의 링크만 배치.

## 클라이언트 전용 화면 설계 원칙
- 화면 패턴: 텍스트 우선 점진 로딩
- 전용 컴포넌트: 핵심 텍스트 셸, 이미지 스켈레톤, 저용량 대체 자산, 연결 재시도, 네트워크 상태 배너
- 상태 설계: 텍스트 성공과 미디어 실패를 독립적으로 처리
- 다른 Client의 화면 배열과 컴포넌트를 자동 병합하지 않는다.

## 화면별 설계
### SCR-001 홈
- 목적: 느린 환경에서도 핵심 정의와 탐색 제공
- 진입 조건: 직접 진입 또는 전역 내비게이션
- 종료 조건: 제품 보기 수행 또는 이전 단계 이동
- 구성/UI: 텍스트 우선 소개, 제품 링크, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 보기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-002 제품 목록
- 목적: 가벼운 목록에서 제품 선택
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 상세 보기 수행 또는 이전 단계 이동
- 구성/UI: 텍스트 카드, 이미지 대체 자산, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 상세 보기, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-003 제품 상세
- 목적: 핵심 사실과 CTA 우선 표시
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 사용법 보기 수행 또는 이전 단계 이동
- 구성/UI: 제품 정의, 이미지 상태, CTA, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 사용법 보기, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-004 사용법
- 목적: 텍스트 중심 사용 안내
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 구매 경로 보기 수행 또는 이전 단계 이동
- 구성/UI: 단계 안내, 대체 미디어, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 구매 경로 보기, 이전 단계 이동 → SCR-005
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-005 구매 안내
- 목적: 확정된 외부 연결 후보 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 외부 연결 수행 또는 이전 단계 이동
- 구성/UI: 연결 조건, 외부 이동 안내, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 외부 연결, 이전 단계 이동 → SCR-006
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-006 외부 연결 결과
- 목적: 성공·실패와 복귀 경로 표시
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 제품으로 돌아가기 수행 또는 이전 단계 이동
- 구성/UI: 연결 상태, 재시도, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품으로 돌아가기, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-007 오류 안내
- 목적: 미디어·네트워크 실패 복구
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 목록으로 이동 수행 또는 이전 단계 이동
- 구성/UI: 텍스트 대안, 재시도, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 목록으로 이동, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공


## 반응형 기준
- 모바일(0~767px): 단일 열, 44px 이상 조작 영역, 핵심 행동 우선.
- 태블릿(768~1023px): 내비게이션과 본문 균형, 카드 2열 허용.
- PC(1024px 이상): 고정 목차와 본문 2열, 읽기 폭 제한.

## 접근성 요구사항
본문 바로가기, 명확한 포커스, 의미 있는 제목 구조, 이미지 대체 텍스트, 상태 텍스트, 키보드 이동, 오류 복구 안내를 제공한다.

## Requirement 추적
- **VC015-REQ-001** (높음): 핵심 제품 정의·이미지·CTA를 우선 로드 대상으로 지정
- **VC015-REQ-002** (높음): 느린 환경에서도 텍스트와 기본 탐색이 작동
- **VC015-REQ-003** (보통 이상): 제품 이미지에 크기·형식·대체 자산 기준 후보 설정
- **VC015-REQ-004** (보통 이상): 복합 모션은 정보 이해 효과와 성능을 검증한 뒤 적용
- **VC015-REQ-005** (보통 이상): 외부 연결·미디어 실패 시 재시도와 대체 경로 제공
- **VC015-REQ-006** (보류): 실측 전 성능 등급·속도 개선 수치를 공개하지 않음

## 가정·HOLD·제외
- 가정: 프로토타입의 버튼은 같은 문서 내 화면으로 이동한다.
- HOLD: VC015-REQ-006 및 승인되지 않은 운영 문구.
- 제외: 미확정 가격·영양 수치·재고·배송·효능·인증·로그인 정책.
