# YOVIA VC-012 화면 설계서

## 프로젝트 및 설계 범위
사이트맵과 서비스 흐름도의 16개 화면 전체를 설계한다. 제품 선택부터 지역·상태 확인과 외부 이동까지 제품 맥락을 유지한다.

## 화면별 목적, 진입 조건, 종료 조건
정상 전환은 SCR-001~012, 입력·결과·정책·연결 예외는 SCR-013~016이다. 모든 예외 화면은 이전 유효 화면으로 복구한다.

## 화면 구성 영역과 UI 요소
- 공통 헤더: 홈, 제품, 판매처 찾기, 채널·상태 안내.
- 제품 맥락 바: 선택 제품명, 제품 상태, 조건 변경.
- 지역 UI: 직접 선택을 기본 제공하고 위치 권한은 가정·선택 사항.
- 결과 UI: 판매처 카드, 지역, 채널, 기준일, 확인 범위.
- 이미지 영역은 대체 텍스트가 있는 플레이스홀더로 표시한다.

## 기본·로딩·빈 상태·오류·완료 상태
- 기본: 선택 제품·지역·기준일·유효 행동 표시.
- 로딩: 제품 맥락과 조건을 유지한다.
- 빈 상태: 결과 0건과 조건 변경을 제공한다.
- 오류: 입력 또는 외부 연결 원인과 복구 행동을 제공한다.
- 완료: 이동 결과와 계속 탐색을 제공한다.

## PC·태블릿·모바일 반응형 기준
- 모바일 0~767px: 제품 맥락 고정, 1열 결과, 직접 지역 선택 우선, CTA 전체 폭.
- 태블릿 768~1199px: 결과 카드 2열, 조건 패널 상단.
- PC 1200px 이상: 조건 패널과 결과 2단 구성, 결과 카드 3열.
- 브레이크포인트는 구현 전 조정 가능한 가정이다.

## 접근성 요구사항
위치 권한 거부 대안을 제공하고, 채널·재고 상태를 색상 외 텍스트로 표시한다. 외부 링크는 목적지를 알리고 키보드 탐색·포커스·44px 터치 영역을 제공한다. 결과 변화와 오류는 aria-live 후보로 알린다.

## 가정 및 보류
- 가정: 위치 권한, 실제 판매 채널, 외부 URL, 정확한 지역 체계.
- HOLD: 실시간 재고·배송·가격·영업시간 약속.
- 제외: 로그인, 구독, 자동 위치 강제.
