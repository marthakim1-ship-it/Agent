# YOVIA 화면 설계서

## 프로젝트 및 설계 범위

VC-001 서하린 분석 결과, 사이트맵, 서비스 흐름에 등장하는 로컬 웹 화면 17개를 설계한다. 모바일 우선이며 데스크톱으로 확장한다. 실제 이미지·제품 사양·판매 채널·가격·건강 효능은 확정하지 않는다.

## 공통 구성과 UI 요소

- 헤더: 로고, 홈·브랜드 소개·제품·사용 가이드·성분 및 신뢰 정보, 모바일 메뉴 버튼.
- 본문: 화면 ID/이름, 현재 위치, 핵심 제목, 상태 라벨, 카드 또는 단계형 콘텐츠, 다음 행동.
- 푸터: 검증 원칙과 홈 링크. 판매·배송·정책 링크는 `가정`이므로 제외.
- 반복 컴포넌트: 제품 카드, 상황 카드, 상태 배지(`CONFIRMED`, `NOT_VERIFIED`, `HOLD`), 근거 항목, CTA.
- 이미지: 실제 자산이 없으므로 의미 있는 대체 텍스트가 붙은 플레이스홀더.

## 유효성 검사와 오류 메시지

| 대상 | 조건 | 메시지 | 복구 |
|---|---|---|---|
| 제품 비교 필터 | 허용 목록 밖의 값 | `선택한 조건을 확인해 주세요.` | 해당 조건 해제 |
| 제품 비교 결과 | 결과 0건 | `조건에 맞는 제품이 없습니다.` | 필터 초기화 |
| 근거 데이터 | 출처·기준일 없음 | `확인되지 않은 정보입니다.` | NOT_VERIFIED 표시 |
| 판매 채널 | 미확정 | `판매처 정보는 준비 중입니다.` | 상세 또는 비교 이동 |
| 외부 연결 | 연결 실패 | `판매처로 연결하지 못했습니다.` | 재시도 또는 홈 이동 |
| 이미지 | 로드 실패 | 대체 텍스트와 `이미지를 불러오지 못했습니다.` | 텍스트 정보 유지 |

## 반응형 기준

- 모바일: 0~767px, 1열, 메뉴 접기, CTA 전체 폭, 최소 터치 영역 44×44px.
- 태블릿: 768~1199px, 카드 2열, 본문 최대 폭 960px.
- 데스크톱: 1200px 이상, 카드 3열, 본문 최대 폭 1200px, 헤더 메뉴 펼침.
- `가정`: 브레이크포인트 수치는 구현 검증 전 조정 가능하다.

## 접근성 요구사항

- 논리적 제목 순서, 랜드마크, 건너뛰기 링크를 제공한다.
- 모든 이미지 플레이스홀더에 구체적 대체 텍스트를 둔다.
- 키보드만으로 메뉴·카드·버튼·단계 이동이 가능해야 한다.
- 포커스 표시를 제거하지 않고 상태는 색상과 텍스트를 함께 쓴다.
- 오류 메시지는 입력과 연결하고 동적 상태는 `aria-live`로 알린다.
- 축소 동작 선호를 존중하고, 본문 대비는 WCAG AA를 목표로 한다.

## 가정 및 보류 정책

- `가정`: 제품 옵션과 비교 필터, 회원 분기, 판매처·외부 연결, 반응형 수치.
- `보류`: 누수·오염·잔여물·폐기 시험 결과, 듀얼 챔버·스파우트·특수 실링 공개.
- `금지`: 검증되지 않은 고단백 수치, 소화·장 건강·이너뷰티·붓기·목 보호 효능, 가격·인증·구독·출시일 확정 표현.
