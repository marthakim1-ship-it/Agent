# YOVIA VC-003 화면 설계서

## 프로젝트 및 설계 범위

VC-003 이수민의 신뢰 정보 체계를 14개 웹 화면으로 설계한다. 모바일 구매 전 비교를 우선하며 확정 제품 속성→원료·영양·알레르기→인증·근거→제품별 판단 순서를 유지한다. QR·배치·미생물 조회와 미검증 효능은 제외한다.

## 화면 ID 규칙과 전체 화면 목록

ID는 `SCR-001`부터 순차 부여하며 MD·HTML·JSON에서 동일하게 사용한다.

| ID | 화면 | 목적 | 진입 | 종료·다음 |
|---|---|---|---|---|
| SCR-001 | 홈 | 핵심 정보 진입 | 최초/오류 | 정보 영역 선택 |
| SCR-002 | 제품 정보 | 확정 속성 탐색 | 홈/GNB | 비교/상세 |
| SCR-003 | 제품 비교 | 적합성 비교 | 제품/행동 | 상세/결과 없음 |
| SCR-004 | 제품 상세 | 사실·근거 통합 | 비교/정보 | 다음 행동 |
| SCR-005 | 원료 및 성분 | 원료 확인 | 홈/GNB/상세 | 근거/상세 |

## 공통 구성과 UI 요소

- 헤더: 로고, 제품 정보, 원료 및 성분, 영양 정보, 알레르기 및 주의, 인증 및 근거.
- 본문: 화면 ID·이름, 현재 위치, 핵심 요약, `CONFIRMED/CANDIDATE/NOT_VERIFIED/HOLD` 라벨, 상세 정보, 다음 행동.
- 푸터: 정보 검증 원칙과 홈 링크. 법적 표시·정책 문서 링크는 책임 자료 확정 전 `가정`.
- 반복 컴포넌트: 상태 배지, 제품 카드, 정보 요약, 아코디언, 근거 항목, 고정 주의, CTA.
- 이미지: 친근한 제품·원료 플레이스홀더와 구체적 대체 텍스트. 의료기관·질환 공포 이미지는 제외.

## 상태, 유효성 검사와 오류 메시지

| 조건 | 메시지 | 처리 |
|---|---|---|
| 비교 필터 값 오류 | `선택한 조건을 확인해 주세요.` | 잘못된 조건 해제 |
| 비교 결과 0건 | `조건에 맞는 제품이 없습니다.` | SCR-012 |
| 원료·영양·알레르기 자료 없음 | `확인되지 않은 정보입니다.` | NOT_VERIFIED 표시 |
| 인증 문서·기준일 없음 | `근거 문서가 확인되지 않았습니다.` | CTA 차단, SCR-009 |
| 채널 미확정 | `구매 안내는 준비 중입니다.` | SCR-013 |
| 외부 연결 실패 | `구매 안내로 연결하지 못했습니다.` | SCR-014 |
| 이미지 실패 | `이미지를 불러오지 못했습니다.` | 대체 텍스트 유지 |

## 반응형 기준

- 모바일 0~767px: 1열, 접이식 메뉴, 요약→상세 순서, CTA 전체 폭, 주의 정보 상시 노출.
- 태블릿 768~1199px: 카드 2열, 본문 최대 960px.
- PC 1200px 이상: 카드 3열, 본문 최대 1200px, GNB 펼침.
- 브레이크포인트 수치는 구현 전 조정 가능한 `가정`이다.

## 접근성 요구사항

- 제목 계층·랜드마크·건너뛰기 링크와 키보드 탐색을 제공한다.
- 이미지에 대체 텍스트, 컨트롤에 명확한 접근 가능한 이름을 제공한다.
- 상태는 색상만으로 구분하지 않고 라벨 텍스트를 병기한다.
- 알레르기·주의는 아코디언에만 숨기지 않는다.
- 포커스 표시, 최소 44×44px 터치 영역, WCAG AA 대비를 목표로 한다.
- 오류와 필터 결과 변화는 `aria-live`로 알린다.

## 가정 및 보류

- `가정`: 제품 옵션·필터 항목, 회원 로그인, 구매 채널·CTA, 전체 검색·브레드크럼, 반응형 수치.
- `HOLD`: QR 배치 추적, 미생물 데이터, 실제 근거 없는 인증·시험 수치.
- `제외`: 장 건강·붓기·목 보호·피부 개선 등 미검증 효능과 공포·질환 중심 이미지.
