# YOVIA VC-005 화면 설계서

## 프로젝트 및 설계 범위

VC-005 최예린의 제품 중심 크리에이티브와 모바일 발견→이해→행동 흐름을 15개 화면으로 설계한다. 실제 제품 자산과 상태가 중심이며 미확정 맛·제품군·효능·CTA는 공개 사실로 다루지 않는다.

## 공통 구성과 UI 요소

- 헤더: 브랜드, 제품, 사용 방법, 사용 장면, 제품 정보, 콘텐츠.
- 본문: 화면 ID, 대표 이미지, 짧은 설명, 상세 정보, 자산 상태, 다음 행동.
- 푸터: 자산·정보 검증 원칙과 홈 링크. 사용권·법적 고지는 실제 운영 자료 확정 전 `가정`.
- 반복 컴포넌트: 제품 카드, 갤러리, 썸네일, 단계 표시, 상황 카드, 컬러+텍스트 라벨, 상태 배지, CTA.
- 이미지: 목적이 명확한 대체 텍스트. CONCEPT 이미지는 실제 제품과 시각·텍스트로 구분.

## 유효성 검사와 오류 메시지

| 조건 | 메시지 | 처리 |
|---|---|---|
| 필터 값 오류 | `선택한 조건을 확인해 주세요.` | 조건 해제 |
| 제품군 결과 없음 | `확정된 제품군 정보가 없습니다.` | SCR-014 |
| 자산 미확정 | `실제 제품 자산으로 확인되지 않았습니다.` | 상태 표시·CTA 차단 |
| 이미지 로드 실패 | `이미지를 불러오지 못했습니다.` | 대체 텍스트·SCR-015 |
| CTA 미확정 | `다음 행동은 준비 중입니다.` | SCR-013 |

## 반응형 기준

- 모바일 0~767px: 1열, 대표 이미지→설명→상세 갤러리, CTA 전체 폭, 스와이프 대체 버튼 제공.
- 태블릿 768~1199px: 카드 2열, 본문 최대 960px.
- PC 1200px 이상: 카드 3열, 본문 최대 1200px, GNB 펼침.
- 수치는 구현 전 조정 가능한 `가정`이다.

## 접근성 요구사항

- 제목·랜드마크·건너뛰기 링크와 키보드 갤러리 탐색을 제공한다.
- 모든 이미지에 구체적 대체 텍스트, 확대 컨트롤에 접근 가능한 이름을 둔다.
- 컬러 라벨은 텍스트를 병기하고 WCAG AA 대비를 목표로 한다.
- 최소 44×44px 터치 영역, 명확한 포커스, `aria-live` 상태 알림을 제공한다.
- 자동 재생 미디어는 사용하지 않으며 축소 동작 선호를 존중한다.

## 가정 및 보류

- `가정`: 최종 컬러·라인업·맛·필터, CTA 목적지, 검색·브레드크럼, 반응형 수치.
- `NOT_VERIFIED/HOLD`: 최종 패키지·촬영·사용권·효능 자료.
- `CONCEPT`: 합성·콘셉트 자산은 실제 제품과 명확히 구분하고 기본 공개하지 않음.
