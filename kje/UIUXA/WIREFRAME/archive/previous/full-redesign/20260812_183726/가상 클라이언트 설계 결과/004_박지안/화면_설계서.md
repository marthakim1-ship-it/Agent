# YOVIA VC-004 화면 설계서

## 프로젝트 및 설계 범위

VC-004 박지안의 모바일 일상 적합성·전환 여정을 14개 화면으로 설계한다. 상황 공감→사용 방법→제품 비교→신뢰 정보→제품 상세→조건부 행동을 다룬다. 커머스 정책과 반복 구매는 확정하지 않는다.

## 화면 ID 규칙과 전체 화면 목록

`SCR-001`부터 순차 부여하며 MD·HTML·JSON에서 동일하게 사용한다.

## 공통 구성과 UI 요소

- 헤더: 로고, 사용 상황, 사용 방법, 제품, 제품 비교, 제품 정보.
- 본문: 화면 ID·현재 위치·생활 장면/제품 요약·상태·다음 행동.
- 푸터: 정보 원칙과 홈 링크. 배송·반품·구독 정책 링크는 근거 확정 전 제외.
- 반복 컴포넌트: 상황 카드, 제품 카드, 비교표, 상태 라벨, 단계 표시, 목적별 CTA.
- 이미지: 실제 생활·제품 장면 플레이스홀더와 대체 텍스트. 과장된 운동·의료 이미지는 제외.

## 유효성 검사와 오류 메시지

| 조건 | 메시지 | 처리 |
|---|---|---|
| 비교 필터 값 오류 | `선택한 조건을 확인해 주세요.` | 조건 해제 |
| 비교 결과 없음 | `조건에 맞는 제품이 없습니다.` | SCR-012 |
| 제품 옵션 미확정 | `확인되지 않은 옵션입니다.` | NOT_VERIFIED |
| 판매 채널 미확정 | `판매처 정보는 준비 중입니다.` | SCR-013 |
| 가격·배송·할인 미확정 | `구매 정책이 확인되지 않았습니다.` | SCR-010, CTA 차단 |
| 외부 연결 실패 | `판매처로 연결하지 못했습니다.` | SCR-014 |
| 이미지 실패 | `이미지를 불러오지 못했습니다.` | 대체 텍스트 유지 |

## 반응형 기준

- 모바일 0~767px: 1열, 접이식 메뉴, 장면→가치→비교→행동 순서, CTA 전체 폭.
- 태블릿 768~1199px: 카드 2열, 본문 최대 960px.
- PC 1200px 이상: 카드 3열, 본문 최대 1200px, GNB 펼침.
- 수치는 구현 전 조정 가능한 `가정`이다.

## 접근성 요구사항

- 제목 계층, 랜드마크, 건너뛰기 링크, 키보드 탐색을 제공한다.
- 이미지 대체 텍스트와 최소 44×44px 터치 영역을 적용한다.
- 상태는 색상과 명시적 텍스트를 함께 사용한다.
- 포커스 표시와 WCAG AA 수준 대비를 유지한다.
- 오류·필터 결과 변화는 `aria-live`로 알린다.

## 가정 및 보류

- `가정`: 제품 옵션·필터, 로그인, 판매 채널·CTA, 검색·브레드크럼, 반응형 수치.
- `NOT_VERIFIED`: 가격·배송·할인·판매처.
- `HOLD`: 구독·반복 구매의 주기·혜택·변경·해지 관리.
