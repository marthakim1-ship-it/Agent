# YOVIA VC-011 화면 설계서

## 프로젝트 및 설계 범위
사이트맵과 서비스 흐름도의 17개 화면 전체를 설계한다. 모바일에서 정의→구성→사용법→검증 순서를 유지하며 로그인·후속 행동 정책은 가정이다.

## 화면별 목적, 진입 조건, 종료 조건
위 목록의 목적·진입·다음 화면을 세 결과물에서 동일하게 사용한다. 정상 흐름은 SCR-001~011·014, 회원 가정은 SCR-012~013, 예외·복구는 SCR-015~017이다.

## 화면 구성 영역과 UI 요소
- 공통 헤더: 로고, 제품 소개, 제품 구성, 사용법, 검증 정보, 모바일 메뉴.
- 공통 본문: 화면 ID·이름, 현재 단계, 초심자 요약, 상태 라벨, 이전·다음 행동.
- 공통 푸터: 홈, 입문 다시 시작, 검증 정보.
- 반복 요소: 진행 표시, 구성 카드, 단계 카드, 용어 도움말, 상태 배지, 조건부 CTA.
- 이미지: 대체 텍스트가 있는 플레이스홀더. 실제 자산 없으면 CONCEPT.

## 기본·로딩·빈 상태·오류·완료 상태
- 기본: 제목·현재 단계·유효 정보·다음 행동 표시.
- 로딩: 제목과 이동 경로를 유지하고 진행 상태를 알림.
- 빈 상태: 없는 값을 만들지 않고 이유와 복구 행동 표시.
- 오류: 원인·영향·재시도·이전·홈 제공.
- 완료: 결과 요약과 계속 탐색 제공.

## 유효성 검사와 오류 메시지
| 조건 | 메시지 | 처리 |
|---|---|---|
| 제품 자산 없음 | 실제 제품 이미지가 준비되지 않았습니다. | 플레이스홀더·CONCEPT |
| 구성 근거 없음 | 확인되지 않은 제품 구성입니다. | NOT_VERIFIED |
| 용어 설명 없음 | 용어 설명이 준비되지 않았습니다. | 호출 화면 복귀 |
| 로그인 값 오류 | 입력한 정보를 확인해 주세요. | SCR-013 |
| 연결 결과 없음 | 현재 연결 가능한 결과가 없습니다. | SCR-015 |
| 정책·근거 미확정 | 다음 행동은 준비 중입니다. | SCR-016 |
| 경로·자산 실패 | 정보를 불러오지 못했습니다. | SCR-017 |

## PC·태블릿·모바일 반응형 기준
- 모바일 0~767px: 1열, 단계 순서 고정, CTA 전체 폭, 메뉴 접기.
- 태블릿 768~1199px: 카드 2열, 본문 최대 960px.
- PC 1200px 이상: 자산·설명 2열, 카드 3~4열, 본문 최대 1200px.
- 브레이크포인트는 구현 전 조정 가능한 가정이다.

## 접근성 요구사항
본문 바로가기, 랜드마크, 논리적 제목, 키보드 탐색, 명확한 포커스, 44px 터치 영역을 제공한다. 상태는 색상과 텍스트로 병기하고 이미지에 대체 텍스트를 제공한다. 오류와 단계 변화는 aria-live 후보로 알린다.

## 가정 및 보류
- 가정: 로그인, 최종 CTA, 판매 채널, 제품 자산, 최종 카피.
- HOLD: 가격·영양 수치·효능·인증·시험·대체 패키지 구조.
- 제외: 전체 검색, 복잡한 비교·필터, 미검증 효능 CTA.
