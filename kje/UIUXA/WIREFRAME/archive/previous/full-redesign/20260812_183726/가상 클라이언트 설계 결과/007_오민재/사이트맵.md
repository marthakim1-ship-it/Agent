# YOVIA VC-007 오민재 사이트맵

## 프로젝트 개요
용량·구성·가격을 같은 기준으로 비교하는 가치 정보을 모바일 우선으로 제공하는 사이트 구조다. 설계 근거는 VC007-REQ-001~006이며 입력에 없는 정책과 수치는 확정하지 않는다.

## 설계 근거와 핵심 사용자 목표
- MENU: 제품 가치, 가치 비교, 구성 비교, 구매 정책, 제품 상세, 검증 상태
- CONTENT: 용량, 구성, 가격, 단위 기준, 배송·할인 조건, 기준일, 편익, 보류 정책
- FUNCTION: 비교 카드, 정책 라벨, 필터, 단위 계산 후보, 1열 카드, CTA 차단
- 핵심 목표: 탐색 기준을 이해하고, 근거와 적용 범위를 확인한 뒤 확정 가능한 행동으로 이동한다.
- 공개 통제: 대용량·번들·구독·포만감은 NOT_VERIFIED/HOLD로 표시하고 CTA에서 제외한다.

## 전역 내비게이션 구조
- 공통: 홈, 제품 가치, 가치 비교, 제품 상세
- 상태·근거: 검증 상태
- 회원 상태별: 로그인은 **가정: 핵심 행동에 인증이 필요한 경우**만 노출한다.
- 예외: 결과 없음, 입력 오류 안내, 오류 안내에서 이전 유효 화면 또는 홈으로 복구한다.

## 계층형 사이트맵
- 1차 — 홈
  - 2차 — 제품 가치
  - 2차 — 가치 비교
  - 2차 — 구성 비교
  - 2차 — 제품 상세
  - 2차 — 구매 정책
  - 2차 — 검증 상태
    - 3차 — 다음 행동
    - 3차 — 로그인
    - 3차 — 준비 중 안내
    - 3차 — 결과 없음
    - 3차 — 입력 오류 안내
    - 3차 — 오류 안내

## 주요 사용자 여정과 검토
홈 → 탐색 → 선택 → 상세 확인 → 핵심 행동 → 결과 확인 순서를 유지한다. 로그인 여부, 입력 오류, 결과 없음, 이전 단계 이동을 조건부로 포함했다. 공유 화면은 단일 노드로 유지했고 모든 예외 화면은 복구 경로가 있다.

## 가정
- 실제 제품 데이터, 기준일, CTA와 인증 정책은 미확정이다.
- 검색·필터·계산은 입력 데이터가 확정된 뒤 활성화한다.
- 대용량·번들·구독·포만감은 근거가 확보될 때까지 공개하지 않는다.
