# 가상클라이언트 기반 분석 결과 — VC-001 (서하린)

## 1. 가상 클라이언트

- **프로젝트 주제**: 바쁜 20~30대 직장인·대학생이 YOVIA의 그릭요거트 기반 올인원 경험을 빠르게 이해하고, 확정된 제품 정보와 행동으로 이동하게 하는 사이트 요소 후보를 분석한다.
- **제작 목적**: 첫 화면에서 브랜드·제품 정의와 일상 편익을 함께 전달하고, 파우치·빌트인 스푼·토핑의 관계와 사용 과정을 실제 제품 자산으로 설명한다. 원료·영양·알레르기·효능·가격·판매 정보는 확인된 근거만 사용한다.
- **제공 자료**: `SRC-BRAND-001`, `SRC-PDF-001`, `SRC-PDF-002`, `SRC-PDF-003`, `SRC-PER-001`, `SRC-PER-002`; `EVD-0001~EVD-0010`; 리서치 `SITE-001~SITE-200` 중 유효 197개.
- **적용 매체**: 모바일 웹 우선, 데스크톱 확장. 브랜드 정의→제품 이해→사용 상황·방법→신뢰 정보→확정 CTA의 의미와 순서를 유지한다.

### 3.1 유사 항목 분류

- **같은 목적의 통합**: 동일한 메뉴에 연결된 Requirement는 하나의 정보 그룹으로 묶고, 각 Requirement ID와 근거는 유지했다.
- **중복 처리**: 같은 의미의 메뉴·콘텐츠·기능은 대표 레이블 아래 통합했다. 서로 다른 검증 상태나 적용 범위는 합치지 않았다.
- **제외·보류**: 보류, HOLD, NOT_VERIFIED 항목은 확정 메뉴·CTA·카피에서 제외하고 검토 상태로 남겼다.
- **노출 우선순위**: 높음 요구를 핵심 정보, 보통 이상을 보조 정보, 보류를 비공개 검증 항목으로 배치한다.
- **자료 유형**: 제품 형태·구조는 이미지, 사용 순서는 이미지·영상, 사실·주의·정책은 텍스트, 수치·상태·비교는 검증된 데이터셋으로 분류한다. 실제 자료가 없으면 대체 자산을 생성하지 않는다.

```text
├─ 행동·지원
│  ├─ 다음 행동
│  │  └─ CTA 목적과 도착 정보 · 제품 상세·판매처 연결 후보
```

- **메뉴 후보 원본 수**: 11개
- **통합 상위 그룹 수**: 5개
- **메뉴 폭 검토**: 적합 — 상위 그룹 5개로 권장 폭 5~9개 안에 있다.
- **메뉴 깊이 검토**: 프로젝트 → 상위 그룹 → 메뉴 → 콘텐츠·기능의 3단계로, 최대 5단계 이내다.
- **레이블 검토**: 상위 그룹과 메뉴는 명사형으로 통일하고, 같은 의미의 레이블은 하나로 합쳤다. 이름만 보고 목적을 알 수 없는 상태·기술 분류명은 사용자용 메뉴로 사용하지 않는다.
## 4. 내비게이션

- **시작 화면**: YOVIA의 제품 정의, 실제 제품 이미지, 바쁜 일상에서 해결하는 문제를 함께 보여주고 제품 구조 또는 사용 상황으로 이동하는 후보가 필요하다 (`VC001-REQ-001~003`; `SITE-001`, `SITE-015`, `SITE-016`, `SITE-176`).
- **이동 경로**: 브랜드·제품 정의 → 제품 구조 → 사용 상황·방법 → 성분·영양·검증 정보 → 제품 비교·상세 → 확정 행동의 후보 흐름을 둔다. 모바일에서도 이 의미 순서를 유지한다 (`VC001-REQ-001~010`).
- **연결 페이지**: 상황 콘텐츠는 관련 제품·사용 방법으로, 제품 구조와 사용법은 성분·신뢰 정보와 제품 상세로 연결한다. 제품 확인·비교·판매처 확인은 실제 채널이 확정된 경우에만 CTA로 사용한다 (`VC001-REQ-003`, `VC001-REQ-005`, `VC001-REQ-010`; `SITE-015`, `SITE-016`, `SITE-176`).
- **검색 및 위치 안내**: 제품군·상황·속성 필터 후보는 비교·필터가 확인된 93/197의 패턴과 연결되지만 YOVIA 옵션이 미확정이다. 전체 검색·브레드크럼은 직접 요구와 충분한 근거가 없어 `not_verified`다.

### 4.1 내비게이션 유형 검토

- **글로벌 내비게이션 후보**: 브랜드·캠페인, 제품 이해, 이용 안내, 신뢰·안전 정보, 행동·지원. 이는 Client별 상위 탐색 그룹이며 최종 GNB 확정안이 아니다.
- **로컬 내비게이션 후보**: 각 상위 그룹 아래에 위 계층 구조의 메뉴 후보를 배치한다.
- **브레드크럼**: 직접 진입과 현재 위치 이해가 필요한 화면에서 상위 그룹 → 메뉴 → 현재 콘텐츠 경로 후보를 제공한다.
- **검색창**: 실제 문서량·검색어·색인 정책이 확인된 경우에만 적용하며, 미확정이면 `not_verified`로 유지한다.
- **풀다운 메뉴**: 하위 메뉴가 복수이고 모바일 접근성·키보드 동작이 검증된 경우에만 사용한다.
- **사이트맵**: 위 계층 구조를 후보로 사용하되 다른 Client 결과와 통합하기 전에는 최종 사이트맵으로 확정하지 않는다.
- **레이블 일관성**: 글로벌·로컬·브레드크럼·링크에서 동일한 메뉴명을 유지한다.
## 5. 화면 구성

- **헤더**: 브랜드 정의, 제품, 사용 방법·상황, 성분·영양으로 진입하는 후보와 확정 CTA 후보를 검토한다. 실제 메뉴 개수와 배치는 확정하지 않는다 (`VC001-REQ-001`, `VC001-REQ-004`, `VC001-REQ-005`).
- **내비게이션**: 모바일 흐름이 확인된 87/197의 기록을 바탕으로 핵심 정보와 행동이 뒤로 밀리지 않는 1열 후보를 둔다. 제품군 컬러는 텍스트 라벨과 함께 탐색 단서로 사용한다 (`VC001-REQ-005`, `VC001-REQ-007`).
- **핵심 콘텐츠**: 실제 제품 구조, 파우치·스푼·토핑 관계, 출근·등교·이동·업무 장면과 단계별 사용법을 우선 후보로 둔다. 빌트인 스푼 동일 사례는 0/197이므로 타사 캡·스파웃을 동일 구조로 표현하지 않는다 (`VC001-REQ-002`, `VC001-REQ-003`, `VC001-REQ-006`).
- **보조 콘텐츠**: 원료·영양·알레르기, 제품 비교, 품질 시험과 근거 상태를 제공하되 실제 YOVIA 자료가 없는 수치·효능·가격·인증·옵션은 `not_verified` 또는 `HOLD`로 표시한다 (`VC001-REQ-004`, `VC001-REQ-008~013`).
- **푸터**: 판매·배송·정책·시험 문서 연결은 실제 채널과 책임 자료가 확정된 경우에만 검토한다. 현재 푸터 구성은 `not_verified`다.

### 5.1 화면 배치 우선순위

| 화면 영역 | 배치 원칙 | 자료 유형 |
|---|---|---|
| 헤더 | 브랜드 식별과 현재 Client의 핵심 상위 탐색을 우선하고 미확정 CTA는 제외 | 텍스트·로고 |
| 내비게이션 | 현재 위치, 상위·하위 메뉴, 이전 단계와 관련 정보 연결 | 텍스트·링크 |
| 바디 | 높음 Requirement의 핵심 사실·과정·이미지를 먼저 배치 | 텍스트·이미지·영상·검증 데이터 |
| 어사이드 | 관련 자료, 기준일, 상태, 보조 행동만 배치하며 모바일에서는 본문 뒤로 이동 | 텍스트·상태 데이터 |
| 푸터 | 확정된 기업·정책·문의·저작권 정보만 연결 | 텍스트·링크 |

- **사용자 행동 경로**: 핵심 정보 이해 → 조건·근거 확인 → 관련 정보 비교 → 확정된 다음 행동 순서를 유지한다.
- **반응형 원칙**: 웹과 모바일에서 정보 의미와 이동 순서는 동일하게 유지한다. 모바일에서는 1열로 재배치하되 핵심 정보·주의·CTA의 상대적 우선순위를 바꾸지 않는다.
- **화면 전환 원칙**: 링크명과 도착 화면의 제목을 일치시키고 오류·빈 상태·보류 상태에서는 이전 유효 화면과 상시 정보로 복귀할 수 있게 한다.
## 6. 검토 결과

- **누락 항목**: 원본 13개 Requirement를 모두 2~5번의 후보 또는 보류 판단에 연결했다. 실제 제품 이미지·부품명·사용 동선, 원료·영양·알레르기 문서, 제품 옵션, 판매 채널·CTA, 누수·오염·잔여물·폐기 시험, 대체 패키지, 건강·효능 근거는 추가 입력이 필요하다.
- **중복 항목**: 브랜드·상황·모바일 전환, 제품 구조·사용법, 성분·근거·효능 통제, 제품 비교·CTA를 각각 연결하되 13개 Requirement의 목적과 상태는 유지했다. 다른 Client 결과를 VC-001 근거로 사용하지 않았다.
- **사용자 관점의 개선점**: 첫 화면에서 브랜드 감성만 전달하기보다 제품 형태와 사용 이유를 동시에 이해시켜야 한다. 사용자는 실제 구조와 단계, 성분·신뢰 정보를 확인한 뒤에만 비교·구매 판단으로 이동할 수 있어야 한다.
- **수정 사항**: 전체 200개 기록을 다시 분리해 `completed` 101개와 `partial` 96개, 총 유효 197개를 확인했다. `SITE-036`, `SITE-113`, `SITE-152`는 `dead/failed`로 제외했다. `partial`은 확인된 필드만 사용했고 `not_verified`는 관찰 수에서 제외했다. 현재 결과 폴더에 기존 VC-001 파일이 없어 별도 아카이브 없이 규정 파일명으로 새로 작성했다.
- **보류·충돌·근거 부족**: 빌트인 스푼 동일 사례와 누수·내압·잔여물, 듀얼 챔버·스파우트·특수 실링의 직접 기록은 각각 0/197이다. 미확정 용량·단백질 수치·가격·인증·효능·구독·출시일은 생성하지 않는다. 운전 중 취식 장면은 안전상 제외한다.
- **검증 결론**: 조건부 완료. 유효 사이트 197개를 기준으로 MENU 11개, CONTENT 13개, FUNCTION 11개 후보를 도출했으며, 근거가 없는 제품 사양·시험·효능·커머스 정보는 `not_verified` 또는 `HOLD`로 유지했다.
### 6.1 반복 검토 체크리스트

- **요청 반영**: 원본 Requirement ID가 요구사항 표와 정보 구조에 모두 연결되어 있다.
- **누락·중복**: 누락 입력은 별도로 기록하고 중복 후보는 대표 레이블로 통합했다.
- **탐색 가능성**: 시작 화면, 이동 경로, 연결 페이지와 현재 위치 안내를 명시했다.
- **메뉴 깊이**: 3단계로 최대 5단계 이내다.
- **항목명 일관성**: 계층 구조·내비게이션·화면 구성에서 같은 명칭을 사용한다.
- **구조 변경 영향**: 상위 그룹 변경 시 로컬 메뉴·브레드크럼·관련 링크·화면 제목을 함께 점검한다.
- **웹·모바일 일관성**: 의미·우선순위·행동 순서를 유지하고 배치만 반응형으로 조정한다.
