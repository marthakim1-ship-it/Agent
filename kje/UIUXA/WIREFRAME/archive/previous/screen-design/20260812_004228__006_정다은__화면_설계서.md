# YOVIA VC-006 정다은 화면 설계서

## 프로젝트 및 설계 범위

사이트맵과 서비스 흐름도의 전체 15개 화면을 대상으로 모바일 우선 저충실도 UI를 정의한다. 맛·질감·토핑과 실제 제품 자산을 연결하며 `CONFIRMED`·`CONCEPT`·`NOT_VERIFIED`·`HOLD`를 명시한다. 최종 라인업, 감미료, 효능, 인증, 구매 CTA는 입력에 없으므로 확정하지 않는다.

## 화면 ID 규칙과 전체 화면 목록

ID는 `SCR-001`부터 사용자 여정 순서로 부여한다.

| ID | 화면 이름 | 영역 | 목적 |
|---|---|---|---|

| SCR-002 | 제품 탐색 | 공통 | 제품 후보 탐색 |
| SCR-003 | 맛·식감 탐색 | 공통 | 감각 기준 탐색 |
| SCR-004 | 제품 비교 | 공통 | 감각 차이 비교 |
| SCR-005 | 제품 상세 | 공통 | 이해·근거·행동 통합 |
| SCR-006 | 제품 갤러리 | 공통 | 실제 이미지 세부 확인 |
| SCR-007 | 제품 정보 | 공통 | 적용 제품과 근거 확인 |

## 화면별 상세 정의

| ID·화면 | 진입 조건 → 종료 조건 | 구성 영역·UI 요소 | 표시 데이터 | 사용자 행동·인터랙션 → 이동 |
|---|---|---|---|---|
| SCR-001 홈 | 최초/오류 복구 → 탐색 선택 | 헤더, 대표 이미지, 상태 배지, 탐색 카드, 푸터 | 확인된 제품명·감각 요약 | 카드 선택 → SCR-002/003 |
| SCR-002 제품 탐색 | 홈/복구 → 후보 선택 | 필터, 제품 카드, 텍스트 상태 | 확정 제품 후보 | 필터·비교·선택 → SCR-004/005; 없음 → 013 |
| SCR-003 맛·식감 탐색 | 홈/GNB → 감각 조건 선택 | 맛·질감·토핑 컨트롤, 범례 | 확정 감각 용어 | 선택·초기화 → SCR-004/005; 오류 → 014 |
| SCR-004 제품 비교 | 탐색 → 제품 선택 | 비교 슬롯, 행 머리글, 상태 배지 | 맛·질감·토핑·자산 상태 | 제거·선택 → SCR-005; 입력 오류 → 014 |
| SCR-005 제품 상세 | 탐색/비교 → 근거 또는 행동 | 대표 이미지, 요약, 상태, 근거, CTA | 실제 제품 자산과 확정 정보 | 갤러리/정보/행동 → 006/007/010 |
| SCR-006 제품 갤러리 | 상세 → 상세 복귀 | 이미지, 썸네일 버튼, 확대, 캡션 | 실제 이미지·대체 텍스트 | 전환·스와이프 → SCR-008/005 |
| SCR-007 제품 정보 | 상세 → 상세 복귀 | 요약, 아코디언, 보류 박스 | 적용 제품·원료/영양 연결 | 펼치기 → SCR-009/005 |
| SCR-008 자산 상태 | 갤러리 → 검증 확인 | 상태 범례, 자산 목록, 출처 | CONFIRMED/CONCEPT/NOT_VERIFIED | 필터 → SCR-009/006 |
| SCR-009 검증 상태 | 정보/자산 → 제품 복귀 | 상태 탭, 공개 목록, HOLD 목록 | 공개 여부·근거 수준 | 관련 제품 → SCR-005/007 |
| SCR-010 다음 행동 | 확정 상세 → 결과/복구 | 행동 목적, 도착 정보, CTA | 확정 여부 | 실행 → SCR-011/012 또는 완료 |
| SCR-011 로그인 | **가정:** 인증 필요 → 행동 복귀 | 이메일, 비밀번호, 오류 요약 | 사용자 입력 | 제출 → SCR-010; 오류 → 014 |
| SCR-012 준비 중 안내 | CTA 미확정 → 정상 흐름 복귀 | 상태 아이콘, 설명, 대체 버튼 | 준비 상태 | 상세/탐색 → SCR-005/002 |
| SCR-013 결과 없음 | 결과 없음 → 조건 초기화 | 빈 상태, 적용 조건, 초기화 | 선택 조건 | 초기화 → SCR-002/003 |
| SCR-014 입력 오류 안내 | 입력 오류 → 원 화면 복귀 | 오류 요약, 수정 안내 | 필드/조건 오류 | 이전 화면 → SCR-002/003/004/011 |
| SCR-015 오류 안내 | URL/로드 오류 → 재시도/홈 | 오류 코드, 재시도, 홈 | 안전한 오류 설명 | 재시도/홈 → SCR-001/005/006/007 |

## 화면 상태

| 상태 | 표현 원칙 | 적용 화면 |
|---|---|---|
| 기본 | 실제 데이터와 텍스트 상태 라벨 표시 | 전체 정상 화면 |
| 로딩 | 제목 유지, `aria-live` 상태 문구와 스켈레톤 | SCR-001~011 |
| 빈 상태 | 현재 조건과 초기화 버튼 제공 | SCR-002, 003, 013 |
| 오류 | 원인·수정 방법·복구 버튼을 함께 제공 | SCR-002~007, 011, 014, 015 |
| 완료 | 완료 문구와 다음 이동 제공 | SCR-010, 011 |
| 정보 미확정 | `NOT_VERIFIED` 또는 `HOLD`, CTA 숨김 | SCR-005, 007~010 |

## 유효성 검사와 오류 메시지

| 대상 | 규칙 | 메시지 |
|---|---|---|
| 감각 필터 | 공개된 선택지만 허용 | “확인 가능한 맛·식감 조건을 선택해 주세요.” |
| 제품 비교 | 최소 2개, **가정:** 최대 3개 | “비교할 제품을 2개 이상 선택해 주세요.” |
| 제품 상태 | `CONFIRMED`만 핵심 행동 연결 | “아직 검증되지 않은 정보로는 이 행동을 진행할 수 없습니다.” |
| 이메일 | **가정:** 이메일 형식 필수 | “올바른 이메일 형식을 입력해 주세요.” |
| 비밀번호 | **가정:** 빈 값 불가 | “비밀번호를 입력해 주세요.” |
| 이미지 | 로드 실패 시 대체 텍스트 유지 | “이미지를 불러오지 못했습니다. 제품 설명을 확인해 주세요.” |

오류는 색상만으로 표현하지 않고 필드 연결 설명과 오류 요약을 함께 제공한다.

## 반응형 기준

- 모바일: 0~767px. 단일 열, 대표 이미지→감각 요약→상태→근거→CTA 순서. 표는 가로 스크롤하며 행 제목을 유지한다.
- 태블릿: 768~1199px. 2열 카드, 상세는 이미지/정보 2열. 터치 대상 최소 44×44px.
- PC: 1200px 이상. 최대 콘텐츠 폭 1280px, 3열 카드와 고정 비교 머리글.
- 브레이크포인트는 구현 검증을 위한 **가정**이며 디자인 토큰 확정 시 조정한다.

## 접근성 요구사항

- 모든 이미지 플레이스홀더에 제품·질감·토핑 맥락의 대체 텍스트를 제공한다.
- 맛 상태는 색상과 텍스트·아이콘을 함께 사용하고 대비 4.5:1 이상을 목표로 한다.
- 키보드로 GNB, 필터, 비교, 갤러리, 아코디언, CTA를 순서대로 조작할 수 있어야 한다.
- 현재 화면·선택·확장·오류 상태를 의미론적 요소와 ARIA 속성으로 전달한다.
- 포커스 표시를 제거하지 않으며 오류 발생 시 오류 요약으로 포커스를 이동한다.
- 애니메이션·스와이프 외에도 버튼 방식의 동일한 조작을 제공한다.

## 가정 모음

1. 로그인과 회원 상태는 핵심 행동에 인증이 필요한 경우만 사용하는 조건부 가정이다.
2. 비교 최대 3개, 이메일 로그인, 브레이크포인트는 상세 정책 미확정에 따른 설계 가정이다.
3. 검색·필터·CTA는 최종 제품 라인업 및 사업 정책 확정 후 활성화한다.
4. 촬영 출처·사용권 표기는 실제 운영 자료가 제공될 때 확정한다.
5. 미확정 맛·감미료·효능은 공개하지 않고 `HOLD`로 유지한다.
