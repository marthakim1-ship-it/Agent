## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 반복 구매·정기배송 경험 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입, 핵심 화면에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: CATEGORY-001, BRAND-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 반복 구매·정기배송 경험 기준 상품 후보 탐색
- 진입: MAIN-001
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 빈 상태·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 반복 구매·정기배송 경험 근거 구분
- 진입: MAIN-001
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 이동: CATEGORY-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-001 반복 구매 조건
- 목적: 반복 구매·정기배송 경험 핵심 과업
- 진입: CATEGORY-001
- 구성: 단건/정기 비교, 일정 상태표
- 행동: 변경·해지 관리 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-002, CATEGORY-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-002 변경·해지 관리
- 목적: 반복 구매·정기배송 경험 검증 상태와 결과 확인
- 진입: TASK-001
- 구성: 근거·기준일, 상태·조건, 다음 행동·복구
- 행동: 메인으로, 이전 단계
- 상태: 기본, 로딩, NOT_VERIFIED, HOLD, 오류, 완료
- 이동: MAIN-001, TASK-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

## 공통 구조·반응형
본문 바로가기, 헤더, 상태, 푸터. 모바일 1열, 태블릿 2열, PC 3열이며 PRODUCT DOM 순서를 유지한다.
## 유효성·오류·접근성
오류마다 재시도·수정·이전 단계를 제공한다. 44px 조작 영역, 보이는 포커스, 이미지 대체 텍스트, 색상 외 상태 문구를 적용한다.
## Requirement 추적과 가정
- **VC025-REQ-001**: 단건 재구매와 정기 구매 조건을 동등하게 비교
- **VC025-REQ-002**: 현재 상태·다음 일정·비용·구성을 명확히 표시
- **VC025-REQ-003**: 변경·건너뛰기·해지를 가입과 동등하게 접근
- **VC025-REQ-004**: 알림과 자동 갱신에 별도 동의·복구 제공
- **VC025-REQ-005**: 모바일에서 적용 전·후 상태를 비교
- **VC025-REQ-006**: 정책 확정 전 구독·할인·배송 혜택 활성화 금지
실제 상품·가격·재고·정책·효능·인증은 NOT_VERIFIED 또는 HOLD다.
