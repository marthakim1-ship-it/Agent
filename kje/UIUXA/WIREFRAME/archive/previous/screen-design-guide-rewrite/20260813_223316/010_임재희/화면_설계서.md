# VC-010 임재희 화면 설계서
## 범위와 독립 설계 원칙
정보 접근성 분석만을 기준으로 핵심 3화면과 전용 과업 2화면을 설계한다. 전용 컴포넌트는 **텍스트 우선 요약·키보드 행동 목록**다.
## 화면 ID와 목록
| ID | 화면명 | 목적 |
|---|---|---|
| MAIN-001 | 메인페이지(홈) | 정보 접근성 관점의 브랜드·상품 탐색 시작 |
| CATEGORY-001 | 카테고리 페이지 | 정보 접근성 기준으로 상품 후보를 탐색 |
| BRAND-001 | 브랜드 소개 페이지 | YOVIA 정의와 정보 접근성 관련 근거를 구분 |
| TASK-001 | 접근 가능한 정보 | 정보 접근성 핵심 과업 수행 |
| TASK-002 | 복구 행동 | 정보 접근성 검증 상태와 다음 행동 확인 |
## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 정보 접근성 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입 또는 CATEGORY-001, BRAND-001에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개 진입, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 접근성: 제목, 상태 텍스트, 키보드 포커스, 오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 정보 접근성 기준으로 상품 후보를 탐색
- 진입: 직접 진입 또는 TASK-001, MAIN-001에서 복귀
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 결과 없음·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 접근성: 제목, 상태 텍스트, 키보드 포커스, 오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 정보 접근성 관련 근거를 구분
- 진입: 직접 진입 또는 CATEGORY-001, MAIN-001에서 복귀
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품 탐색
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 접근성: 제목, 상태 텍스트, 키보드 포커스, 오류 복구

### TASK-001 접근 가능한 정보
- 목적: 정보 접근성 핵심 과업 수행
- 진입: 직접 진입 또는 TASK-002, CATEGORY-001에서 복귀
- 구성: 텍스트 우선 요약, 키보드 행동 목록
- 행동: 복구 행동 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 접근성: 제목, 상태 텍스트, 키보드 포커스, 오류 복구

### TASK-002 복구 행동
- 목적: 정보 접근성 검증 상태와 다음 행동 확인
- 진입: 직접 진입 또는 MAIN-001, TASK-001에서 복귀
- 구성: 근거·기준일, 상태·조건, 다음 행동·복구
- 행동: 메인으로, 이전 단계
- 상태: 기본, 로딩, NOT_VERIFIED, HOLD, 오류, 완료
- 접근성: 제목, 상태 텍스트, 키보드 포커스, 오류 복구

## 공통 구조·반응형
본문 바로가기, 전역 내비게이션, 상태 영역, 푸터를 공통 적용한다. 모바일 1~2열, 태블릿 2~3열, PC 3~5열이며 PRODUCT DOM 순서는 유지한다.
## 유효성·오류
필수 입력 누락은 필드 인접 문구로 알리고 오류마다 재시도·수정·이전 단계 중 하나를 제공한다.
## 접근성
44px 조작 영역, 명확한 포커스, 의미 있는 제목, 이미지 대체 텍스트, 색상 외 상태 텍스트, 라이브 상태 안내를 적용한다.
## Requirement 추적
- **VC010-REQ-001** (높음): 핵심 정보·CTA 키보드·보조기술 탐색
- **VC010-REQ-002** (높음): 제품군·검증·오류를 색상만으로 구분 금지
- **VC010-REQ-003** (보통 이상): 이미지 대체 텍스트·컨트롤 이름
- **VC010-REQ-004** (보통 이상): 모바일 확대·1열에서도 순서·행동 유지
- **VC010-REQ-005** (보통 이상): 로딩·빈·오류·완료와 복구 명시
- **VC010-REQ-006** (보류): 검증 없는 접근성 준수·인증 표시 금지
## 가정·HOLD·제외
15개는 상품 슬롯 수이며 실제 라인업 수가 아니다. 미확정 상품 정보와 정책은 NOT_VERIFIED 또는 HOLD다.
