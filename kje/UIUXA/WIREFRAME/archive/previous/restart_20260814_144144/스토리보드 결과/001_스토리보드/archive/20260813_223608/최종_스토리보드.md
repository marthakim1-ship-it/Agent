## 8. 반응형 설계 기준

- 모바일 <768px: 단일 열, 15개 상품 DOM 순서 유지, CSS 가로 슬라이드.
- 태블릿 768~1199px: 2열 사용 가능, 읽기 순서는 모바일과 동일.
- 데스크톱 ≥1200px: 최대 폭 1280px, 2~3열 확장 가능.
- 320px CSS 폭과 텍스트 200% 확대에서 기능 손실 없음. 터치 대상은 최소 44×44px.
- 브레이크포인트는 구현 가정이며 콘텐츠 기준 재검증이 필요함.

## 9. 접근성 및 콘텐츠 기준

- header/nav/main/section/footer 랜드마크와 H1→H2 계층을 유지한다.
- 본문 바로가기를 첫 포커스로 두고 모든 카드·필터·슬라이드를 키보드로 이용할 수 있게 한다.
- 정보 이미지는 목적 중심 대체 텍스트, 장식 이미지는 빈 대체 텍스트를 사용한다.
- 상태·경고는 색상 외 텍스트로 병기하고 로딩·오류·완료는 라이브 영역 후보로 전달한다.
- WCAG 인증/준수는 감사 근거가 없으므로 NOT_VERIFIED이다.
