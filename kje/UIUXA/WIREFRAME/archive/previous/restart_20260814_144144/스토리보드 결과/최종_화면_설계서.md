# YOVIA 최종 화면 설계서

> 작성 기준: `최종_와이어프레임_화면설계서_가이드.txt`  
> 통합 범위: VC-001~030  
> 화면 구성: MAIN-001, CATEGORY-001, BRAND-001  
> 상태 기준: 확인되지 않은 제품·가격·후기·정책 정보는 확정하지 않으며 `NOT_VERIFIED` 또는 `HOLD`로 관리한다.

## 1. MAIN-001 — 메인페이지(홈)

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | YOVIA 메인페이지(홈) |
| 화면 목적 | YOVIA의 핵심 가치를 소개하고 사용자가 목적에 맞는 상품 탐색, 카테고리 확인, 브랜드 정보 확인을 시작하도록 돕는다. |
| 주요 콘텐츠 | 브랜드명, 목적 중심 히어로 문구, 상품 15개 영역(`PRODUCT-001~015`), 소비자 후기 빈 상태, 정책·문의 안내 영역. 상품명·이미지·가격·효능과 실제 후기는 자료 확보 전까지 미확정으로 표시한다. |
| 인터페이스 요소 | 본문 바로가기, 헤더, 주 내비게이션, 히어로 제목과 설명, 상품 카드, CSS 가로 슬라이드, 상태 라벨, 조건부 링크, 후기 빈 상태 카드, 푸터 링크. |
| 레이아웃 | 상단부터 본문 바로가기 → 헤더·내비게이션 → 히어로 → 상품 15개 슬라이드 → 소비자 후기 → 푸터 순서로 배치한다. 모바일은 단일 열, 태블릿은 최대 2열, 데스크톱은 최대 3열과 1280px 콘텐츠 폭을 적용한다. |
| 작동 방식 | 카테고리 메뉴 선택 시 `CATEGORY-001`, 브랜드 메뉴 선택 시 `BRAND-001`로 이동한다. 상품 카드는 상세 목적지가 검증된 경우에만 이동하며, 미검증 상태에서는 링크와 CTA를 활성화하지 않는다. 슬라이드는 JavaScript 없이 CSS 스크롤 방식으로 동작한다. |
| 연결 화면 | `CATEGORY-001` 카테고리 페이지, `BRAND-001` 브랜드 소개 페이지. 상품 상세 화면은 목적지 검증 전까지 연결하지 않는다. |
| 사용자 경로 | 메인 진입 → 브랜드 가치 확인 → 상품 15개 탐색·비교 → 카테고리 상세 탐색 또는 브랜드 근거 확인 → 필요 시 메인으로 복귀. |
| 비고·주석 | 실제 상품 DB, 승인 이미지, 가격, 효능 근거, 후기 원문, 정책 및 문의 목적지가 필요하다. 모든 카드와 메뉴는 키보드로 접근 가능해야 하며 첫 포커스는 본문 바로가기에 둔다. 정보 이미지는 목적 중심 대체 텍스트를 제공한다. |

## 2. CATEGORY-001 — 카테고리 페이지

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | YOVIA 상품 카테고리 페이지 |
| 화면 목적 | 사용자가 목적과 조건에 따라 상품 후보를 좁히고 15개 상품을 비교하도록 지원한다. 결과 없음이나 오류가 발생해도 탐색을 복구할 수 있게 한다. |
| 주요 콘텐츠 | 현재 위치, 카테고리와 필터 후보, 정렬 조건, `PRODUCT-001~015` 상품 결과, 결과 없음 안내, 입력 오류 및 시스템 오류 복구 안내. 필터 체계와 상품 상세 정보는 검증 전까지 미확정으로 표시한다. |
| 인터페이스 요소 | 브레드크럼, 필터 그룹, 정렬 선택, 상품 카드, CSS 가로 슬라이드, 조건 초기화 버튼, 재시도 버튼, 홈 이동 링크, 상태 메시지. |
| 레이아웃 | 상단 현재 위치 → 필터·정렬 → 상품 결과 → 빈 상태·오류 복구 영역 순서로 배치한다. 모바일에서는 필터와 결과를 단일 열로 배치하고 상품은 터치 스크롤을 지원한다. 태블릿·데스크톱에서는 콘텐츠 폭에 따라 2~3열로 확장한다. |
| 작동 방식 | 사용자가 필터나 정렬 조건을 선택하면 결과 갱신 후보 상태를 표시한다. 결과가 없으면 조건 초기화를, 오류가 발생하면 재시도를 제공하며 마지막 유효 상태를 보존한다. 상품 상세 이동은 검증된 목적지가 있는 경우에만 허용한다. |
| 연결 화면 | `MAIN-001` 메인페이지, 검증된 경우의 상품 상세 화면. 오류가 반복되거나 복구가 어려운 경우 `MAIN-001`로 이동한다. |
| 사용자 경로 | 메인에서 상품 탐색 선택 → 카테고리 진입 → 필터·정렬 설정 → 상품 15개 비교 → 검증된 상품 상세 확인 또는 조건 수정 → 메인으로 복귀. |
| 비고·주석 | 필터 항목과 정렬 기준은 상품 데이터와 운영 정책 확정 후 결정한다. 필터는 `fieldset`과 `legend`로 묶고 선택 상태를 텍스트로 전달한다. 결과 변화와 오류는 라이브 영역 적용 후보로 관리한다. |

## 3. BRAND-001 — 브랜드 소개 페이지

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | YOVIA 브랜드 소개 페이지 |
| 화면 목적 | YOVIA의 확인된 브랜드 정의를 전달하고, 확정 정보와 미확정 정보를 구분해 사용자가 정보의 신뢰 범위를 이해하도록 한다. 이후 상품 탐색으로 자연스럽게 연결한다. |
| 주요 콘텐츠 | 확인된 브랜드 정의인 ‘그릭요거트 기반 간편 건강식’, 정보 상태 설명(`CONFIRMED`, `NOT_VERIFIED`, `HOLD`), 관련 제품 탐색 안내. 추가 브랜드 서사와 효능·환경 주장은 근거 확보 전까지 보류한다. |
| 인터페이스 요소 | 페이지 제목, 브랜드 설명, 상태 라벨과 상태 목록, 관련 제품 탐색 링크, 메인 복귀 링크. |
| 레이아웃 | 브랜드 정의 → 근거 상태 안내 → 관련 제품 탐색 순서의 단일 열 구조를 기본으로 한다. 화면 크기가 달라져도 읽기 순서와 제목 계층을 유지한다. |
| 작동 방식 | 상태 라벨을 통해 검증 수준을 텍스트로 안내한다. 관련 제품 탐색 링크 선택 시 `CATEGORY-001`로 이동하고, 미확정 주장과 CTA는 활성화하지 않는다. |
| 연결 화면 | `CATEGORY-001` 카테고리 페이지, `MAIN-001` 메인페이지. |
| 사용자 경로 | 메인에서 브랜드 메뉴 선택 → 브랜드 정의 확인 → 정보별 검증 상태 확인 → 관련 제품 탐색 선택 → 카테고리 페이지 이동. |
| 비고·주석 | 색상만으로 상태를 구분하지 않고 상태명을 함께 표시한다. 링크는 목적을 명확히 설명하고 최소 44×44px 터치 영역을 확보한다. 확정되지 않은 원료, 효능, 친환경성, 인증 관련 문구는 추가하지 않는다. |

## 4. 공통 화면 상태 및 처리 기준

| 상태 | 표시 및 처리 기준 | 사용자 복구 경로 |
|---|---|---|
| 기본 | 각 화면의 기본 정보와 현재 위치를 표시한다. | 세 화면 간 내비게이션 사용 |
| 로딩 | 상품 또는 후기 데이터를 불러오는 상태를 텍스트로 알린다. | 이전 유효 화면 유지 |
| 빈 상태 | 실제 후기가 없거나 검색 결과가 없음을 명확히 표시하며 임의 데이터를 생성하지 않는다. | 조건 초기화 또는 `CATEGORY-001` 이동 |
| 입력 오류 | 오류 원인과 수정 방법을 함께 표시하고 첫 오류 항목과 연결한다. | 조건 수정 후 재시도 |
| 시스템 오류 | 재시도 안내와 홈 이동 경로를 제공하고 마지막 유효 상태를 보존한다. | 재시도 또는 `MAIN-001` 이동 |
| 완료 | 정보 확인 또는 작업 완료를 텍스트로 알리고 다음 탐색 영역으로 초점을 이동한다. | 다음 화면 또는 이전 화면 이동 |
| NOT_VERIFIED | 제품·가격·정책·후기 등 미확정 정보를 라벨로 구분하며 확정 사실처럼 표현하지 않는다. | 이전 화면 또는 검증된 정보 확인 |
| HOLD | 효능·평점·정책 등 근거가 부족한 항목은 보류하고 관련 CTA를 비활성화한다. | `MAIN-001` 또는 `CATEGORY-001` 이동 |

## 5. 공통 접근성·반응형 기준

- `header`, `nav`, `main`, `section`, `footer` 랜드마크와 `H1 → H2` 제목 계층을 유지한다.
- 본문 바로가기를 첫 포커스로 제공하고 메뉴, 카드, 필터, 슬라이드를 키보드로 조작할 수 있게 한다.
- 상태와 경고는 색상 외에 텍스트로 함께 전달한다.
- 정보 이미지는 목적 중심 대체 텍스트를, 장식 이미지는 빈 대체 텍스트를 제공한다.
- 모바일 768px 미만은 단일 열, 태블릿 768~1199px은 최대 2열, 데스크톱 1200px 이상은 최대 3열을 기준으로 한다.
- 320px 화면 폭과 텍스트 200% 확대에서도 기능과 콘텐츠가 손실되지 않도록 한다.
- 터치 대상은 최소 44×44px로 설계한다.
- 접근성 준수 또는 인증은 별도 감사 결과가 없으므로 확정 표현하지 않는다.

## 6. 확정 전 필요한 자료

- `PRODUCT-001~015`의 실제 상품명, 이미지, 맛, 용량, 가격 및 상세 목적지
- 원료, 알레르기, 교차접촉 관련 승인 표시 정보
- 할인, 배송, 번들, 구독, 로그인 및 회원 운영 정책
- 효능, 감미료, 친환경성 등 규제·법무 검토가 필요한 주장 근거
- 출처, 작성 동의, 작성일을 포함한 실제 소비자 후기 원문
- 정책, 문의, 상품 상세 화면의 확정 URL과 이동 조건
- 접근성 감사 및 사용성 검증 결과

## 7. 최종 판정

화면 설계서 양식에 따른 3개 핵심 화면의 재작성은 완료되었다. 화면 목적, 콘텐츠, 인터페이스, 레이아웃, 작동 방식, 연결 구조와 사용자 경로는 정의되어 있으나 실제 상품·후기·운영 정책 자료가 없으므로 구현 확정 상태는 **조건부 완료**로 유지한다.
