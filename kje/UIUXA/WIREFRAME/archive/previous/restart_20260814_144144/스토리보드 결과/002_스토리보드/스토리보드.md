# VC-002 김도현 패키지 사용 경험 스토리보드

## 1. 제작 기준

- Client: VC-002 김도현
- 독립 설계 축: 패키지 사용 경험
- 입력: `002_김도현/사이트맵.md`, `서비스_흐름도.md`, `화면_설계서.md`
- 다른 Client 및 통합 `최종_스토리보드.md`: 입력으로 사용하지 않음
- 출력 화면: MAIN-001, CATEGORY-001, BRAND-001, TASK-001, TASK-002
- 표현: 회색 박스와 텍스트만 사용, JavaScript 제외

## 2. 핵심 사용자 흐름

```text
MAIN-001 메인페이지
→ CATEGORY-001 카테고리
→ 상품 후보 선택
→ TASK-001 사용 단계 안내
→ TASK-002 품질 근거
→ 결과 확인 또는 메인 복귀
```

브랜드 탐색은 `MAIN-001 → BRAND-001 → CATEGORY-001`로 연결한다. 로그인은 강제하지 않는다.

## 5. 상품 슬롯 계약

`PRODUCT-001~PRODUCT-015`는 실제 라인업이 아닌 설계 슬롯이다. 상품명·이미지·가격·용량·영양·효능·재고는 모두 `NOT_VERIFIED`이며, 각 슬롯은 `TASK-001 사용 단계 안내`의 조건부 후보로만 연결한다.

### 상품 슬라이드 설계

- MAIN-001에 15개 상품을 하나의 가로 슬라이드 트랙으로 배치한다.
- JavaScript 없이 CSS `overflow-x: auto`와 `scroll-snap-type`으로 구현한다.
- 첫 진입 시 모바일 1개, 태블릿 2개, 데스크톱 3개 카드와 다음 카드 일부가 보이게 한다.
- PRODUCT-001~015의 DOM 순서와 ID는 화면 크기와 관계없이 유지한다.
- 스크롤·스와이프·키보드로 조작하며, 트랙 자체에도 포커스를 제공한다.
- 트랙 위에 `15개 상품 · 가로로 이동`, 아래에 `PRODUCT-001 — PRODUCT-015` 범위를 표시한다.
- JavaScript가 필요한 비작동 이전·다음 화살표는 만들지 않는다.
