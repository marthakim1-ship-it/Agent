# YOVIA 최종 통합 화면 설계서

> 입력: `최종_통합_스토리보드.md`  
> 작성 기준: `최종_와이어프레임_화면설계서_가이드.txt`  
> 통합 범위: VC-001~VC-030  
> 최종 화면: `MAIN-001`, `CATEGORY-001`, `BRAND-001` — 총 3개

## 1. 문서 목적과 통합 원칙

본 문서는 001~030 개별 스토리보드에 반복 정의된 핵심 화면을 하나의 구현 기준으로 통합한 화면 설계서다. 각 클라이언트의 요구를 삭제하지 않고 공통 콘텐츠, 탐색 조건, 운영 상태 및 검증 항목으로 재배치한다.

- 확인된 브랜드 정의는 **YOVIA · 그릭요거트 기반 간편 건강식**으로 제한한다.
- 실제 상품명, 이미지, 맛, 용량, 가격, 재고, 효능, 후기 및 정책은 자료 확보 전까지 `NOT_VERIFIED` 또는 `HOLD`로 관리한다.
- 최종 사용자 화면은 메인, 카테고리, 브랜드 소개의 3개로 유지한다.
- 개별 스토리보드의 `TASK-001`, `TASK-002` 요구는 별도 화면을 추가하지 않고 세 화면의 콘텐츠 영역, 상태 패널, 조건부 링크 및 운영 기능으로 수용한다.
- 로그인, 구매, 구독, 알림, 문의, 기관 도입 등 운영 정책이 필요한 행동은 목적지와 정책이 확정된 경우에만 활성화한다.

| CATEGORY-001 | 상품 카테고리 페이지 | 조건별 상품 탐색·비교와 상세 정보 확인 | MAIN-001, BRAND-001, 조건부 상품 정보 영역 |

## 3. MAIN-001 — 메인페이지(홈)

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | YOVIA 메인페이지(홈) (`MAIN-001`) |
| 화면 목적 | 첫 방문자가 YOVIA의 브랜드와 제품 범위를 빠르게 이해하고, 개인 섭취·가족 안전·구매·기관 도입·지원 등 자신의 목적에 맞는 탐색 경로를 선택하도록 돕는다. 상품과 운영 정보의 검증 상태를 첫 단계에서 명확히 전달한다. |
| 주요 콘텐츠 | 브랜드 정의와 핵심 가치, 목적별 탐색 메뉴, 사용 상황 및 패키지 경험, 맛·식감·토핑 정보 후보, 상품 슬롯 `PRODUCT-001~015`, 원료·영양·알레르기 및 안전 정보 요약, 가격·구성 가치 후보, 판매·재고 상태, 후기 빈 상태, 캠페인·체험·기관 도입·고객지원 진입 후보, `CONFIRMED`·`NOT_VERIFIED`·`HOLD` 상태 안내. |
| 인터페이스 요소 | 본문 바로가기, 로고, 전역 내비게이션, 목적별 퀵 메뉴, 히어로 제목·설명, 조건부 CTA, 상품 카드 15개, CSS 가로 슬라이드, 상태 배지, 안전 공지 배너, 후기 빈 상태 카드, 언어·지역 표시 후보, 고객지원 링크 후보, 푸터. |
| 레이아웃 | 본문 바로가기 → 헤더·전역 내비게이션 → 히어로 → 목적별 탐색 → 사용 경험·핵심 정보 → 상품 15개 → 신뢰·안전·후기 상태 → 지원·운영 진입 → 푸터 순서로 배치한다. 모바일은 단일 열과 가로 스크롤, 태블릿은 2열, 데스크톱은 최대 3열과 1280px 콘텐츠 폭을 적용한다. |
| 작동 방식 | 카테고리 선택 시 `CATEGORY-001`, 브랜드 선택 시 `BRAND-001`로 이동한다. 상품 카드는 승인된 상세 정보가 있을 때만 상세 목적지를 제공한다. 미검증 구매·구독·알림·캠페인 CTA는 비활성 상태와 사유를 표시한다. 안전 공지는 일반 홍보보다 먼저 노출하며 오류 발생 시 마지막 유효 상태와 홈 복구 경로를 유지한다. |
| 연결 화면 | `CATEGORY-001`, `BRAND-001`. 제품 상세, 구매, 정기배송, 재고 알림, 체험 신청, 기관 도입 및 고객지원 목적지는 정책 확정 후 조건부 연결한다. |
| 사용자 경로 | 직접 진입 → 브랜드·제품 정의 확인 → 목적 선택 → 상품 15개 탐색 → 검증 상태 확인 → 카테고리 비교 또는 브랜드 근거 확인 → 조건부 전환 또는 메인 복귀. 안전 이슈가 있으면 진입 → 안전 공지 확인 → 영향 범위 확인 → 지원 경로 순으로 우선 처리한다. |
| 비고·주석 | 첫 포커스는 본문 바로가기에 둔다. 상품 카드 DOM 순서는 모든 화면 폭에서 유지한다. 개인정보와 행동 측정은 최소화하고 비필수 수집은 동의 전 실행하지 않는다. 승인되지 않은 효능·비교 우위·친환경·인증 문구를 사용하지 않는다. 이미지보다 제품 정보와 상태 텍스트를 우선한다. |

## 4. CATEGORY-001 — 상품 카테고리 페이지

| 구분 | 화면 설계 내용 |
|---|---|
| 화면명 | YOVIA 상품 카테고리 페이지 (`CATEGORY-001`) |
| 화면 목적 | 사용자가 성분, 알레르기, 맛, 식감, 토핑, 패키지 사용성, 보관 조건, 구성 가치 및 판매 상태 등 검증 가능한 조건으로 상품 후보를 좁히고 비교하도록 돕는다. 결과 없음과 오류를 구분해 탐색을 복구한다. |
| 주요 콘텐츠 | 현재 위치, 목적·제품 기준 필터, 정렬 기준, 상품 결과 `PRODUCT-001~015`, 상품별 이미지·이름·구성·원료·영양·알레르기·보관·가격·재고·판매 채널·검증 상태, 비교 안내, 빈 상태, 오류 메시지, 조건 초기화 및 재시도 안내. 미확정 값은 자리표시자와 상태 라벨로 표시한다. |
| 인터페이스 요소 | 브레드크럼, 검색 입력 후보, 필터 `fieldset`·`legend`, 체크박스·라디오·선택 목록, 정렬 컨트롤, 선택 조건 칩, 상품 카드, 비교 선택, CSS 슬라이드·스크롤, 결과 개수, 상태 메시지, 조건 초기화 버튼, 재시도 버튼, 홈·브랜드 링크. |
| 레이아웃 | 헤더 → 브레드크럼 → 검색·필터·정렬 → 선택 조건 요약 → 상품 결과 → 비교·상세 정보 → 빈 상태·오류 복구 → 푸터 순서로 배치한다. 모바일에서는 필터를 본문보다 먼저 읽을 수 있는 단일 열로 제공하고 상품 카드의 논리적 순서를 유지한다. 데스크톱에서는 필터 어사이드와 결과 바디를 2영역으로 구성할 수 있다. |
| 작동 방식 | 필터·정렬 변경 시 조건과 결과 상태를 함께 갱신한다. 실제 데이터 연결 전에는 동작 후보임을 표시한다. 상품 선택 시 승인된 상세 데이터가 있으면 동일 화면의 상세 영역 또는 확정된 목적지로 이동하고, 없으면 비활성 사유를 안내한다. 결과 없음은 조건 초기화를, 시스템 오류는 재시도를 제공하며 마지막 유효 조건을 보존한다. |
| 연결 화면 | `MAIN-001`, `BRAND-001`, 조건부 상품 상세·제품 이해 영역. 구매·판매처·정기배송·재고 알림·체험·문의는 운영 정책 확정 후 연결한다. |
| 사용자 경로 | 메인에서 상품 탐색 선택 → 카테고리 진입 → 목적·안전·감각·가격·보관 조건 설정 → 결과 확인 → 상품 비교 → 원료·표시·사용·판매 상태 확인 → 조건부 상세 또는 전환 → 조건 수정이나 메인 복귀. |
| 비고·주석 | 필터와 상품 속성은 실제 상품 DB의 필드가 확정된 후 최종 결정한다. 항목명·값·단위 관계를 화면 축소와 200% 확대에서도 유지한다. 알레르기와 안전 정보는 접힌 영역에만 숨기지 않는다. 가격·재고·배송 정보는 기준일과 적용 채널을 함께 표시한다. |

## 5. BRAND-001 — 브랜드 소개 페이지

| 사용자 경로 | 메인에서 브랜드 선택 → 브랜드 정의 확인 → 주장별 검증 상태와 운영 원칙 확인 → 안전·개인정보·콘텐츠 기준 확인 → 관련 상품 탐색 → 카테고리 이동 또는 메인 복귀. |
| 비고·주석 | 색상만으로 상태를 구분하지 않는다. 확정·미확정·보류의 의미와 기준일을 텍스트로 제공한다. 건강 효능, 친환경성, 패키지 성능, 인증 및 비교 우위는 증빙과 승인 전까지 브랜드 가치로 확정하지 않는다. 지역별로 다른 정보는 공통 정보와 분리한다. |

## 7. 공통 반응형·접근성 기준

- 모바일 768px 미만은 단일 열, 태블릿 768~1199px은 최대 2열, 데스크톱 1200px 이상은 최대 3열을 사용한다.
- 최대 콘텐츠 폭은 1280px을 기준으로 하되 정보 위계와 읽기 순서를 우선한다.
- 320px 화면 폭과 텍스트 200% 확대에서도 정보와 조작 기능이 손실되지 않게 한다.
- 모든 조작 대상은 최소 44×44px을 확보한다.
- `header`, `nav`, `main`, `section`, `aside`, `footer` 랜드마크와 `H1 → H2 → H3` 제목 계층을 유지한다.
- 본문 바로가기를 첫 포커스로 제공하고 카드, 필터, 슬라이드, 상태 패널을 키보드로 이용할 수 있게 한다.
- 정보 이미지는 목적 중심 대체 텍스트를, 장식 이미지는 빈 대체 텍스트를 제공한다.
- 로딩·오류·완료·결과 갱신은 라이브 영역 적용 후보로 관리한다.
- 상태와 경고는 색상 외 텍스트·아이콘·레이블을 함께 사용한다.
- 접근성 준수 또는 인증은 별도 감사 결과가 없으므로 `NOT_VERIFIED`다.

## 10. 최종 판정

가이드의 9개 필수 항목을 적용한 3개 핵심 화면의 통합 설계는 완료되었다. VC-001~030의 요구는 각 화면의 콘텐츠, 인터페이스, 상태 및 운영 기준으로 매핑되었다. 실제 상품·후기·정책·승인 자료가 부족하므로 구현 확정 상태는 **조건부 완료**이며, 미확정 기능과 주장은 활성화하지 않는다.
