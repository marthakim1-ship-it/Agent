# VC-027 유승호 사이트맵
## 프로젝트 개요
리뷰·커뮤니티 신뢰 분석을 기준으로 공통 핵심 3화면과 전용 과업 2화면을 구성한다.
## 설계 근거와 핵심 사용자 목표
- **VC027-REQ-001** (Must): 후기 의견과 공식 제품 사실을 명확히 분리
- **VC027-REQ-002** (Must): 구매 인증·협찬·샘플·작성 기준일 표시
- **VC027-REQ-003** (Should): 신고·정정·운영 답변과 상태 이력 제공
- **VC027-REQ-004** (Should): 긍정·부정 의견을 같은 탐색 기준으로 제공
- **VC027-REQ-005** (Should): 모바일에서도 이해관계·상태 라벨 유지
- **VC027-REQ-006** (Hold): 실제 데이터 없는 후기·평점·효능 경험담 생성 금지
대표 Site 근거: SITE-002, SITE-003, SITE-041, SITE-077, SITE-141
## 전역 내비게이션 구조
메인페이지 · 카테고리 · 브랜드 소개 · 후기 맥락 확인 · 신고·정정 상태
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 후기 맥락 확인
  - TASK-002 신고·정정 상태

## 공통·회원·예외
로그인을 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD와 재시도·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001의 PRODUCT-001~015는 실제 라인업이 아닌 NOT_VERIFIED 설계 슬롯이다.
## 연결성·가정
5개 화면은 시작점에서 도달·복귀 가능하다. 실제 상품·가격·재고·정책·효능·인증은 확정하지 않는다.
