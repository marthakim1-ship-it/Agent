# VC-003 이수민 서비스 흐름도
## 개요와 사용자
원료·영양 신뢰 요구를 가진 방문자가 로그인 없이 제품과 브랜드를 탐색한다.
## 시작·종료
시작은 MAIN-001이며 종료는 근거 검증 결과 확인 또는 유효 화면 복귀다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 원료·알레르기 정보 → TASK-002 근거 검증 → 결과 확인.
브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~PRODUCT-015는 모두 TASK-001 조건부 상세 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·이탈·재진입
결과 없음, 입력 오류, 외부·시스템 오류에 재시도·조건 완화·이전 단계·홈 복귀를 제공한다. 로그인은 정상 흐름에 강제하지 않는다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 오류 시 재시도·이전 단계 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 오류 시 재시도·이전 단계 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 오류 시 재시도·이전 단계 |
| TASK-001 원료·알레르기 정보 | 근거 검증 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 오류 시 재시도·이전 단계 |
| TASK-002 근거 검증 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 오류 시 재시도·이전 단계 |
## Requirement 추적
- **VC003-REQ-001** (높음): 락토프리·무가당 등 확정 정보와 실제 원료·영양·알레르기 정보를 분명히 구분
- **VC003-REQ-002** (높음): 영양 수치·인증·시험 결과는 실제 근거 문서가 있는 값만 노출
- **VC003-REQ-003** (높음): 건강·의료 효능을 검증 전 제품 가치나 구매 유도 문구로 사용하지 않음
- **VC003-REQ-004** (보통 이상): 모바일에서 핵심 성분과 상세 근거를 단계적으로 확인
- **VC003-REQ-005** (보통 이상): 전문성을 유지하되 병원 같은 공포·과도한 의학 이미지를 회피
- **VC003-REQ-006** (보류): QR 배치 추적·미생물 데이터 등 고도화 기능은 데이터 체계 검증 전 보류
## 연결성 검토
세 핵심 화면과 특화 화면의 이름·ID는 사이트맵과 일치하며 끊긴 정상 흐름이 없다.
