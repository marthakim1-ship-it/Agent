## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 재고 대기·출시 알림 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입, 핵심 화면에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: CATEGORY-001, BRAND-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 재고 대기·출시 알림 기준 상품 후보 탐색
- 진입: MAIN-001
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 빈 상태·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 재고 대기·출시 알림 근거 구분
- 진입: MAIN-001
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 이동: CATEGORY-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-001 판매 상태 확인
- 목적: 재고 대기·출시 알림 핵심 과업
- 진입: CATEGORY-001
- 구성: 상태 배지, 알림 동의 패널
- 행동: 알림 설정 관리 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-002, CATEGORY-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-002 알림 설정 관리
- 목적: 재고 대기·출시 알림 검증 상태와 결과 확인
- 진입: TASK-001
- 구성: 근거·기준일, 상태·조건, 다음 행동·복구
- 행동: 메인으로, 이전 단계
- 상태: 기본, 로딩, NOT_VERIFIED, HOLD, 오류, 완료
- 이동: MAIN-001, TASK-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

## 유효성·오류·접근성
오류마다 재시도·수정·이전 단계를 제공한다. 44px 조작 영역, 보이는 포커스, 이미지 대체 텍스트, 색상 외 상태 문구를 적용한다.
## Requirement 추적과 가정
- **VC029-REQ-001**: 판매 중·품절·출시 예정·미확정 상태를 명확히 구분
- **VC029-REQ-002**: 알림 목적·범위·채널·철회 방법을 신청 전에 제공
- **VC029-REQ-003**: 알림 없이도 제품·사용법·대체 정보 접근
- **VC029-REQ-004**: 상태 변경·신청·철회 결과를 명확히 확인
- **VC029-REQ-005**: 모바일에서 상태와 기준일을 첫 화면에 유지
- **VC029-REQ-006**: 가짜 품절·긴급성·미확정 출시일·재고 공개 금지
실제 상품·가격·재고·정책·효능·인증은 NOT_VERIFIED 또는 HOLD다.
