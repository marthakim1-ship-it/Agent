## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 주문 후 문제 해결 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입, 핵심 화면에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: CATEGORY-001, BRAND-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 주문 후 문제 해결 기준 상품 후보 탐색
- 진입: MAIN-001
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 빈 상태·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 주문 후 문제 해결 근거 구분
- 진입: MAIN-001
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 이동: CATEGORY-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

- 행동: 처리 상태 확인 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-002, CATEGORY-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

## 유효성·오류·접근성
오류마다 재시도·수정·이전 단계를 제공한다. 44px 조작 영역, 보이는 포커스, 이미지 대체 텍스트, 색상 외 상태 문구를 적용한다.
## Requirement 추적과 가정
- **VC028-REQ-001**: 안전 문제와 일반 주문 문제를 첫 단계에서 구분
- **VC028-REQ-002**: 주문·제품 식별에 필요한 최소 정보와 목적 표시
- **VC028-REQ-003**: 접수·검토·추가 정보·완료 상태와 다음 행동 제공
- **VC028-REQ-004**: 판매처·브랜드 책임 범위에 맞는 지원 경로 연결
- **VC028-REQ-005**: 모바일 입력 오류·업로드 실패의 복구 제공
- **VC028-REQ-006**: 미확정 환불·교환·보상 정책과 처리 기한 약속 금지
실제 상품·가격·재고·정책·효능·인증은 NOT_VERIFIED 또는 HOLD다.
