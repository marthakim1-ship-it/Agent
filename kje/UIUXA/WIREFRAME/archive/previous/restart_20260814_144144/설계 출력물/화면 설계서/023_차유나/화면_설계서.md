## 화면별 설계
### MAIN-001 메인페이지(홈)
- 목적: 냉장 유통·보관 정보 관점의 브랜드·상품 탐색 시작
- 진입: 직접 진입, 핵심 화면에서 복귀
- 구성: 브랜드·제품 가치, 카테고리 진입, 상품 15개, 브랜드 소개, 검증 상태
- 행동: 카테고리 보기, 브랜드 소개 보기
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: CATEGORY-001, BRAND-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### CATEGORY-001 카테고리 페이지
- 목적: 냉장 유통·보관 정보 기준 상품 후보 탐색
- 진입: MAIN-001
- 구성: 현재 위치, 정렬·필터 후보, 상품 결과, 빈 상태·복구
- 행동: 상품 후보 확인, 메인으로
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### BRAND-001 브랜드 소개 페이지
- 목적: YOVIA 정의와 냉장 유통·보관 정보 근거 구분
- 진입: MAIN-001
- 구성: 브랜드 정의, 그릭요거트 기반 간편 건강식, 근거 상태, 관련 제품
- 행동: 관련 제품 보기, 메인으로
- 상태: 기본, 로딩, 자료 없음, 오류, 완료
- 이동: CATEGORY-001, MAIN-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-001 보관 상태 안내

- 진입: CATEGORY-001
- 구성: 온도, 시간 조건표, 이상 상태 체크
- 행동: 이상 상태 확인 보기, 이전 단계
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 이동: TASK-002, CATEGORY-001
- 접근성: 제목·상태 텍스트·키보드 포커스·오류 복구

### TASK-002 이상 상태 확인

## 공통 구조·반응형

## 유효성·오류·접근성
오류마다 재시도·수정·이전 단계를 제공한다. 44px 조작 영역, 보이는 포커스, 이미지 대체 텍스트, 색상 외 상태 문구를 적용한다.
## Requirement 추적과 가정
- **VC023-REQ-001**: 보관·개봉·섭취 조건을 상태별 행동 지침으로 제공
- **VC023-REQ-002**: 이동 편의와 냉장 안전성을 서로 다른 주장으로 구분
- **VC023-REQ-003**: 수령·보관 중 이상 상태의 확인·문의 경로 제공
- **VC023-REQ-004**: 시간·온도·기준일·단위를 모바일에서 함께 표시
- **VC023-REQ-005**: 보관 안내 변경 시 제품·FAQ·공지 연결을 함께 갱신
- **VC023-REQ-006**: 근거 없는 상온 보관·신선도·유통기한 공개 금지
실제 상품·가격·재고·정책·효능·인증은 NOT_VERIFIED 또는 HOLD다.
