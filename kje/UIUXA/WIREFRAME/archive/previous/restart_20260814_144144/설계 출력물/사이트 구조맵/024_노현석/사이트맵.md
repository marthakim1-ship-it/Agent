# VC-024 노현석 사이트맵
## 프로젝트 개요
기업·캠퍼스 복지 도입 분석을 기준으로 공통 핵심 3화면과 전용 과업 2화면을 구성한다.
## 설계 근거와 핵심 사용자 목표
- **VC024-REQ-001** (Must): 개인용 제품 정보와 기관 도입 조건을 분리
- **VC024-REQ-002** (Must): 대상·알레르기·보관·배포 책임 체크리스트 제공
- **VC024-REQ-003** (Should): 기관 담당자가 필요한 자료와 미확정 항목 확인
- **VC024-REQ-004** (Should): 공식 담당 채널이 확정된 경우에만 도입 문의 연결
- **VC024-REQ-005** (Should): 모바일 요약과 데스크톱 비교 문서의 정보 일치
- **VC024-REQ-006** (Hold): 미확정 공급량·단가·납기·도입 사례 공개 금지
대표 Site 근거: SITE-001, SITE-012, SITE-017, SITE-041, SITE-077
## 전역 내비게이션 구조
메인페이지 · 카테고리 · 브랜드 소개 · 기관 도입 검토 · 도입 자료 확인
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 기관 도입 검토
  - TASK-002 도입 자료 확인

## 공통·회원·예외
로그인을 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD와 재시도·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001의 PRODUCT-001~015는 실제 라인업이 아닌 NOT_VERIFIED 설계 슬롯이다.
## 연결성·가정
5개 화면은 시작점에서 도달·복귀 가능하다. 실제 상품·가격·재고·정책·효능·인증은 확정하지 않는다.
