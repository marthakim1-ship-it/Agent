# VC-027 유승호 서비스 흐름도
## 개요와 시작·종료
리뷰·커뮤니티 신뢰 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 후기 맥락 확인 → TASK-002 신고·정정 상태 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 후기 맥락 확인 | 신고·정정 상태 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 신고·정정 상태 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC027-REQ-001**: 후기 의견과 공식 제품 사실을 명확히 분리
- **VC027-REQ-002**: 구매 인증·협찬·샘플·작성 기준일 표시
- **VC027-REQ-003**: 신고·정정·운영 답변과 상태 이력 제공
- **VC027-REQ-004**: 긍정·부정 의견을 같은 탐색 기준으로 제공
- **VC027-REQ-005**: 모바일에서도 이해관계·상태 라벨 유지
- **VC027-REQ-006**: 실제 데이터 없는 후기·평점·효능 경험담 생성 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
