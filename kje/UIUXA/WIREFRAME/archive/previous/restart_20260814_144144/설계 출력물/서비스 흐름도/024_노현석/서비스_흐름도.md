# VC-024 노현석 서비스 흐름도
## 개요와 시작·종료
기업·캠퍼스 복지 도입 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 기관 도입 검토 → TASK-002 도입 자료 확인 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 기관 도입 검토 | 도입 자료 확인 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 도입 자료 확인 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC024-REQ-001**: 개인용 제품 정보와 기관 도입 조건을 분리
- **VC024-REQ-002**: 대상·알레르기·보관·배포 책임 체크리스트 제공
- **VC024-REQ-003**: 기관 담당자가 필요한 자료와 미확정 항목 확인
- **VC024-REQ-004**: 공식 담당 채널이 확정된 경우에만 도입 문의 연결
- **VC024-REQ-005**: 모바일 요약과 데스크톱 비교 문서의 정보 일치
- **VC024-REQ-006**: 미확정 공급량·단가·납기·도입 사례 공개 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
