# VC-018 나유찬 화면 설계서

## 프로젝트 및 설계 범위
캠페인과 상시 제품 경험 연결을 위한 7개 저충실도 화면을 정의한다. 실제 거래·회원·외부 시스템 구현은 범위 밖이다.

## 화면 ID 규칙과 전체 목록
SCR-001부터 연속 부여하며 사이트맵·서비스 흐름도·JSON·HTML에서 동일하게 사용한다.

| ID | 화면명 | 목적 |
|---|---|---|
| SCR-001 | 캠페인 랜딩 | 유입 약속과 첫 화면 메시지 일치 |
| SCR-002 | 이용 조건 | 기간·대상·상태를 CTA 전에 설명 |
| SCR-003 | 제품 상세 | 캠페인과 검증된 제품 사실 연결 |
| SCR-004 | 행동 결과 | 행동 성공·실패와 다음 경로 제공 |
| SCR-005 | 캠페인 목록 | 진행·종료 상태별 캠페인 탐색 |
| SCR-006 | 종료·품절 안내 | 종료·품절 시 상시 제품으로 연결 |
| SCR-007 | 오류 안내 | 딥링크·외부 연결 오류 복구 |

## 공통 구조
- 헤더: 홈과 캠페인, 제품, 이용 조건 탐색.
- 본문: 제목, 목적, 핵심 콘텐츠, 상태, 주요·복구 행동.
- 푸터: 검증된 정책·문의 링크만 배치.

## 화면별 설계
### SCR-001 캠페인 랜딩
- 목적: 유입 약속과 첫 화면 메시지 일치
- 진입 조건: 직접 진입 또는 전역 내비게이션
- 종료 조건: 조건 확인 수행 또는 이전 단계 이동
- 구성/UI: 캠페인 메시지, 상태, 조건, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 조건 확인, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-002 이용 조건
- 목적: 기간·대상·상태를 CTA 전에 설명
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 제품 근거 보기 수행 또는 이전 단계 이동
- 구성/UI: 조건, 적용 범위, 기준일, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 근거 보기, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-003 제품 상세
- 목적: 캠페인과 검증된 제품 사실 연결
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 핵심 행동 수행 또는 이전 단계 이동
- 구성/UI: 제품 정의, 근거, 관련 캠페인, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 핵심 행동, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-004 행동 결과
- 목적: 행동 성공·실패와 다음 경로 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 캠페인으로 돌아가기 수행 또는 이전 단계 이동
- 구성/UI: 처리 상태, 다음 행동, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 캠페인으로 돌아가기, 이전 단계 이동 → SCR-001
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-005 캠페인 목록
- 목적: 진행·종료 상태별 캠페인 탐색
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 캠페인 보기 수행 또는 이전 단계 이동
- 구성/UI: 상태 텍스트, 캠페인 카드, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 캠페인 보기, 이전 단계 이동 → SCR-001
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-006 종료·품절 안내
- 목적: 종료·품절 시 상시 제품으로 연결
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 제품 보기 수행 또는 이전 단계 이동
- 구성/UI: 종료 상태, 관련 제품, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 보기, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-007 오류 안내
- 목적: 딥링크·외부 연결 오류 복구
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 목록으로 이동 수행 또는 이전 단계 이동
- 구성/UI: 유입 맥락, 재시도, 대체 경로, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 목록으로 이동, 이전 단계 이동 → SCR-005
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공


## 반응형 기준
- 모바일(0~767px): 단일 열, 44px 이상 조작 영역, 핵심 행동 우선.
- 태블릿(768~1023px): 내비게이션과 본문 균형, 카드 2열 허용.
- PC(1024px 이상): 고정 목차와 본문 2열, 읽기 폭 제한.

## 접근성 요구사항
본문 바로가기, 명확한 포커스, 의미 있는 제목 구조, 이미지 대체 텍스트, 상태 텍스트, 키보드 이동, 오류 복구 안내를 제공한다.

## Requirement 추적
- **VC018-REQ-001** (높음): 캠페인 메시지를 검증된 제품 사실과 직접 연결
- **VC018-REQ-002** (높음): 기간·대상·상태·조건을 CTA 전에 명확히 표시
- **VC018-REQ-003** (보통 이상): 종료·품절·오류 시 관련 제품 또는 상시 정보로 연결
- **VC018-REQ-004** (보통 이상): SNS·광고 유입 메시지와 랜딩 첫 화면을 일치
- **VC018-REQ-005** (보통 이상): 모바일 공유·딥링크 후 핵심 맥락과 행동 유지
- **VC018-REQ-006** (보류): 확정되지 않은 할인·재고·효능 캠페인 공개 금지

## 가정·HOLD·제외
- 가정: 프로토타입의 버튼은 같은 문서 내 화면으로 이동한다.
- HOLD: VC018-REQ-006 및 승인되지 않은 운영 문구.
- 제외: 미확정 가격·영양 수치·재고·배송·효능·인증·로그인 정책.
