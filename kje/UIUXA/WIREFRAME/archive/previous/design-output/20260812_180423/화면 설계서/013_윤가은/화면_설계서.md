# VC-013 윤가은 화면 설계서

## 프로젝트 및 설계 범위
검증 FAQ와 고객지원 연결을 위한 7개 저충실도 화면을 정의한다. 실제 거래·회원·외부 시스템 구현은 범위 밖이다.

## 화면 ID 규칙과 전체 목록
SCR-001부터 연속 부여하며 사이트맵·서비스 흐름도·JSON·HTML에서 동일하게 사용한다.

| ID | 화면명 | 목적 |
|---|---|---|
| SCR-001 | 홈 | 검증된 도움말과 제품 탐색의 시작점 |
| SCR-002 | FAQ | 사용법·보관·성분·구매 질문 분류 |
| SCR-003 | FAQ 상세 | 검증 답변과 관련 제품·문의 연결 |
| SCR-004 | 문의 | 미해결 문제 접수 |
| SCR-005 | 문의 완료 | 접수 결과와 복귀 행동 안내 |
| SCR-006 | 제품 안내 | FAQ 맥락의 제품 정보 제공 |
| SCR-007 | 오류 안내 | 실패 원인과 복구 행동 제공 |

## 공통 구조
- 헤더: 홈과 도움말, FAQ, 문의 탐색.
- 본문: 제목, 목적, 핵심 콘텐츠, 상태, 주요·복구 행동.
- 푸터: 검증된 정책·문의 링크만 배치.

## 화면별 설계
### SCR-001 홈
- 목적: 검증된 도움말과 제품 탐색의 시작점
- 진입 조건: 직접 진입 또는 전역 내비게이션
- 종료 조건: 도움말 보기 수행 또는 이전 단계 이동
- 구성/UI: 도움말, 제품 안내, 중요 주의 정보, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 도움말 보기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-002 FAQ
- 목적: 사용법·보관·성분·구매 질문 분류
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 답변 선택 수행 또는 이전 단계 이동
- 구성/UI: 질문 유형, 검증 상태, 중요 주의, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 답변 선택, 이전 단계 이동 → SCR-003
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-003 FAQ 상세
- 목적: 검증 답변과 관련 제품·문의 연결

- 종료 조건: 문의하기 수행 또는 이전 단계 이동
- 구성/UI: 답변, 근거 상태, 주의 정보, 관련 제품, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 문의하기, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-004 문의
- 목적: 미해결 문제 접수
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 접수하기 수행 또는 이전 단계 이동
- 구성/UI: 문의 유형, 내용, 개인정보 안내, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 접수하기, 이전 단계 이동 → SCR-005
- 상태: 기본, 로딩, 빈 상태, 오류, 완료

### SCR-005 문의 완료
- 목적: 접수 결과와 복귀 행동 안내
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: FAQ로 돌아가기 수행 또는 이전 단계 이동
- 구성/UI: 접수 상태, 후속 안내, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: FAQ로 돌아가기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-006 제품 안내
- 목적: FAQ 맥락의 제품 정보 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: FAQ 보기 수행 또는 이전 단계 이동
- 구성/UI: 제품 정의, 사용 맥락, 검증 정보, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: FAQ 보기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-007 오류 안내
- 목적: 실패 원인과 복구 행동 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 이전 화면 수행 또는 이전 단계 이동
- 구성/UI: 오류 설명, 재시도, 대체 문의, 상태 메시지, 주요/보조 버튼

- 인터랙션·이동: 이전 화면, 이전 단계 이동 → SCR-001
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공


## 반응형 기준
- 모바일(0~767px): 단일 열, 44px 이상 조작 영역, 핵심 행동 우선.
- 태블릿(768~1023px): 내비게이션과 본문 균형, 카드 2열 허용.
- PC(1024px 이상): 고정 목차와 본문 2열, 읽기 폭 제한.

## 접근성 요구사항
본문 바로가기, 명확한 포커스, 의미 있는 제목 구조, 이미지 대체 텍스트, 상태 텍스트, 키보드 이동, 오류 복구 안내를 제공한다.

## Requirement 추적
- **VC013-REQ-001** (높음): 사용법·보관·성분·구매 질문을 검증 답변으로 분류
- **VC013-REQ-002** (높음): 답변으로 해결되지 않는 문제에 책임 있는 문의 경로 제공
- **VC013-REQ-003** (보통 이상): FAQ 검색·필터는 실제 문서량이 충분할 때만 적용
- **VC013-REQ-004** (보통 이상): 중요 알레르기·주의 정보는 접힌 답변에만 숨기지 않음
- **VC013-REQ-005** (보통 이상): 문의 접수·오류·완료 상태와 복귀 행동을 표시
- **VC013-REQ-006** (보류): 승인되지 않은 보관·효능·품질 답변 공개 금지

## 가정·HOLD·제외
- 가정: 프로토타입의 버튼은 같은 문서 내 화면으로 이동한다.
- HOLD: VC013-REQ-006 및 승인되지 않은 운영 문구.
- 제외: 미확정 가격·영양 수치·재고·배송·효능·인증·로그인 정책.
