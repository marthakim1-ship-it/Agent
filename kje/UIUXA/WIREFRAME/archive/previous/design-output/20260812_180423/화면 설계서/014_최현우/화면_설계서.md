# VC-014 최현우 화면 설계서

## 프로젝트 및 설계 범위
개인정보 동의와 데이터 최소화을 위한 7개 저충실도 화면을 정의한다. 실제 거래·회원·외부 시스템 구현은 범위 밖이다.

## 화면 ID 규칙과 전체 목록
SCR-001부터 연속 부여하며 사이트맵·서비스 흐름도·JSON·HTML에서 동일하게 사용한다.

| ID | 화면명 | 목적 |
|---|---|---|
| SCR-001 | 홈 | 동의 없이도 핵심 제품 정보 접근 |
| SCR-002 | 제품 정보 | 비필수 동의와 무관한 제품 탐색 |
| SCR-003 | 개인정보 안내 | 수집 항목·목적·필수 여부 설명 |
| SCR-004 | 동의 설정 | 수락·거부·철회를 동등하게 제공 |
| SCR-005 | 설정 완료 | 변경 결과와 재변경 경로 안내 |
| SCR-006 | 지역 선택 | 위치 권한 거부의 직접 선택 대안 |
| SCR-007 | 오류 안내 | 설정 실패 시 복구 제공 |

## 공통 구조
- 헤더: 홈과 제품 정보, 개인정보 안내, 동의 설정 탐색.
- 본문: 제목, 목적, 핵심 콘텐츠, 상태, 주요·복구 행동.
- 푸터: 검증된 정책·문의 링크만 배치.

## 화면별 설계
### SCR-001 홈
- 목적: 동의 없이도 핵심 제품 정보 접근
- 진입 조건: 직접 진입 또는 전역 내비게이션
- 종료 조건: 제품 정보 보기 수행 또는 이전 단계 이동
- 구성/UI: 제품 정의, 개인정보 선택 안내, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 정보 보기, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-002 제품 정보
- 목적: 비필수 동의와 무관한 제품 탐색
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 지역 정보 보기 수행 또는 이전 단계 이동
- 구성/UI: 제품 설명, 사용 정보, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 지역 정보 보기, 이전 단계 이동 → SCR-006
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-003 개인정보 안내
- 목적: 수집 항목·목적·필수 여부 설명
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 선택 관리 수행 또는 이전 단계 이동
- 구성/UI: 수집 목적, 항목, 상태, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 선택 관리, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-004 동의 설정
- 목적: 수락·거부·철회를 동등하게 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 설정 저장 수행 또는 이전 단계 이동
- 구성/UI: 필수/선택 구분, 현재 상태, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 설정 저장, 이전 단계 이동 → SCR-005
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-005 설정 완료
- 목적: 변경 결과와 재변경 경로 안내
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 제품 정보로 이동 수행 또는 이전 단계 이동
- 구성/UI: 반영 상태, 다음 행동, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 제품 정보로 이동, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-006 지역 선택
- 목적: 위치 권한 거부의 직접 선택 대안
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 지역 적용 수행 또는 이전 단계 이동
- 구성/UI: 지역 목록, 직접 선택, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 지역 적용, 이전 단계 이동 → SCR-002
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공

### SCR-007 오류 안내
- 목적: 설정 실패 시 복구 제공
- 진입 조건: 이전 화면의 행동 선택
- 종료 조건: 다시 시도 수행 또는 이전 단계 이동
- 구성/UI: 오류 설명, 재시도, 설정 유지, 상태 메시지, 주요/보조 버튼
- 표시 데이터: 승인된 입력 정보와 검증 상태만 표시
- 인터랙션·이동: 다시 시도, 이전 단계 이동 → SCR-004
- 상태: 기본, 로딩, 빈 상태, 오류, 완료
- 검증: 필수 입력 누락 시 인접 오류와 복구 행동 제공


## 반응형 기준
- 모바일(0~767px): 단일 열, 44px 이상 조작 영역, 핵심 행동 우선.
- 태블릿(768~1023px): 내비게이션과 본문 균형, 카드 2열 허용.
- PC(1024px 이상): 고정 목차와 본문 2열, 읽기 폭 제한.

## 접근성 요구사항
본문 바로가기, 명확한 포커스, 의미 있는 제목 구조, 이미지 대체 텍스트, 상태 텍스트, 키보드 이동, 오류 복구 안내를 제공한다.

## Requirement 추적
- **VC014-REQ-001** (높음): 수집 항목·목적·필수 여부를 행동 전에 설명
- **VC014-REQ-002** (높음): 비필수 동의 거부 후에도 핵심 제품 정보 접근 유지
- **VC014-REQ-003** (보통 이상): 위치 권한 거부 시 직접 지역 선택 대안 제공
- **VC014-REQ-004** (보통 이상): 동의 상태 확인·변경·철회 경로 후보 제공
- **VC014-REQ-005** (보통 이상): 모바일에서 수락과 거부 선택을 동등하게 이해
- **VC014-REQ-006** (보류): 정책·보관기간·도구 확정 전 준수 문구를 단정하지 않음

## 가정·HOLD·제외
- 가정: 프로토타입의 버튼은 같은 문서 내 화면으로 이동한다.
- HOLD: VC014-REQ-006 및 승인되지 않은 운영 문구.
- 제외: 미확정 가격·영양 수치·재고·배송·효능·인증·로그인 정책.
