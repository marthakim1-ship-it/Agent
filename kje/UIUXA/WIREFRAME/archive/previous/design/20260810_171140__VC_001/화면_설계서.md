## 공통 구성과 반복 컴포넌트

- 헤더: 로고/홈, 제품, 제품 구조, 사용 상황, 성분·영양, 브랜드, 가정 검색·로그인
- 푸터: 정책·접근성, 검증 상태 설명, 미확정 문의 경로
- 상태 라벨: `CONFIRMED`, `NOT_VERIFIED`, `HOLD`, `가정`, `조건부`
- 제품 카드: 이미지 대체 텍스트, 제품명, 확정 속성, 검증 상태, 상세·비교 행동
- 콘텐츠 카드: 상황·단계·근거 요약과 명확한 연결 대상
- 이미지: 실제 자산 미확보 시 `[이미지: 대체 텍스트]` 플레이스홀더 사용

## 화면 상태

| 상태 | 공통 처리 |
|---|---|
| 기본 | 최신 확정 데이터와 상태 라벨 표시 |
| 로딩 | 레이아웃을 유지하는 텍스트·이미지 스켈레톤, `aria-busy=true` |
| 빈 상태 | 원인, 조건 초기화, 상위 화면 복귀 제공 |
| 오류 | 사용자가 수정할 항목과 시스템 오류를 구분하고 재시도·대체 경로 제공 |
| 완료 | 로그인·외부 이동 등 수행 결과와 다음 행동 표시 |
| 미확정 | 값을 추측하지 않고 `NOT_VERIFIED` 또는 `HOLD`, 필요한 자료 설명 |

## 유효성 검사와 오류 메시지

- P70 이메일: 빈 값 `이메일을 입력해 주세요.` / 형식 오류 `이메일 형식을 확인해 주세요.`
- P70 비밀번호: 빈 값 `비밀번호를 입력해 주세요.`; 길이·정책은 입력 근거가 없어 `가정`하지 않는다.
- P21·P80 검색/필터: 결과 0건 `조건에 맞는 결과가 없습니다. 조건을 줄이거나 전체 제품을 확인해 주세요.`
- P60 외부 연결 실패: `판매처로 이동하지 못했습니다. 잠시 후 다시 시도하거나 제품 상세로 돌아가 주세요.`
- 데이터 오류: 수치·효능을 대체값으로 표시하지 않고 `정보를 불러오지 못했습니다.`

## 반응형 기준

- 모바일 `<768px`: 1열, 콘텐츠 우선순위 유지, 표는 카드형 행으로 변환, CTA는 콘텐츠를 가리지 않음.
- 태블릿 `768~1199px`: 2열 카드, 비교표 가로 스크롤 허용, 핵심 내비게이션 유지.
- 데스크톱 `≥1200px`: 최대 너비 1200px, 3열 카드 가능, 정보 순서는 모바일과 동일.
- 터치 대상 최소 44×44px, 텍스트 확대 200%에서도 기능 손실 없음.

## 접근성 요구사항

- 시맨틱 헤딩·랜드마크·키보드 포커스 순서 제공.
- 모든 이미지 플레이스홀더와 실제 이미지에 의미 있는 대체 텍스트 제공.
- 컬러만으로 제품군·검증 상태를 구분하지 않고 텍스트 라벨 병기.
- 본문·UI 대비 WCAG AA 목표, 동작 애니메이션은 감소 설정 지원.
- 오류는 입력과 연결된 텍스트로 알리고, 상태 변화는 라이브 영역으로 전달.
- 스와이프·호버 기능에는 버튼·키보드 대체 조작 제공.

## 가정 및 미확정 정책

- 가정: P70 로그인, P71 내 활동, P80 검색 결과와 저장 기능.
- 조건부: P52 품질·시험, P60 판매처·다음 행동.
- 미확정: 제품 옵션, 원료·영양 수치, 알레르기, 가격, 판매 채널, CTA, 시험 결과, 효능, 회원 정책.
- 위 항목은 확정 자료가 없으면 표시값을 생성하지 않고 상태 안내만 제공한다.
