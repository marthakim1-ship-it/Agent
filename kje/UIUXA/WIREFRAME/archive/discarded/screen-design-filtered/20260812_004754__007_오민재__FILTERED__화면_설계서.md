# YOVIA 화면 설계서

## 프로젝트 및 설계 범위

007_오민재 설계 입력을 기준으로 10개 화면을 정의한다. 용량·구성·가격을 같은 기준으로 비교하는 흐름을 핵심 범위로 하며 확인되지 않은 값은 확정하지 않는다.

## 화면 ID 규칙과 전체 화면 목록

원본 설계의 화면 ID와 이름을 유지한다. 문서와 후속 구조 데이터에서도 같은 식별자를 사용한다.

| ID | 화면 | 목적 | 주 진입 | 종료·다음 |
|---|---|---|---|---|
| SCR-001 | 홈 | 제품 가치 진입 | 최초 진입 | 제품 가치 |
| SCR-002 | 제품 가치 | 구성과 편의 가치 | 홈 | 가치 비교 |
| SCR-003 | 가치 비교 | 용량·구성·가격 차이 | 제품 가치 | 구성 비교 |
| SCR-004 | 구성 비교 | 단위 기준과 묶음 차이 | 가치 비교 | 제품 상세 |
| SCR-005 | 제품 상세 | 핵심 기준과 적용 범위 | 구성 비교 | 구매 정책 |
| SCR-006 | 구매 정책 | 가격·배송·할인 조건과 기준일 | 제품 상세 | 검증 상태 |
| SCR-007 | 검증 상태 | 정책 공개 수준 | 구매 정책 | 다음 행동 |
| SCR-008 | 다음 행동 | 확정 조건 이후 선택 | 검증 상태 | 준비 중 안내 |
| SCR-010 | 준비 중 안내 | 미확정 경로의 대체 선택 | 다음 행동 | 결과 없음 |
| SCR-011 | 결과 없음 | 비교 조건 초기화 | 준비 중 안내 | 홈 |

## 공통 구성과 UI 요소

- 상단 영역: YOVIA 로고와 현재 화면 이름, 핵심 정보 이동 링크.
- 본문: 화면 ID, 핵심 제목, 설명, 확인된 데이터, 상태 표식, 다음 행동.
- 하단 영역: 검증 원칙과 홈 이동 링크.
- 반복 구성: 정보 목록, 비교 목록, 단계 목록, 상태 표식, 근거 항목, 행동 링크.

## 입력 및 데이터 안내 문구

| 대상 | 조건 | 안내 문구 | 복구 |
|---|---|---|---|
| 필수 데이터 | 값 없음 | `확인되지 않은 정보입니다.` | 확인된 정보만 유지 |
| 탐색 결과 | 결과 0건 | `조건에 맞는 결과가 없습니다.` | 조건 초기화 |
| 근거 링크 | 문서 미확정 | `근거 자료를 확인 중입니다.` | 상위 정보로 이동 |

## 가정 및 보류 정책

- `가정`: 화면 간 세부 선택 조건과 운영 데이터.
- `보류`: 대용량·묶음·구독·포만감 정보는 근거 확보 전 보류.
- 확인되지 않은 값은 `NOT_VERIFIED` 또는 `HOLD`로 표시하고 다음 행동과 직접 연결하지 않는다.
