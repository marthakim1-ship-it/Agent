# YOVIA 화면 설계서

## 프로젝트 및 설계 범위

008_한유진 설계 입력을 기준으로 10개 화면을 정의한다. 원료·알레르기·교차접촉·주의를 먼저 확인하는 흐름을 핵심 범위로 하며 확인되지 않은 값은 확정하지 않는다.

## 화면 ID 규칙과 전체 화면 목록

원본 설계의 화면 ID와 이름을 유지한다. 문서와 후속 구조 데이터에서도 같은 식별자를 사용한다.

| ID | 화면 | 목적 | 주 진입 | 종료·다음 |
|---|---|---|---|---|
| SCR-001 | 홈 | 원료와 주의 진입 | 최초 진입 | 원료·주의 |
| SCR-002 | 원료·주의 | 원료·첨가물과 핵심 주의 | 홈 | 알레르기 |
| SCR-003 | 알레르기 | 포함·교차접촉 정보 | 원료·주의 | 제품 정보 |
| SCR-004 | 제품 정보 | 적용 대상과 기준일 | 알레르기 | 사용 상황 |
| SCR-005 | 사용 상황 | 가족 공유 상황과 제품 연결 | 제품 정보 | 제품 상세 |
| SCR-006 | 제품 상세 | 정보와 근거 통합 | 사용 상황 | 검증 상태 |
| SCR-007 | 검증 상태 | 공개 수준과 적용 범위 | 제품 상세 | 보류 정보 |
| SCR-008 | 보류 정보 | 공개하지 않는 주장 범위 | 검증 상태 | 다음 행동 |
| SCR-009 | 다음 행동 | 확정 정보 이후 선택 | 보류 정보 | 결과 없음 |
| SCR-011 | 결과 없음 | 조건 초기화와 탐색 복귀 | 다음 행동 | 홈 |

## 공통 구성과 UI 요소

- 상단 영역: YOVIA 로고와 현재 화면 이름, 핵심 정보 이동 링크.
- 본문: 화면 ID, 핵심 제목, 설명, 확인된 데이터, 상태 표식, 다음 행동.
- 하단 영역: 검증 원칙과 홈 이동 링크.
- 반복 구성: 정보 목록, 비교 목록, 단계 목록, 상태 표식, 근거 항목, 행동 링크.

## 입력 및 데이터 안내 문구

| 대상 | 조건 | 안내 문구 | 복구 |
|---|---|---|---|
| 필수 데이터 | 값 없음 | `확인되지 않은 정보입니다.` | 확인된 정보만 유지 |
| 탐색 결과 | 결과 0건 | `조건에 맞는 결과가 없습니다.` | 조건 초기화 |
| 근거 링크 | 문서 미확정 | `근거 자료를 확인 중입니다.` | 상위 정보로 이동 |

## 가정 및 보류 정책

- `가정`: 화면 간 세부 선택 조건과 운영 데이터.
- `보류`: 어린이 적합·유기농·무첨가 주장은 근거 확보 전 보류.
- 확인되지 않은 값은 `NOT_VERIFIED` 또는 `HOLD`로 표시하고 다음 행동과 직접 연결하지 않는다.
