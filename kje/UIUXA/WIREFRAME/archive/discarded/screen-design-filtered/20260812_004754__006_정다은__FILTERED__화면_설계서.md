# YOVIA 화면 설계서

## 프로젝트 및 설계 범위

006_정다은 설계 입력을 기준으로 11개 화면을 정의한다. 맛·질감·토핑을 제품 근거와 연결하는 흐름을 핵심 범위로 하며 확인되지 않은 값은 확정하지 않는다.

## 화면 ID 규칙과 전체 화면 목록

원본 설계의 화면 ID와 이름을 유지한다. 문서와 후속 구조 데이터에서도 같은 식별자를 사용한다.

| ID | 화면 | 목적 | 주 진입 | 종료·다음 |
|---|---|---|---|---|
| SCR-001 | 홈 | 제품과 감각 탐색 진입 | 최초 진입 | 제품 탐색 |
| SCR-002 | 제품 탐색 | 확정 제품 후보 | 홈 | 맛·식감 탐색 |
| SCR-003 | 맛·식감 탐색 | 맛·질감·토핑 조건 | 제품 탐색 | 제품 비교 |
| SCR-004 | 제품 비교 | 감각 정보 차이 | 맛·식감 탐색 | 제품 상세 |
| SCR-005 | 제품 상세 | 요약·근거·행동 통합 | 제품 비교 | 제품 정보 |
| SCR-007 | 제품 정보 | 적용 제품과 근거 | 제품 상세 | 자산 상태 |
| SCR-008 | 자산 상태 | 확정·콘셉트·미검증 구분 | 제품 정보 | 검증 상태 |
| SCR-009 | 검증 상태 | 공개 가능 정보와 보류 범위 | 자산 상태 | 다음 행동 |
| SCR-010 | 다음 행동 | 확정된 정보 이후 선택 | 검증 상태 | 준비 중 안내 |
| SCR-012 | 준비 중 안내 | 미확정 경로의 대체 선택 | 다음 행동 | 결과 없음 |
| SCR-013 | 결과 없음 | 조건 초기화와 탐색 복귀 | 준비 중 안내 | 홈 |

## 공통 구성과 UI 요소

- 상단 영역: YOVIA 로고와 현재 화면 이름, 핵심 정보 이동 링크.
- 본문: 화면 ID, 핵심 제목, 설명, 확인된 데이터, 상태 표식, 다음 행동.
- 하단 영역: 검증 원칙과 홈 이동 링크.
- 반복 구성: 정보 목록, 비교 목록, 단계 목록, 상태 표식, 근거 항목, 행동 링크.

## 입력 및 데이터 안내 문구

| 대상 | 조건 | 안내 문구 | 복구 |
|---|---|---|---|
| 필수 데이터 | 값 없음 | `확인되지 않은 정보입니다.` | 확인된 정보만 유지 |
| 탐색 결과 | 결과 0건 | `조건에 맞는 결과가 없습니다.` | 조건 초기화 |
| 근거 링크 | 문서 미확정 | `근거 자료를 확인 중입니다.` | 상위 정보로 이동 |

## 가정 및 보류 정책

- `가정`: 화면 간 세부 선택 조건과 운영 데이터.
- `보류`: 최종 맛·라인업·감미료·행동 정책은 확정 전 보류.
- 확인되지 않은 값은 `NOT_VERIFIED` 또는 `HOLD`로 표시하고 다음 행동과 직접 연결하지 않는다.
