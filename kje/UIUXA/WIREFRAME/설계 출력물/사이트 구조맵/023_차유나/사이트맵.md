# VC-023 차유나 사이트맵
## 프로젝트 개요
냉장 유통·보관 정보 분석을 기준으로 공통 핵심 3화면과 전용 과업 2화면을 구성한다.
## 설계 근거와 핵심 사용자 목표
- **VC023-REQ-001** (Must): 보관·개봉·섭취 조건을 상태별 행동 지침으로 제공
- **VC023-REQ-002** (Must): 이동 편의와 냉장 안전성을 서로 다른 주장으로 구분
- **VC023-REQ-003** (Should): 수령·보관 중 이상 상태의 확인·문의 경로 제공
- **VC023-REQ-004** (Should): 시간·온도·기준일·단위를 모바일에서 함께 표시
- **VC023-REQ-005** (Should): 보관 안내 변경 시 제품·FAQ·공지 연결을 함께 갱신
- **VC023-REQ-006** (Hold): 근거 없는 상온 보관·신선도·유통기한 공개 금지
대표 Site 근거: SITE-003, SITE-008, SITE-015, SITE-036, SITE-047
## 전역 내비게이션 구조
메인페이지 · 카테고리 · 브랜드 소개 · 보관 상태 안내 · 이상 상태 확인
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 보관 상태 안내
  - TASK-002 이상 상태 확인

## 공통·회원·예외
로그인을 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD와 재시도·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001의 PRODUCT-001~015는 실제 라인업이 아닌 NOT_VERIFIED 설계 슬롯이다.
## 연결성·가정
5개 화면은 시작점에서 도달·복귀 가능하다. 실제 상품·가격·재고·정책·효능·인증은 확정하지 않는다.
