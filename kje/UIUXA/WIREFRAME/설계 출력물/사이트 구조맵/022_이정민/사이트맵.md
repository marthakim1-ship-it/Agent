# VC-022 이정민 사이트맵
## 프로젝트 개요
식품 표시·광고 준법 분석을 기준으로 공통 핵심 3화면과 전용 과업 2화면을 구성한다.
## 설계 근거와 핵심 사용자 목표
- **VC022-REQ-001** (Must): 제품 요약과 법정 표시 원문을 명확히 연결
- **VC022-REQ-002** (Must): 건강·영양·무첨가 표현마다 승인 상태와 적용 범위 표시
- **VC022-REQ-003** (Should): 필수 주의사항을 주요 정보 흐름에서 숨기지 않음
- **VC022-REQ-004** (Should): 문구별 출처·기준일·버전·승인자 관리
- **VC022-REQ-005** (Should): 모바일에서도 항목명·값·단위의 관계 유지
- **VC022-REQ-006** (Hold): 승인 없는 수치·인증·효능·비교 우위 공개 금지
대표 Site 근거: SITE-001, SITE-003, SITE-008, SITE-017, SITE-036
## 전역 내비게이션 구조
메인페이지 · 카테고리 · 브랜드 소개 · 표시 정보 확인 · 문구 승인 상태
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 표시 정보 확인
  - TASK-002 문구 승인 상태

## 공통·회원·예외
로그인을 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD와 재시도·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001의 PRODUCT-001~015는 실제 라인업이 아닌 NOT_VERIFIED 설계 슬롯이다.
## 연결성·가정
5개 화면은 시작점에서 도달·복귀 가능하다. 실제 상품·가격·재고·정책·효능·인증은 확정하지 않는다.
