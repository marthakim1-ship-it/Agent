# VC-011 조은채 사이트맵
## 프로젝트 개요
YOVIA 설계를 **첫 방문 교육** 관점에서 독립 구성한다. 공통 필수 화면 3개와 이 Client 전용 과업 화면 2개를 포함한다.
## 설계 근거와 사용자 목표
- **VC011-REQ-001** (높음): 첫 화면에서 브랜드 정의와 제품 편익을 한 문장으로 이해
- **VC011-REQ-002** (높음): 파우치·빌트인 스푼·토핑 관계를 초심자용 단계로 설명
- **VC011-REQ-003** (보통 이상): 낯선 제품 용어에 짧은 도움말과 상세 연결 제공
- **VC011-REQ-004** (보통 이상): 모바일에서 정의→구성→사용법 순서를 유지
- **VC011-REQ-005** (보통 이상): 입문 콘텐츠 완료 뒤 검증 정보·다음 행동을 연결
- **VC011-REQ-006** (보류): 미확정 제품 사양을 입문 메시지로 사용 금지
- 대표 Site 근거: SITE-001, SITE-012, SITE-017
- 분석 이동 경로: 브랜드 정의→제품 구성→사용법→검증 정보.
## 전역 내비게이션
메인페이지 · 카테고리 · 브랜드 소개 · 제품 구성 학습 · 검증 정보
## 계층형 사이트맵
- MAIN-001 메인페이지(홈)
  - PRODUCT-001~PRODUCT-015 상품 슬롯
  - CATEGORY-001 카테고리 페이지
  - BRAND-001 브랜드 소개 페이지
- TASK-001 제품 구성 학습
  - TASK-002 검증 정보

## 공통·상태·예외
로그인은 근거가 없어 강제하지 않는다. 로딩·빈 상태·오류·완료·NOT_VERIFIED·HOLD를 텍스트로 표시하고 재시도·이전 단계·홈 복귀를 제공한다.
## 상품 수량 계약
MAIN-001에는 PRODUCT-001~PRODUCT-015의 15개 슬롯이 있다. 실제 상품 데이터가 없으므로 모두 NOT_VERIFIED이며 가격·효능·재고를 확정하지 않는다.
## 가정·HOLD·제외
상품 상세은 TASK-001에 조건부 매핑한다. 실제 제품명·가격·용량·영양·효능·재고·판매 정책은 제외 또는 HOLD다.
