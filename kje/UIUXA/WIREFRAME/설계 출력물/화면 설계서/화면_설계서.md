# VC-001 서하린 — 화면 설계서

## 프로젝트 및 설계 범위

사이트맵과 서비스 흐름도에 정의된 P-001~P-006 전체를 대상으로 한 모바일 우선 저충실도 설계다. HTML에서 화면 이동, 구조·상황·단계 선택, 상세 펼치기와 기본·로딩·빈·오류·완료 상태를 직접 확인한다.

- 제외: 로그인, 회원가입, 입력 폼, 구매, 결제, 구독
- 가정: 실제 제품·영양 자산은 추후 제공되며 현재 플레이스홀더로 표시한다.

## 화면별 상세 정의

### P-001 홈

| 구분 | 정의 |
|---|---|
| 표시 데이터 | 제품 한 문장 정의, 대표 이미지, 핵심 정보 카드 3개 |
| UI 요소 | 히어로, 이미지 플레이스홀더, 탐색 카드, 완료 버튼 |
| 사용자 행동 | 제품 상세·사용 안내·성분·영양 선택, 탐색 완료 |
| 이동 대상 | P-002, P-003, P-004 |
| 상태 | 기본: 콘텐츠 표시 / 로딩: 골격 안내 / 빈: 제품 자료 없음 / 오류: 로드 실패 / 완료: 탐색 시작 준비 완료 |

| UI 요소 | 15개 상품 선택기, 이미지 플레이스홀더, 상품 요약, 유형별 구성 패널, 관련 정보 버튼 |
| 사용자 행동 | PRODUCT ID 선택·정보 전환, 카테고리 복귀, 사용 안내·성분·영양 이동, 완료 |

## 유효성 검사와 오류 메시지

| 검사 | 실패 조건 | 메시지 | 복구 |
|---|---|---|---|
| 화면 ID | 존재하지 않는 해시 | 요청한 화면이 없습니다. | P-001 표시 |
| 제품 자산 | 이미지·사양 없음 | 제품 자산 확인이 필요합니다. | 텍스트 설명 유지 |
| 단계 범위 | 1보다 작거나 4보다 큼 | 첫 단계 또는 마지막 단계입니다. | 유효 단계 유지 |
| 영양 근거 | 기준량·출처 없음 | 확정된 수치와 출처가 없습니다. | 상세·사용 안내 이동 |
| 자료 로드 | 데이터 표시 실패 | 정보를 불러오지 못했습니다. | 재시도·홈 이동 |

입력 폼은 없으므로 사용자 입력값 검사는 `해당 없음`이다.

## 반응형 기준

- 모바일 ≤767px: 1열, 내비게이션 2열, 카드·단계 1열.
- 태블릿 768~1199px: 카드·단계 2열.
- 데스크톱 ≥1200px: 최대 1200px, 히어로·상세 2열, 카드 3열, 단계 4열.

## 접근성 요구사항

- 제목·랜드마크 순서, 본문 건너뛰기 링크를 제공한다.
- 화면 전환 후 `tabindex=-1` 제목으로 포커스를 이동한다.
- 현재 화면·선택 탭은 `aria-current`, `aria-pressed`로 전달한다.
- 이미지 플레이스홀더는 역할과 대체 설명을 제공한다.
- 상태는 색상뿐 아니라 제목과 텍스트로 전달한다.
- 키보드로 모든 버튼과 상세 요소를 조작할 수 있다.

## 가정 및 보류

- 실제 제품 이미지·구조·사양과 원료·영양 데이터는 `가정` 상태다.
- 제품 옵션·비교·판매처·구매 CTA는 근거 확보 전 보류한다.
- 건강 효능·시험 결과는 검증 자료 전 표시하지 않는다.
- 브랜드명 의미·최종 슬로건·공식 미션·BI 규칙과 패키지 기술 적용 여부는 보류 또는 검토 필요 상태로 유지한다.

## 실행 및 검증

- 실행: `와이어프레임.html`을 브라우저에서 연다.
- 상태 검사: 각 화면 상단의 5개 상태 버튼을 사용한다.
- 구조·상황·단계·상세 인터랙션과 화면 이동을 키보드·포인터로 확인한다.
