# VC-023 차유나 서비스 흐름도
## 개요와 시작·종료
냉장 유통·보관 정보 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 보관 상태 안내 → TASK-002 이상 상태 확인 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 보관 상태 안내 | 이상 상태 확인 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 이상 상태 확인 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC023-REQ-001**: 보관·개봉·섭취 조건을 상태별 행동 지침으로 제공
- **VC023-REQ-002**: 이동 편의와 냉장 안전성을 서로 다른 주장으로 구분
- **VC023-REQ-003**: 수령·보관 중 이상 상태의 확인·문의 경로 제공
- **VC023-REQ-004**: 시간·온도·기준일·단위를 모바일에서 함께 표시
- **VC023-REQ-005**: 보관 안내 변경 시 제품·FAQ·공지 연결을 함께 갱신
- **VC023-REQ-006**: 근거 없는 상온 보관·신선도·유통기한 공개 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
