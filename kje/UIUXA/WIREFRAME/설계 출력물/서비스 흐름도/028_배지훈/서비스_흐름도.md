# VC-028 배지훈 서비스 흐름도
## 개요와 시작·종료
주문 후 문제 해결 요구 사용자가 로그인 없이 MAIN-001에서 시작해 TASK-002 결과 확인 또는 유효 화면 복귀로 종료한다.
## 정상 흐름
MAIN-001 → CATEGORY-001 → 상품 선택 → TASK-001 문제 유형 확인 → TASK-002 처리 상태 확인 → 결과 확인. 브랜드 흐름은 MAIN-001 → BRAND-001 → CATEGORY-001이다.
## 상품 행동
PRODUCT-001~015는 TASK-001 조건부 후보로 연결하며 실제 상품 정보는 NOT_VERIFIED다.
## 분기·오류·재진입
결과 없음, 입력·시스템 오류에 조건 완화·재시도·이전 단계·홈 복귀를 제공한다.
## 단계별 처리
| 화면 | 행동 | 시스템 처리 | 다음 화면 | 실패·복구 |
|---|---|---|---|---|
| MAIN-001 메인페이지(홈) | 카테고리 보기 | 상태·조건 갱신 | CATEGORY-001, BRAND-001 | 재시도·이전 단계·홈 |
| CATEGORY-001 카테고리 페이지 | 상품 후보 확인 | 상태·조건 갱신 | TASK-001, MAIN-001 | 재시도·이전 단계·홈 |
| BRAND-001 브랜드 소개 페이지 | 관련 제품 보기 | 상태·조건 갱신 | CATEGORY-001, MAIN-001 | 재시도·이전 단계·홈 |
| TASK-001 문제 유형 확인 | 처리 상태 확인 보기 | 상태·조건 갱신 | TASK-002, CATEGORY-001 | 재시도·이전 단계·홈 |
| TASK-002 처리 상태 확인 | 메인으로 | 상태·조건 갱신 | MAIN-001, TASK-001 | 재시도·이전 단계·홈 |
## Requirement 추적
- **VC028-REQ-001**: 안전 문제와 일반 주문 문제를 첫 단계에서 구분
- **VC028-REQ-002**: 주문·제품 식별에 필요한 최소 정보와 목적 표시
- **VC028-REQ-003**: 접수·검토·추가 정보·완료 상태와 다음 행동 제공
- **VC028-REQ-004**: 판매처·브랜드 책임 범위에 맞는 지원 경로 연결
- **VC028-REQ-005**: 모바일 입력 오류·업로드 실패의 복구 제공
- **VC028-REQ-006**: 미확정 환불·교환·보상 정책과 처리 기한 약속 금지
## 연결성 검토
사이트맵과 화면 이름·ID가 일치하고 정상 흐름의 끊긴 링크가 없다.
