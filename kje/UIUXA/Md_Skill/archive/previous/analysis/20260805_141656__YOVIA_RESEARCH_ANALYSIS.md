### 3.2 선정 콘셉트와 선정 방식

- **선정 디자인 콘셉트**: 구조와 섭취 순간을 연결하는 제품 설명형
- **선정 방식**: 근거 기반 추천
- 사용 상황·방법 20/20과 CTA 19/20이 결합되고, [015] GoGo squeeZ와 [017] Oats Overnight이 짧은 사용 흐름의 직접 근거를 제공해 Phase 1에서 조건부 타당하다. 20/20은 상황 문구의 존재를 뜻하며 단계 설명의 깊이가 모두 같다는 뜻은 아니다.

### 3.3 주 콘셉트 역할

제품 구조가 무엇인지, 어떻게 열고 먹는지, 어느 상황에서 편한지를 `구조 → 사용 단계 → 섭취 상황 → 행동` 순으로 설명한다.

### 3.4 보조 콘셉트 역할

맛·패키지 컬러 커머스형은 맛 카드와 제품 선택 구간에만 사용한다. [004] Noosa, [008] BraveQueen, [014] Yoplait의 제품군 탐색을 참고하되 모든 컬러를 같은 강도로 경쟁시키지 않는다.

### 3.5 타당성·모바일 적합성·구현 조건

- 타당성: 제품 설명과 전환을 함께 지지하는 반복 패턴이 충분하다.
- 모바일: 한 화면 한 메시지, 세로 1열 사용 단계, 가로 스와이프 맛 카드로 축약할 수 있다.
- 구현 조건: 실제 파우치·내장 도구·토핑 구조, 정확한 사용 순서, 확정 영양·원료 정보, 제품 이미지가 필요하다.

### 3.6 위험·중단 조건·대안 콘셉트

- 실제 제품 구조가 제안한 단계와 다르면 구조 설명형의 제작을 중단하고 사실 확인 후 재설계한다.
- 모바일에서 핵심 가치와 CTA가 첫 흐름에 남지 않으면 장식과 부가 설명을 먼저 제거한다.
- 사용 단계가 제품 차별점을 만들지 못하면 맛·패키지 컬러 커머스형을 주 콘셉트 대안으로 재검토한다.

## 4. 전체 레퍼런스 공통점

1. 제품 또는 패키지가 첫 인지 단서다. 확인 가능한 19개 중 18개가 이를 사용하며 [001] Chobani, [005] Ellenos, [013] Stonyfield가 대표적이다.
2. 제품 선택 후 행동으로 이어지는 CTA가 19/20에서 확인된다. 다만 이 빈도는 전환 성과를 입증하지 않는다.
3. 맛·형식·제품군 탐색이 20/20에서 확인돼 제품 다양성을 먼저 정리한 뒤 상세 설명으로 이동하는 구조가 공통적으로 나타난다. 정적 메뉴와 인터랙티브 필터를 같은 상위 지표로 센 한계가 있다.
4. 수치·배지는 18/20, 사용 상황·방법은 20/20이다. 두 패턴을 함께 쓰면 기능 정보와 실제 섭취 장면을 균형 있게 전달할 수 있다.
5. 패턴의 관계는 `패키지 인지 → 제품군 선택 → 핵심 정보 확인 → 사용 이해 → 구매·판매처 행동`으로 요약된다.

## 5. 제품 관련성별 공통점과 차이

### 5.1 직접 레퍼런스

직접군 15개는 요거트, 스키르, 식물성 요거트, 파우치 경험을 중심으로 맛·질감·토핑·제품 형식을 강조한다. [001] Chobani와 [004] Noosa는 토핑 결합, [012] Forager Project와 [013] Stonyfield는 파우치와 이동 상황의 직접 참고 사례다.

### 5.2 인접 레퍼런스

인접군 5개는 오트밀·식사 대용·구독 경험을 통해 준비 단계, 정량 정보, 루틴을 더 강하게 설명한다. [017] Oats Overnight의 단계형 사용법과 [019] Soylent의 정보 계층이 대표적이다.

### 5.3 주변 레퍼런스

해당 레코드가 없어 확인 가능한 근거가 부족하다.

### 5.4 그룹 간 비교

- 직접군은 식감·맛·패키지와 식품다운 즐거움에 강하다.
- 인접군은 사용 순서·정량 정보·반복 구매 구조에 강하다.
- YOVIA는 직접군을 시각 언어의 중심으로 삼고 인접군의 설명 구조만 선택적으로 결합하는 편이 적합하다.

## 8. 핵심 UX/UI 패턴

### 8.1 헤더와 내비게이션

제품군·맛·형식을 우선 노출하고 브랜드 스토리와 콘텐츠는 2차로 둔다. 모바일에서는 제품, 사용법, 구매의 세 진입점을 짧게 유지한다.

### 8.2 히어로와 가치 제안

제품·패키지 이미지와 한 문장 가치 제안을 결합한다. YOVIA의 확정되지 않은 구조나 수치를 히어로에서 단정하지 않는다.

### 8.3 제품·패키지 표현

패키지의 구성 관계가 보이는 정면·분해·사용 직전 이미지를 우선한다. 데스크톱은 이미지와 설명을 병렬 배치하고 모바일은 이미지 다음에 핵심 설명을 둔다.

### 8.4 핵심 수치·배지

확정된 영양·용량·보관 정보만 3개 안팎으로 우선 노출한다. 타사 수치를 YOVIA의 제품 사실처럼 사용하지 않는다.

### 8.5 제품 구조와 사용법

`열기 → 결합 또는 준비 → 먹기`처럼 실제 제품에 맞는 3단계 이내 흐름을 검토한다. [017] Oats Overnight의 단계형 설명을 구조 참고로 사용한다.

### 8.6 제품군 탐색

맛, 토핑, 제품 형식을 카드와 필터로 구분한다. 모바일에서는 필터를 접고 현재 선택을 항상 확인할 수 있게 한다.

### 8.7 영양·원료·신뢰 정보

가치 제안 뒤에 원료·영양·보관·제조 근거를 계층화한다. 감성 이미지와 검증 정보가 서로 대체되지 않게 한다.

### 8.8 CTA와 구매 전환

페이지 목적에 맞춰 구매, 판매처, 제품 보기 중 하나를 주 CTA로 정한다. 반복 배치는 가능하지만 모든 버튼을 같은 우선순위로 만들지 않는다.

### 8.9 인터랙션과 모션

실제 관찰 근거가 부족하다. 구조 변화나 단계 이해를 돕는 짧은 전환만 후보로 두고, 목적 없는 3D·파티클·복합 모션은 보류한다.

### 8.10 모바일 UX

한 화면 한 메시지, 1열 단계, 큰 터치 영역, 짧은 카드 제목을 기본으로 한다. 데스크톱의 넓은 비교표를 축소하지 말고 핵심 행을 카드로 재구성한다.

## 9. 예외·차별화·대안 사례

- [005] Ellenos의 질감·제조·리뷰 결합은 프리미엄 감성의 차별화 후보지만 주 사용 흐름보다 앞서지 않는다.
- [008] BraveQueen의 다수 맛 탐색은 SKU 확장 시 유용하지만 초기 제품 수가 적다면 과한 필터가 된다.
- [017] Oats Overnight의 맞춤·구독 구조는 반복 구매 참고 사례지만 YOVIA의 판매 방식이 확정되기 전에는 도입하지 않는다.
- [009] Yogurtman의 프랜차이즈 중심 구조는 소비자용 제품 정보가 밀리는 반면교사다.

## 10. YOVIA 적용 우선순위

### 필수

- 확정 제품 구조와 사용 순서를 짧게 설명하는 핵심 구간
- 제품·패키지를 중심으로 한 히어로와 명확한 주 CTA
- 맛·형식·토핑을 구분하는 기본 제품 카드
- 확정된 원료·영양·보관 정보와 근거

### 우선

- 이동·아침·간식 등 실제 섭취 상황 이미지와 카피
- 데스크톱 병렬 설명과 모바일 1열 단계의 별도 구성
- 판매처 또는 구매 흐름의 일관된 연결

### 선택

- 질감 매크로, 리뷰, 제조 과정 콘텐츠
- 제품 수가 늘었을 때의 맛 필터와 비교 기능
- 실제 운영 모델이 확정된 뒤의 구독·맞춤 기능

### 보류

- 확정되지 않은 영양 수치와 효능 메시지
- 목적 없는 3D·복합 모션
- 제품 수가 적은 상태의 복잡한 필터와 비교표

## 11. 구현 난이도·위험·중단 조건

| 항목 | 난이도 | 주요 위험 | 중단 또는 재검토 조건 |
|---|---|---|---|

| 3단계 사용법 | 낮음~중간 | 설명 과밀 또는 단계 오류 | 사용자 테스트에서 순서 오해 발생 |
| 맛·제품 카드 | 낮음 | 컬러 경쟁과 정보 중복 | SKU 체계 미확정 |
| 영양·원료 정보 | 낮음 | 법적·사실 오류 | 승인된 수치와 문구 부재 |
| 판매·구매 CTA | 중간 | 연결 경로 불명확 | 판매 채널 미확정 |
| 모션 | 중간~높음 | 성능 저하와 주의 분산 | 모바일 성능 또는 접근성 저하 |

## 12. 피해야 할 방향과 반면교사

- 기능성 수치만 전면에 내세워 보충제처럼 보이게 하는 방향
- 맛 컬러와 배지를 같은 강도로 과다 노출하는 방향
- 제품 구조보다 브랜드 서사를 먼저 길게 설명하는 방향
- 확인되지 않은 편의성, 건강 효능, 영양 수치를 확정 사실처럼 쓰는 방향
- 데스크톱 표와 복합 인터랙션을 모바일에 단순 축소하는 방향

## 13. 추가 확인이 필요한 자료

- YOVIA 실제 패키지 구조, 내장 도구와 토핑의 결합 방식, 사용 순서
- 확정 SKU, 맛 체계, 용량, 보관 방법, 원료·영양·알레르기 정보
- 구매·판매처·구독 중 실제 전환 경로
- 브랜드 사진, 패키지 렌더, 사용 상황 이미지의 제작 가능 범위
- [002] FAGE, [018] Huel, [020] Daily Harvest의 접근 제한 페이지와 모바일 동작
- Phase 2 누적 70개에서 패턴 비율과 선정 콘셉트의 유지·수정·폐기 여부

## 14. 결론

Phase 1 신규 20개에서는 **구조와 섭취 순간을 연결하는 제품 설명형**이 가장 타당한 초기 콘셉트다. 패키지 중심 표현 18/19, 사용 상황·방법 20/20, CTA 19/20이 제품 이해에서 행동까지 이어지는 근거를 제공한다. 다만 사용 상황의 설명 깊이는 브랜드마다 달라 구체적 단계 UI의 보편성을 뜻하지 않는다.

YOVIA의 권장 정보 흐름은 `제품·패키지 인지 → 구조와 3단계 사용법 → 섭취 상황 → 확정 영양·원료 신뢰 정보 → 맛·제품 선택 → 구매 또는 판매처 CTA`다. 직접 × 핵심 6개를 시각·제품 근거의 중심으로, 인접 × 핵심 4개를 단계·수치·루틴 구조의 보완 근거로 사용한다.

다만 이 결론은 20개 표본의 초기 가설이다. 실제 제품 구조와 정보가 확정되지 않으면 구조 설명을 제작하지 않으며, Phase 2 누적 70개에서 빈도와 콘셉트를 다시 검증한다.
