- 위험: 설명량이 많아지면 모바일 첫 화면이 무거워질 수 있음

### 후보 B — 패키지와 맛 컬러 중심 비비드형
- 핵심 키워드: 패키지 히어로, 맛별 컬러, 카드 탐색
- 강점: 제품군 확장과 시각적 기억에 유리함
- 위험: 제품 사용법과 정보 위계가 약해질 수 있음

### 후보 C — 영양 신뢰 중심 퍼포먼스형

- 강점: 기능성·고단백 인접군의 신뢰 정보를 차용하기 좋음

## 4. 선정 디자인 콘셉트

- **선정 디자인 콘셉트**: 구조와 섭취 순간을 연결하는 제품 설명형
- **선정 방식**: 근거 기반 추천
- **주 콘셉트 역할**: 제품이 무엇이고 어떻게 열고 섞어 먹는지 우선 설명
- **보조 콘셉트 역할**: 패키지·맛 컬러와 검증된 영양 수치를 탐색 보조로 사용
- **Phase 1 대비**: 주 콘셉트 유지. 50개 확장 표본에서 패키지 탐색과 기능 수치가 보조축으로 강화됨
- **모바일 적합성**: 단계형 카드와 1열 흐름으로 확장 가능
- **구현 위험**: 제품 구조 자산과 확정 수치가 없으면 설명 섹션을 축소해야 함
