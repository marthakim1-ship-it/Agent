- Phase 1 신규 조사 20개만 사용했다. Active 20, Completed 17, Partial 3, 중복 공식 도메인 0개다.

## 4. 선정 디자인 콘셉트

- **선정 디자인 콘셉트**: 구조와 섭취 순간을 연결하는 제품 설명형
- **선정 방식**: 근거 기반 추천
- **주 콘셉트 역할**: 무엇이 들어 있고 어떻게 열고 먹으며 언제 편한지를 패키지·단계·상황 순으로 설명한다.
- **보조 콘셉트 역할**: 맛·패키지 컬러 커머스형을 제품 선택 카드에 제한 적용한다.
- **선정 이유**: 16/20의 사용 맥락과 19/20의 CTA를 YOVIA 고유 구조에 직접 연결할 수 있다.
- **대표 출처**: 001, 013, 015, 017, 019
- **제외 후보 이유**: 영양형은 보충제화 위험, 질감형은 사용 구조 약화 위험 때문에 주축에서 제외했다.
- **모바일 적합성**: 높음. 1열 단계와 카드로 변환 가능하다.
- **구현 위험**: 실제 패키지 구조·사용 순서·제품 정보가 확정돼야 한다.
- **상태**: 분석 단계에서 검증할 Phase 1 가설이다.
