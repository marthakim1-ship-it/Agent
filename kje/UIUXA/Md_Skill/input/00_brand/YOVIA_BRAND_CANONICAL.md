## 14. 가상 클라이언트 생성 시 적용 규칙

`virtual_client/SKILL.md`는 이 문서를 읽을 때 다음 우선순위를 적용한다.

```text
1. 이 문서의 CONFIRMED
2. 가상 클라이언트 PDF의 검증된 사실
3. 페르소나 TXT의 사용자 행동·요구
4. 기존 레퍼런스 리서치·분류·분석
5. 모델 추론
```

### 필수 규칙

- `CONFIRMED`와 충돌하는 요구는 자동 채택하지 않는다.
- `CANDIDATE`는 가상 클라이언트가 요구할 수 있으나 브랜드 확정 사실로 사용하지 않는다.
- `HYPOTHESIS`는 요구사항 생성 근거로 활용할 수 있으나 `Validation Needed: true`를 적용한다.
- `NOT_VERIFIED` 값은 임의 생성하지 않는다.
- 사용자 문제는 YOVIA의 그릭요거트 기반 제품·웹 경험 안에서 해결하는 방향을 먼저 검토한다.
- 별개의 설계 의사결정 관점이 존재하면 가상 클라이언트를 임의로 합치지 않는다.
- 같은 의미의 요구를 표현만 바꾸어 수량을 부풀리지 않는다.
