# VC-025 — 장하늘

## 1. 생성 정보
- Client ID: VC-025
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002, SRC-PDF-002
- 기반 Evidence: EVD-0038
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 반복 구매·정기배송 경험 책임자
- 담당 영역: 재구매 시점과 구독 상태·변경·해지 경험
- 프로젝트 관점: 건강 루틴 지원과 사용자의 통제권을 함께 보장
- 핵심 타깃: YOVIA를 반복 소비하려는 바쁜 직장인·대학생
- 주요 사용 상황: 재구매, 배송 일정 확인, 수량 변경, 건너뛰기·해지
- 사업 목표: 강압 없는 반복 구매와 상태 투명성
- 전환 목표: 정책 확인 후 재구매 또는 정기배송 후보 선택

## 3. 핵심 사용자 문제
- 구독 여부와 정책이 미확정인데 반복 구매 편익만 강조하면 비용·일정·해지 조건을 오인한다.

## 4. 중요하게 보는 가치
- 통제권, 일정 투명성, 비용 명확성, 쉬운 변경·해지, 복구

## 5. 정보 우선순위
- 현재 상태 → 다음 일정 → 구성·비용 → 변경·건너뛰기 → 해지·지원

## 6. 기능 요구
- 재구매 알림 후보, 일정·수량 변경, 건너뛰기·해지의 동등한 경로

## 7. UX 요구
- 가입보다 변경·해지 경로를 숨기거나 어렵게 만들지 않음

## 8. UI 요구
- 현재값·변경값·적용일을 한 화면에서 비교

## 9. 콘텐츠 요구
- 건강 습관 메시지를 압박·죄책감·자동 갱신 은폐에 사용하지 않음

## 10. 비주얼 요구
- 일정·구성·상태를 장식보다 우선

## 11. 신뢰 요구
- 가격·배송·환불·해지 정책 확정 전 구독을 활성화하지 않음

## 12. 전환·구매 요구
- 단건 구매와 정기 구매를 동등하게 비교

## 13. 반응형·디바이스 요구
- 모바일에서 다음 일정·비용·변경·해지를 첫 화면에 제공

## 14. 금지·회피 사항
- 사전 선택 구독, 숨은 비용, 해지 방해, 미확정 혜택 생성
