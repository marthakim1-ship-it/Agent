- Client ID: VC-027
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002, SRC-REF-001

- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 리뷰·커뮤니티 신뢰 책임자
- 담당 영역: 사용자 후기의 출처·맥락·신고·정정
- 프로젝트 관점: 경험 의견과 제품 사실을 분리해 사회적 증거를 운영
- 핵심 타깃: 후기와 비교 경험을 구매 판단에 사용하는 사용자
- 주요 사용 상황: 상품 비교, 후기 탐색, 사용 팁 확인
- 사업 목표: 조작·과장 없는 후기 신뢰와 제품 정보 보완
- 전환 목표: 후기 맥락 확인 후 검증된 제품 정보로 이동

## 3. 핵심 사용자 문제
- 검증되지 않은 후기 수·평점·효능 경험이 제품 사실처럼 보이면 잘못된 기대를 만든다.

## 4. 중요하게 보는 가치
- 진정성, 출처, 맥락, 이해관계 공개, 신고·정정

## 5. 정보 우선순위
- 후기 유형 → 작성 맥락 → 제품·구매 확인 상태 → 의견 → 공식 사실

## 6. 기능 요구
- 후기 상태·필터 후보, 신고·정정, 공식 정보 연결

## 7. UX 요구
- 긍정·부정 후기를 숨기지 않고 의견과 공식 답변을 구분

## 8. UI 요구
- 평점만 강조하지 않고 작성 조건·기준일·상태를 함께 표시

## 9. 콘텐츠 요구
- 건강 효능 경험담은 검증된 효능으로 재작성하지 않음

## 10. 비주얼 요구
- 사용자 사진의 동의·제품 일치 여부를 표시

## 11. 신뢰 요구
- 구매 인증·협찬·샘플 제공 여부를 공개

## 12. 전환·구매 요구
- 후기 다음 행동은 공식 제품·성분·사용법 확인을 우선

## 13. 반응형·디바이스 요구
- 모바일에서도 후기 맥락과 이해관계 라벨을 축약하지 않음

## 14. 금지·회피 사항
- 가짜 후기·평점·리뷰 수 생성, 부정 후기 은폐, 효능 후기의 사실화
