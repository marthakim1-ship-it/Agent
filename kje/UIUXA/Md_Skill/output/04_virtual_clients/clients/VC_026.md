## 2. 기본 정보
- 역할: 체험·샘플링 프로그램 책임자
- 담당 영역: 첫 체험 구성과 취향·주의 정보 학습
- 프로젝트 관점: 라인업 미확정 상태에서 체험 가치를 과장하지 않고 선택 부담을 낮춤
- 핵심 타깃: YOVIA를 처음 접하고 맛·사용 경험을 비교하려는 사용자
- 주요 사용 상황: 출시 체험, 오프라인 샘플, 선물·입문 세트 검토
- 사업 목표: 첫 체험에서 제품 사용법과 검증 상태를 정확히 전달
- 전환 목표: 체험 조건 확인 후 제품 정보 또는 공식 신청 후보로 이동

## 3. 핵심 사용자 문제
- 실제 맛·구성·재고가 미확정이면 체험 세트가 확정 상품처럼 보이기 쉽다.

## 4. 중요하게 보는 가치
