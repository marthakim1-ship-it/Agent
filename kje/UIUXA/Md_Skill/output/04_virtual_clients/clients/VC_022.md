# VC-022 — 이정민

## 1. 생성 정보
- Client ID: VC-022
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002, SRC-REF-001
- 기반 Evidence: EVD-0035
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 식품 표시·광고 준법 책임자
- 담당 영역: 제품 페이지의 법정 표시와 건강·영양 표현 검토
- 프로젝트 관점: 이해하기 쉬운 제품 정보와 승인된 법정 문구를 구분해 공개
- 핵심 타깃: 성분·영양·건강 문구를 구매 판단에 사용하는 방문자
- 주요 사용 상황: 제품 상세, 비교, 캠페인, 검색 직접 진입
- 사업 목표: 과장·누락 위험을 낮추면서 핵심 정보를 빠르게 전달
- 전환 목표: 승인 표시를 확인한 사용자가 조건부 제품 탐색으로 이동

## 3. 핵심 사용자 문제
- 쉬운 마케팅 문구와 법적 필수 정보가 섞이면 확정 사실과 효능 주장을 구분하기 어렵다.

## 4. 중요하게 보는 가치
- 정확성, 승인 상태, 적용 범위, 기준일, 표현 일관성

## 5. 정보 우선순위
- 제품 정의 → 필수 표시 → 원료·영양 근거 → 주의사항 → 승인된 행동

## 6. 기능 요구
- 표시 항목 상태표, 승인본 연결, 문구 버전·기준일, 공개 보류 상태

## 7. UX 요구
- 요약과 전체 표시를 연결하되 중요한 주의사항을 접힌 영역에만 숨기지 않음

## 8. UI 요구
- 필수·선택·미확정 문구를 텍스트 라벨과 동일한 표 구조로 구분

## 9. 콘텐츠 요구
- 락토프리·무가당 등 확정 방향과 수치·효능 미확정을 문장 수준에서 분리

## 10. 비주얼 요구
- 장식보다 라벨·원재료·패키지 표시 자산을 판독 가능하게 제시

## 11. 신뢰 요구
- 승인자·출처·기준일 없는 수치·인증·효능은 공개하지 않음

## 12. 전환·구매 요구
- 법정 정보 확인을 방해하지 않는 위치에 확정된 CTA만 제공

## 13. 반응형·디바이스 요구
- 모바일에서도 표 항목명·값·단위·주의 문구 연결을 유지

## 14. 금지·회피 사항
- 미확정 영양 수치·인증·의료 효능 확정, 면책 문구로 과장 주장을 정당화
