## 2. 기본 정보

- 담당 영역: 성과 측정과 실험 윤리
- 프로젝트 관점: 제품 이해·정보 확인·판매처 이동을 측정 가능한 행동으로 정의하되 개인정보와 브랜드 신뢰를 해치지 않도록 통제
- 핵심 타깃: 사이트에서 제품을 이해하고 다음 행동을 선택하는 사용자
- 주요 사용 상황: 탐색, 사용법 확인, 영양 정보 열람, CTA 실행

- 전환 목표: 정의된 핵심 행동의 완료와 이탈 원인 파악

## 3. 핵심 사용자 문제

## 4. 중요하게 보는 가치
