# VC-030 — 고은별

## 1. 생성 정보
- Client ID: VC-030
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PDF-001, SRC-PDF-002, SRC-PDF-003, SRC-REF-003
- 기반 Evidence: EVD-0043
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 출시 전 경험 QA·릴리스 책임자
- 담당 영역: 핵심 여정·콘텐츠·상태·접근성의 출시 판정
- 프로젝트 관점: 개별 산출물이 아니라 실제 공개 가능한 연결 상태를 검증
- 핵심 타깃: 모바일·키보드·느린 연결·오류 상황을 포함한 전체 방문자
- 주요 사용 상황: 출시 후보 검토, 회귀 테스트, 콘텐츠·정책 변경 후 재검증
- 사업 목표: 끊긴 링크·오래된 정보·복구 없는 오류를 공개 전에 차단
- 전환 목표: 핵심 여정이 검증된 경우에만 출시 승인

## 3. 핵심 사용자 문제
- 화면별 문서가 정상이어도 실제 연결·상태·콘텐츠 버전이 어긋나면 사용자는 목표를 완료할 수 없다.

## 4. 중요하게 보는 가치
- 추적성, 재현 가능성, 실패 복구, 회귀 방지, 승인 근거

## 5. 정보 우선순위
- 릴리스 범위 → 핵심 여정 → 상태·예외 → 콘텐츠·정책 버전 → 판정·잔여 위험

## 6. 기능 요구
- 검증 체크리스트, 링크·상태 점검, 결함 심각도, 재검증 이력

## 7. UX 요구
- 정상 흐름뿐 아니라 로딩·빈 상태·오류·복구·직접 진입을 검증

## 8. UI 요구
- 통과·실패·보류를 색상 외 텍스트와 근거로 표시

## 9. 콘텐츠 요구
- 화면의 제품·정책·CTA가 동일 승인 버전인지 확인

## 10. 비주얼 요구
- 이미지 대체 텍스트·깨짐·레이아웃 확대·좁은 폭을 확인

## 11. 신뢰 요구
- 테스트하지 않은 항목을 통과로 표시하지 않음

## 12. 전환·구매 요구
- 판매 정책·도착 화면·오류 복구가 없으면 CTA 출시를 보류

## 13. 반응형·디바이스 요구
- 320px, 텍스트 200%, 키보드, 모바일, 느린 연결을 최소 후보로 검증

## 14. 금지·회피 사항
- 미실행 테스트 통과 처리, 알려진 중대 결함 은폐, 미확정 정책 강제 출시
