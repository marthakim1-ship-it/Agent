# VC-002 — 김도현, 패키지 사용성·품질 책임자

## 1. 생성 정보
- Client ID: VC-002
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002
- 기반 Evidence: EVD-0002, EVD-0004, EVD-0009, EVD-0011, EVD-0012
- Evidence Confidence: High/Medium 혼합

## 2. 기본 정보
- 역할: Packaging Usability & Quality Lead (synthetic)
- 담당 영역: 파우치 구조, 개봉·취식·정리 경험, 품질 주장 검증
- 프로젝트 관점: 제품 사용성을 웹에서 이해시키되 시험하지 않은 성능은 약속하지 않는 발주자
- 핵심 타깃: 이동·업무 환경에서 흘림과 도구 부담을 줄이려는 사용자
- 주요 사용 상황: 출근 전, 이동 후 정차·대기 상황, 사무실·수업 사이
- 사업 목표: 패키지 사용성 차별화를 신뢰 가능한 제품 가치로 전환
- 전환 목표: 사용법을 이해한 사용자가 제품 상세 확인으로 이동

## 3. 핵심 사용자 문제
- 컵·스푼·분리 포장이 손과 주변을 더럽히고 폐기 부담을 만든다.
- 파우치의 개봉, 토핑 결합, 잔여물 배출 방식이 보이지 않으면 편의성을 판단하기 어렵다.
- 누수·내압·잔여물 감소 같은 성능은 시험 없이 단정할 수 없다.

## 4. 중요하게 보는 가치
- 실제 사용성, 안전, 단계 감소, 증거 기반 품질 표현

## 5. 정보 우선순위
1. 확정 패키지 구조 2. 개봉·스푼·토핑 사용법 3. 사용 전후 상태 4. 검증된 시험 결과

## 6. 기능 요구
- 사용 과정 미디어와 단계별 설명, 확대 가능한 구조 설명을 요구한다.

## 7. UX 요구
- 준비부터 폐기까지 사용 흐름이 끊기지 않고 이해되어야 한다.

## 8. UI 요구
- 단계, 부품, 주의사항을 명확한 라벨과 상태로 구분한다.

## 9. 콘텐츠 요구
- 실제 제품 이미지와 검증된 성능만 사용한다.

## 10. 비주얼 요구
- 손과 제품의 상호작용, 개봉 전후, 토핑과 스푼 관계를 우선한다.

## 11. 신뢰 요구
- 누수·내압·잔여물·소재 주장은 시험 근거에 연결한다.

## 12. 전환·구매 요구
- 사용성을 이해한 뒤 제품 상세 또는 확정 구매 행동으로 연결한다.

## 13. 반응형·디바이스 요구
- 모바일에서도 사용 단계의 순서와 라벨이 잘리지 않아야 한다.

## 14. 금지·회피 사항
- 운전 중 취식을 권장하지 않는다.
- 듀얼 챔버·스파우트·친환경 소재를 확정 사양처럼 제시하지 않는다.
