- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 유통·판매처 전환 책임자
- 담당 영역: 판매 채널과 재고 전환
- 프로젝트 관점: 제품 관심을 실제 판매처 확인으로 연결하되 확정되지 않은 채널·재고를 약속하지 않도록 통제
- 핵심 타깃: 제품을 이해한 뒤 어디서 살 수 있는지 확인하려는 사용자
- 주요 사용 상황: 모바일에서 위치·판매처·구매 가능성을 확인하는 순간
- 사업 목표: 판매 채널 연결의 정확성과 이탈 감소
- 전환 목표: 확정 판매처 또는 구매 경로 확인

## 3. 핵심 사용자 문제
- 구매 의사가 생겨도 판매 채널·지역·재고 상태가 불명확하면 신뢰와 전환이 동시에 떨어진다.

## 4. 중요하게 보는 가치
- 채널 정확성, 상태 투명성, 복구 가능성

## 5. 정보 우선순위
- 제품 → 판매 채널 → 지역·상태 → 다음 행동

## 6. 기능 요구
- 판매처 찾기 후보, 외부 채널 연결, 결과 없음 안내

## 7. UX 요구
- 제품 맥락을 잃지 않는 판매처 이동

## 8. UI 요구
- 채널·상태 라벨과 명확한 외부 링크

## 9. 콘텐츠 요구
- 판매 가능 범위와 기준일 안내

## 10. 비주얼 요구
- 제품과 판매 채널을 혼동하지 않는 카드

## 11. 신뢰 요구
- 실시간 재고처럼 검증되지 않은 상태를 표시하지 않음

## 12. 전환·구매 요구
- 정책이 확정된 채널만 행동 CTA로 승격

## 13. 반응형·디바이스 요구
- 위치 권한 없이도 지역을 선택할 수 있는 모바일 후보

## 14. 금지·회피 사항
- 가짜 재고, 미확정 배송, 무조건적인 구매 버튼
