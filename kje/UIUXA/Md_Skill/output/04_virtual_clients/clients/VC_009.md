# VC-009 — 배서윤, 지속가능성·폐기 경험 책임자

## 1. 생성 정보
- Client ID: VC-009
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002
- 기반 Evidence: EVD-0012, EVD-0022
- Evidence Confidence: Low

## 2. 기본 정보
- 역할: Sustainability & End-of-Use Experience Lead (synthetic)
- 담당 영역: 정리·폐기·환경 주장 거버넌스
- 프로젝트 관점: 사용 후 부담을 설명하되 소재·환경 효과를 근거 없이 친환경으로 포장하지 않는 발주자
- 핵심 타깃: 이동·야외 활동 후 쓰레기와 잔여물 처리를 걱정하는 사용자
- 주요 사용 상황: 사무실, 이동, 캠핑·야외 활동 후 정리
- 사업 목표: 사용 후 경험의 신뢰와 책임성 강화
- 전환 목표: 확인된 폐기 안내를 본 사용자가 제품을 올바르게 검토

## 3. 핵심 사용자 문제
- 잔여물·부피·분리배출 방식이 불명확하다.
- 친환경 소재·효과는 현재 미확정이다.

## 4. 중요하게 보는 가치
- 정확한 폐기 안내, 그린워싱 방지, 사용 전후 경험 연결

## 5. 정보 우선순위
- 사용 후 정리 → 분리배출 → 소재·시험 근거 → 환경 주장 상태

## 6. 기능 요구
- 단계별 폐기 안내, 지역 차이 고지, 근거 상태

## 7. UX 요구
- 사용 방법의 마지막 단계에 정리·폐기를 포함한다.

## 8. UI 요구
- 환경 상태를 모호한 잎 아이콘만으로 표현하지 않는다.

## 9. 콘텐츠 요구
- 잔여물 처리, 압축 여부, 분리배출 안내 후보

## 10. 비주얼 요구
- 자연 이미지로 미확정 친환경성을 암시하지 않는다.

## 11. 신뢰 요구
- 소재·재활용·환경 수치는 시험·인증 근거 필요

## 12. 전환·구매 요구
- 친환경성을 구매 CTA의 근거로 사용하기 전 검증한다.

## 13. 반응형·디바이스 요구
- 모바일에서 폐기 단계를 짧은 순서로 제공한다.

## 14. 금지·회피 사항
- 생분해·재활용·폐기 감소 효과를 임의 확정하지 않는다.
