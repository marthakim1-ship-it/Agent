## 2. 기본 정보
- 역할: 지역화·언어 운영 책임자
- 담당 영역: 언어·지역별 정보 일관성
- 프로젝트 관점: 브랜드 정의와 제품 사실은 일관되게 유지하면서 판매·표시·문의 정보는 실제 지역 조건에 맞춰 분리
- 핵심 타깃: 기본 언어와 지역 조건이 다른 방문자
- 주요 사용 상황: 언어 전환, 지역 판매처 확인, 현지 표시 정보 검토

- 전환 목표: 현재 지역에 유효한 정보와 행동 확인

## 3. 핵심 사용자 문제
- 언어만 번역하고 제품·정책·판매 조건을 구분하지 않으면 사용자는 다른 지역 정보를 자신의 조건으로 오해한다.
