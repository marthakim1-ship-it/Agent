# VC-010 — 임재희, 정보 접근성·포용성 책임자

## 1. 생성 정보
- Client ID: VC-010
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PDF-001, SRC-PDF-002, SRC-PDF-003
- 기반 Evidence: EVD-0006, EVD-0014, EVD-0023
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: Inclusive Information Experience Lead (synthetic)
- 담당 영역: 모바일 정보 접근성·상태 이해·오류 복구
- 프로젝트 관점: 시각적 브랜드를 유지하면서 다양한 사용자가 핵심 제품 정보를 놓치지 않게 하는 발주자
- 핵심 타깃: 작은 화면·이동 환경·다양한 시각 및 입력 조건에서 정보를 확인하는 사용자
- 주요 사용 상황: 모바일 한 손 탐색, 밝은 야외, 키보드·보조기술 탐색
- 사업 목표: 정보 접근 실패와 이탈 감소
- 전환 목표: 누구나 핵심 정보와 다음 행동의 의미를 이해

## 3. 핵심 사용자 문제
- 색상·이미지·가로표에 의존하면 핵심 정보가 누락된다.
- 오류·빈 상태·포커스 흐름 요구가 기존 관점에서 약하다.

## 4. 중요하게 보는 가치
- 인지 가능성, 조작 가능성, 이해 가능성, 복구 가능성

## 5. 정보 우선순위
- 제품 정의 → 핵심 정보 → 상태·주의 → 명확한 행동

## 6. 기능 요구
- 키보드 탐색, 대체 텍스트, 상태 알림, 오류 복구 후보

## 7. UX 요구
- 핵심 여정이 확대·축소와 단일 열에서도 유지된다.

## 8. UI 요구
- 색상만으로 제품군·상태·오류를 구분하지 않는다.

## 9. 콘텐츠 요구
- 짧고 구체적인 레이블과 오류 메시지

## 10. 비주얼 요구
- 텍스트 대비와 이미지 대체 설명을 검증한다.

## 11. 신뢰 요구
- 접근성 충족을 검증 없이 준수했다고 주장하지 않는다.

## 12. 전환·구매 요구
- CTA가 목적과 도착 화면을 예측 가능하게 표현한다.

## 13. 반응형·디바이스 요구
- 모바일 1열, 터치·키보드·확대, 동작 축소 선호를 검토한다.

## 14. 금지·회피 사항
- 색상·이미지·호버만으로 정보와 기능을 전달하지 않는다.

## 16. 다른 가상 클라이언트와의 관계
- 공통: 모든 Client의 모바일 정보 탐색
- 보완: 접근성·상태·오류 복구를 독립 품질 축으로 추가
- 충돌: 강한 컬러·이미지 중심 표현과 비시각적 정보 전달
- 특화: 키보드·대체 텍스트·상태 알림

- 접근성 감사, 보조기술·키보드 테스트, 대비, 터치 영역, 오류 상태
