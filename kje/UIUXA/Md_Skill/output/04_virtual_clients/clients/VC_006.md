# VC-006 — 정다은, 맛·식감 경험 책임자

## 1. 생성 정보
- Client ID: VC-006
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PER-001, SRC-PER-002
- 기반 Evidence: EVD-0017, EVD-0019
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: Sensory Experience & Portfolio Lead (synthetic)
- 담당 영역: 맛·식감 탐색과 제품군 표현
- 프로젝트 관점: 미확정 맛을 사실로 만들지 않으면서 사용자가 실제 맛과 질감을 판단하게 하는 발주자
- 핵심 타깃: 인공적인 맛에 민감하고 꾸덕함·토핑 식감을 비교하는 사용자
- 주요 사용 상황: 간식 선택, 운동 후, 야간 작업, SNS 발견 후 제품 검토
- 사업 목표: 감각적 관심을 검증 가능한 제품 이해로 전환
- 전환 목표: 확정 맛·식감 정보를 확인한 사용자가 제품 상세로 이동

## 3. 핵심 사용자 문제
- 건강식의 밍밍함과 인공 감미료 잔향을 구매 전에 판단하기 어렵다.
- 이미지가 실제 질감·토핑 양을 과장할 수 있다.

## 4. 중요하게 보는 가치
- 실제 제품 기반 감각 정보, 맛과 식감의 명확한 구분, 과장 방지

## 5. 정보 우선순위
- 확정 맛·원료 → 질감·토핑 → 당류 등 검증 정보 → 적용 제품

## 6. 기능 요구
- 확정 라인업 필터 후보, 질감·토핑 갤러리, 비교 카드

## 7. UX 요구
- 감성 표현 뒤에 실제 원료·제품 상태를 바로 연결한다.

## 8. UI 요구
- 맛은 색상만이 아니라 이름·상태 텍스트를 병기한다.

## 9. 콘텐츠 요구
- 실제 촬영, 맛 설명 기준, 토핑 구성과 식감 설명

## 10. 비주얼 요구
- 콘셉트 합성과 실제 제품 이미지를 명확히 구분한다.

## 11. 신뢰 요구
- 미확정 맛·감미료·영양 수치를 `NOT_VERIFIED`로 표시한다.

## 12. 전환·구매 요구
- 확정 라인업에만 제품 확인 CTA를 연결한다.

## 13. 반응형·디바이스 요구
- 모바일에서 대표 이미지→짧은 맛 설명→상세 근거 순서를 유지한다.

## 14. 금지·회피 사항
- 가상 맛, 토핑 양, 효능을 실제 사양처럼 표현하지 않는다.
