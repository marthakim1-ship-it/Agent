# VC-029 — 신가람

## 1. 생성 정보
- Client ID: VC-029
- 생성 유형: synthetic virtual client
- 기반 Source: SRC-BRAND-001, SRC-PDF-001, SRC-PDF-002, SRC-REF-001
- 기반 Evidence: EVD-0042
- Evidence Confidence: Medium

## 2. 기본 정보
- 역할: 재고 대기·출시 알림 책임자
- 담당 영역: 품절·출시 전 제품의 알림 선택과 상태 변경
- 프로젝트 관점: 미확정 출시·재고를 조급한 전환 문구로 과장하지 않음
- 핵심 타깃: 관심 제품이 없거나 아직 구매할 수 없는 사용자
- 주요 사용 상황: 품절 상품, 출시 예정, 판매 채널 미확정, 알림 신청·철회
- 사업 목표: 관심을 보존하면서 허위 긴급성과 불필요한 개인정보 수집 방지
- 전환 목표: 상태를 이해한 사용자가 선택적으로 알림 또는 대체 정보 탐색

## 3. 핵심 사용자 문제
- 출시일·재고·채널이 미확정인데 알림 신청만 제공하면 구매 가능 시점을 오해하고 개인정보를 불필요하게 제공한다.

## 4. 중요하게 보는 가치
- 상태 정확성, 선택권, 알림 목적, 쉬운 철회, 대체 경로

## 5. 정보 우선순위
- 현재 상태 → 확인 기준일 → 알림 범위 → 수집 정보 → 대체 제품·정보

## 6. 기능 요구
- 상태 구독 후보, 채널 선택, 알림 해제, 대체 정보 연결

## 7. UX 요구
- 신청하지 않아도 제품·브랜드·사용법 정보 열람

## 8. UI 요구
- 품절·예정·미확정·판매 중 상태를 색상 외 텍스트로 구분

## 9. 콘텐츠 요구
- 임박·한정·곧 출시 같은 표현은 승인 일정이 있을 때만 사용

## 10. 비주얼 요구
- 확정 제품과 콘셉트 이미지를 명확히 구분

## 11. 신뢰 요구
- 알림 목적·빈도·채널·보관 기간·철회 방법 공개

## 12. 전환·구매 요구
- 알림 신청과 일반 탐색을 동등하게 제공

## 13. 반응형·디바이스 요구
- 모바일에서 현재 상태와 신청·철회 결과를 즉시 확인

## 14. 금지·회피 사항
